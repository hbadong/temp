# Heatwatch

热词游戏站最小验证。按公众号《想用AI做网站挣钱？我把热词游戏站从选游戏到上线跑了一遍》的漏斗落地：1 款游戏、6 个已确认页面、sitemap / robots、28 天观察期。

站点仍在测试期，不包装成成功案例。广告代码可预埋，流量出现以前它不是收入。

## 页面

- `index.html` 首页
- `release-date.html` 发售时间
- `playtest.html` 测试资格
- `price.html` 价格与版本
- `system-requirements.html` 电脑配置
- `faq.html` 重复出现的玩家问题
- `method.html` 67→6 的筛选方法与停机线
- `analysis.html` 原文深度分析
