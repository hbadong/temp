How to join the test

Players search “closed test”, “server slam”, “how to get a key”. If the official FAQ is buried, a one-screen checklist can rank.

Last checked: 2026-10-01 · Status: steps must match the live signup form

Checklist (only after official signup is live)

  1. Open the publisher’s playtest page — not a third-party “key shop”.
  2. Confirm platform (PC / console) and region. A lot of tests silently drop unsupported countries.
  3. Link the required account (Steam, PlayStation, Xbox, or publisher ID).
  4. Submit hardware / NDA fields if asked. Save the confirmation email.
  5. Watch the same official channel for wave dates. Discord rumors are not a source.
