## 一、接收输入，分析原网站

> **前置条件**：SKILL.md「阶段〇：三问门禁」已完成 — 原网址 / 源码路径 / 主题名三要素齐备后才能进入本章。

### 1.0 主题命名规则（三问之第三问，AI 自行命名）

不询问用户，按以下规则确定主题名：

1. **取名依据**：原站域名主体优先（如 `www.youxilibao.com` → `youxilibao`）；域名无意义时按网站内容/品牌名取拼音或英文
2. **格式要求**：小写字母 + 数字，不超过 10 个字符，仅目录名安全字符
3. **冲突检查**：Glob `view/*/info.ini` 确认现有主题，**不得与现有主题重名**
4. **移动端主题惯例**：若需创建手机端主题，命名为主主题名 + `m`（如 `game955` → `game955m`）
5. **告知用户**：命名确定后在确认摘要中告知用户
6. **用户自定义名**：三问中用户通过 AskUserQuestion 输入了自定义主题名的，直接采用（仍执行冲突检查，重名时告知用户并给替代名）

**输入齐备后输出确认摘要**（一行）：

```
原网址：https://www.xxx.com | 源码路径：D:/path/to/source | 主题名：xxx
```

### 1.1 源码分析

从本地源码提取：

| 分析项 | 提取方式 | 产出 |
|--------|---------|------|
| HTML 模板 | 遍历源码目录，找到 `.html` / `.htm` 文件 | 页面清单 |
| CSS 样式 | 找到 `.css` 文件，分析 class 命名 | 样式文件清单 |
| JS 交互 | 找到 `.js` 文件，分析功能 | JS 文件清单 |
| 图片资源 | 找到 `image/`、`img/`、`picture/` 目录 | 图片资源清单 |
| 字体/图标 | 找到 `font/`、`iconfont` 等 | 字体文件清单 |
| URL 结构 | 分析 HTML 中的链接路径 | URL 路由映射表 |

### 1.2 在线分析

通过浏览器或 WebFetch 分析原网站：

| 分析项 | 需要确认的问题 |
|--------|--------------|
| 导航菜单 | 顶部导航有哪些栏目？URL 路径？ |
| 内容类型 | 网站有哪些类型的内容？ |
| 频道分类 | 每个频道下有哪些子分类？层级？ |
| 列表页结构 | 每个频道列表页的布局？ |
| 详情页结构 | 详情页有哪些区块？ |
| 特殊页面 | 搜索/标签/排行榜/专题页？ |
| 静态页面 | 关于我们/联系我们等单页？ |
| 自定义字段 | 详情页非标准字段（大小/下载链接/平台）？ |
| 标签系统 | 内容是否带标签？用于什么场景？ |
| 属性标记 | 推荐/热门/头条等标记？ |

**移动端站点（m.xxx.com）额外确认：**

| 分析项 | 要点 |
|--------|------|
| 与 PC 端关系 | 是否共数据共模型？确认后**不新建模型/分类**，只建移动端主题（`view/{主题}/`），配置 open_mobile_view 自动切换 |
| 手机端导航 | 通常比 PC 精简（955yx 手机端仅 首页/手游/资讯 + 搜索图标，无软件栏目） |
| 手机端首页区块 | 焦点图轮播 + 图标宫格（火爆/必备）+ 图文列表（资讯）+ 列表项（最新）+ 精选分类 + 友情链接（上下轮播） |
| 列表项结构 | 图 + 标题 + 星级（star star{N}）+ 分类/大小 + 查看按钮 |
| 详情页下载区 | 高速/普通/暂不提供 按钮（对应 download_url_android/ios 字段判断） |
| JS 体系 | 原站是否用 seajs（`seajs.use('app/common')`）？jquery 是否定制版（内嵌 seajs/Vue/TouchSlide）？交互是否依赖原站 AJAX API？ |

### 1.3 推导模板文件需求

根据分析结果，推导需要哪些 `.htm` 模板文件：

```
推导逻辑：

内容类型 A（如游戏）
  ├── 有列表页吗？ → 需要 game_list.htm
  ├── 有详情页吗？ → 需要 game_show.htm
  └── 详情页区块有哪些？ → 决定模板内 section 划分

内容类型 B（如软件）
  ├── 列表页和游戏相同吗？ → 可共用 game_list.htm
  └── 详情页和游戏相同吗？ → 可基于 game_show.htm 修改

内容类型 C（如文章）
  ├── 有频道首页吗？ → 需要 article_index.htm
  ├── 有列表页吗？ → 需要 article_list.htm
  └── 有详情页吗？ → 需要 article_show.htm

特殊页面
  ├── 有搜索？ → search.htm
  ├── 有标签页？ → tag_list.htm / tag_top.htm / tag_all.htm
  ├── 有排行榜？ → flags.htm 或 page_show.htm
  ├── 有404页？ → 404.htm
  ├── 有评论？ → comment.htm
  └── 有友情链接/随机内容？ → inc-rand.htm
```

### 1.4 产出设计文档

分析完成后，生成设计文档，包含：

```
docs/superpowers/specs/{日期}-lecms-{主题}-design.md

├── 项目概述（参考网站、目标）
├── 内容类型对比表（列表页结构 / 详情页结构）
├── 模型设计（模型清单、自定义字段、建表 SQL）
├── 分类结构树（带 cid 占位）
├── 模板文件映射表（参考页面 → 模板文件）
├── URL 路由方案
├── 样式资源清单
└── 验收标准
```
