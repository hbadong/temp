## 一、系统概述

### 1.1 LECMS程序特性

该CMS系统使用自研的**XiunoPHP模板引擎**，采用编译型模板方式，将模板文件编译为PHP缓存文件后执行。

**核心特点：**
- 编译型模板：模板文件编译为PHP缓存，提升性能
- 标签解析：支持自定义标签语法
- Block模块：可复用的数据块
- Hook支持：模板中支持插件钩子
- 缓存机制：模板缓存和数据缓存分离
- 程序框架：采用懒加载、分布式服务器的设计，每张表都可有自己的DB服务器群和CACHE服务器(群)，单表能承受亿级数据
- 安全高效：基于开源框架XIUNOPHP开发，邀请"乌云漏洞平台"、"被黑站点统计平台"的专业白帽子审计程序代码
- 插件扩展：采用基于开源XIUNOPHP框架的AOP插件机制，性能方面零损耗，可自由扩展程序功能
- 轻量级CMS：简洁精干，注重实用性，主程序只做最核心功能，其它通过插件实现
- SEO优化：内置多种SEO设置，对网站URL路径设置自由度极高
- 后台框架：使用基于Layui编写的一套简洁易用的后台框架layuimini，响应式设计
- MIT协议：您可以自由修改、派生版本、商用而不用担心任何法律风险

## 四、模板引擎核心机制

### 4.1 模板处理流程

```
模板文件 (.htm)
      ↓
view::display() 发起渲染
      ↓
view::tpl_process() 模板编译 (9个步骤)
      ↓
写入编译缓存 (runcache/lecms_view/)
      ↓
include 编译后的PHP文件
      ↓
输出HTML
```

### 4.2 模板编译步骤

**文件：** `lecms/xiunophp/lib/view.class.php:55-106`

```php
private function tpl_process($tpl_file) {
    $s = file_get_contents($tpl_file);
    
    // 第1步: 包含inc模板
    $s = preg_replace_callback('#\{inc\:([\w|\/\.]+)\}#', array($this, 'process_inc'), $s);
    
    // 第2步: 解析模板hook
    $s = preg_replace_callback('#\{hook\:([\w\.]+)\}#', array('core', 'process_hook'), $s);
    
    // 第3步: 解析php代码
    $s = preg_replace('#(?:\<\?.*?\?\>|\<\?.*)#s', '', $s);  // 清理PHP语法
    $s = preg_replace('#\{php\}(.*?)\{\/php\}#s', '<?php \\1 ?>', $s);
    
    // 第4步: 包含block
    $s = preg_replace_callback('#\{block\:([a-zA-Z_]\w*)\040?([^\n\}]*?)\}(.*?){\/block}#s', 
                               array($this, 'process_block'), $s);
    
    // 第5步: 解析loop
    $s = preg_replace_callback('#\{loop\:(\$'.$reg_arr.'(?:\040\$[a-zA-Z_]\w*){1,2})\}(.*?)\{\/loop\}#s', 
                               array($this, 'process_loop'), $s);
    
    // 第6步: 解析if
    $s = preg_replace_callback('#\{if\:([^\n\}]+)\}(.*?)\{\/if\}#s', 
                               array($this, 'process_if'), $s);
    
    // 第7步: 解析变量
    $s = preg_replace('#\{\@([^\}]+)\}#', '<?php echo(\\1); ?>', $s);
    $s = preg_replace_callback('#\{(\$'.$reg_arr.')\}#', array($this, 'process_vars'), $s);
    
    // 第8步: 解析语言包
    $s = preg_replace_callback('#\{lang\:([\w\.]+)\}#', array($this, 'process_lang'), $s);
    
    // 第9步: 代码压缩 (可选)
    
    return $s;
}
```

### 4.3 缓存机制

**模板缓存位置：** `runcache/lecms_view/`

```php
private function get_tplfile($filename) {
    $view_dir = APP_NAME.($_ENV['_view_diy'] ? '_view_diy' : '_view').'/';
    $php_file = RUNTIME_PATH.$view_dir.$_ENV['_theme'].','.$filename.'.php';
    
    if(!is_file($php_file) || DEBUG) {
        // 编译模板
        $tpl_file = core::get_original_file($filename, VIEW_PATH.$_ENV['_theme'].'/');
        if($tpl_file) {
            FW($php_file, $this->tpl_process($tpl_file));
        }
    }
    
    return $php_file;
}
```

**缓存规则：**
- DEBUG模式下：每次都重新编译
- 正常模式下：有缓存则使用缓存

**清除缓存方法：**
```bash
# 清除模板编译缓存
rm -rf runcache/lecms_view/
```

## 五、模板标签语法

### 5.1 变量标签

#### 5.1.1 普通变量

**语法：** `{$变量名}`

**示例：**
```html
<!-- 简单变量 -->
<h1>{$cfg[webname]}</h1>
<a href="{$cfg[weburl]}">链接</a>

<!-- 数组变量 -->
<p>{$gdata[title]}</p>
<span>{$v[date]}</span>

<!-- 多维数组 -->
<img src="{$v[thumb][0]}" />
```

**编译后：**
```php
<?php echo isset($cfg['webname']) ? $cfg['webname'] : ''; ?>
<?php echo isset($gdata['title']) ? $gdata['title'] : ''; ?>
```

#### 5.1.2 运算输出

**语法：** `{@表达式}`

**示例：**
```html
<!-- 数学运算 -->
<p>{@$v[views] + 100}</p>

<!-- 字符串处理 -->
<p>{@mb_substr($v[title], 0, 20)}</p>

<!-- 三元运算 -->
<p>{@$v[status] ? '已发布' : '草稿'}</p>
```

**编译后：**
```php
<?php echo($v['views'] + 100); ?>
```

### 5.2 循环标签

#### 5.2.1 loop循环

**语法：**
```html
{loop:$数组 $值}
    <!-- 循环体 -->
{/loop}

{loop:$数组 $键 $值}
    <!-- 循环体 -->
{/loop}
```

**示例：**
```html
<!-- 简单循环 -->
{loop:$list $v}
    <li>{$v[title]}</li>
{/loop}

<!-- 带键名循环 -->
{loop:$list $k $v}
    <li>{$k} - {$v[title]}</li>
{/loop}

<!-- 嵌套循环 -->
{loop:$cate_list $cate}
    <div class="category">
        <h3>{$cate[name]}</h3>
        {loop:$cate[article] $article}
            <p>{$article[title]}</p>
        {/loop}
    </div>
{/loop}
```

**编译后：**
```php
<?php if(isset($list) && is_array($list)) { foreach($list as $v) { ?>
    <li><?php echo isset($v['title']) ? $v['title'] : ''; ?></li>
<?php }} ?>
```

#### 5.2.2 Block循环

**语法：**
```html
{block:模块名 参数="值"}
    {loop:$data[list] $v}
        <!-- 循环体 -->
    {/loop}
{/block}
```

**示例：**
```html
<!-- 内容列表 -->
{block:list cid="1" mid="2" limit="10"}
    {loop:$data[list] $v}
        <div class="article">
            <h2><a href="{$v[url]}">{$v[subject]}</a></h2>
            <p>{$v[intro]}</p>
        </div>
    {/loop}
{/block}
```

### 5.3 条件标签

#### 5.3.1 if条件

**语法：**
```html
{if:条件}
    <!-- 满足条件时 -->
{elseif:条件}
    <!-- 否则如果条件满足时 -->
{else}
    <!-- 都不满足时 -->
{/if}
```

**示例：**
```html
<!-- 简单条件 -->
{if:$user[uid]}
    <p>欢迎您，{$user[username]}</p>
{else}
    <p>请<a href="/login">登录</a></p>
{/if}

<!-- 多条件 -->
{if:$row[status] == 1}
    <span class="published">已发布</span>
{elseif:$row[status] == 0}
    <span class="draft">草稿</span>
{else}
    <span class="archived">已归档</span>
{/if}

<!-- 数组判断 -->
{if:isset($gdata[prev][url])}
    <a href="{$gdata[prev][url]}">{$gdata[prev][title]}</a>
{/if}

<!-- 长度判断 -->
{if:$data[list]}
    <p>有{$data[count]}条数据</p>
{/if}
```

**编译后：**
```php
<?php if($user['uid']) { ?>
    <p>欢迎您，<?php echo isset($user['username']) ? $user['username'] : ''; ?></p>
<?php } else { ?>
    <p>请<a href="/login">登录</a></p>
<?php } ?>
```

### 5.4 包含标签

#### 5.4.1 inc包含

**语法：** `{inc:模板文件名}`

**示例：**
```html
<!-- 包含头部 -->
{inc:header.htm}

<!-- 包含底部 -->
{inc:footer.htm}

<!-- 包含子目录模板 -->
{inc:user/header.htm}
```

**说明：**
- 自动查找 `inc-模板名.htm` 文件
- 例如 `{inc:header.htm}` 实际查找 `inc-header.htm`

#### 5.4.2 block包含

**语法：** `{block:模块名 参数="值"}{/block}`

**示例：**
```html
<!-- 分类列表 -->
{block:category cid="0" limit="10"}
    {loop:$data[list] $v}
        <a href="{$v[url]}">{$v[name]}</a>
    {/loop}
{/block}

<!-- 标签列表 -->
{block:taglist limit="20"}
    {loop:$data[list] $v}
        <a href="{$v[url]}">{$v[name]}</a>
    {/loop}
{/block}
```

### 5.5 语言标签

**语法：** `{lang:语言键名}`

**示例：**
```html
<p>{lang:welcome}</p>
<span>{lang:submit}</span>
<a>{lang:login}</a>
```

**编译后：**
```php
<?php echo '欢迎访问'; ?>
```

### 5.6 Hook标签

**语法：** `{hook:钩子名}`

**示例：**
```html
<!-- 在模板中插入Hook -->
<div class="custom-area">
    {hook:my_custom_hook}
</div>

<!-- 用于插件扩展 -->
{hook:article_show_bottom}
```

### 6.6 重要提示

**注意：一个HTM页面只能有一个 `global_` 开头的block，这个开头的代表是当前页面的全局变量。**

比如内容页可以写成：

```html
{block:global_show show_prev_next="1" dateformat="Y-m-d"}{/block}

页面其他任意位置均可调用 {$gdata}
```

### 6.8 自定义Block开发

**文件：** `lecms/block/block_my_custom.lib.php`

```php
<?php
defined('ROOT_PATH') || exit;

/**
 * 自定义内容列表Block
 * 
 * 参数说明：
 * @param int cid 分类ID
 * @param int limit 显示数量
 * @param string orderby 排序方式
 * @param int life 缓存时间
 * 
 * @return array
 */
function block_my_custom($conf) {
    global $run;
    
    // hook block_my_custom_before.php
    
    // 获取参数
    $cid = isset($conf['cid']) ? intval($conf['cid']) : 0;
    $limit = isset($conf['limit']) ? intval($conf['limit']) : 10;
    $orderby = isset($conf['orderby']) ? $conf['orderby'] : 'id';
    $orderway = isset($conf['orderway']) && $conf['orderway'] == 1 ? 1 : -1;
    $life = isset($conf['life']) ? intval($conf['life']) : 0;
    
    // hook block_my_custom_conf_after.php
    
    // 缓存处理
    $cache_key = $life ? md5('my_custom'.serialize(array($cid, $limit, $orderby, $orderway))) : '';
    if($cache_key) {
        $cache_data = $run->runtime->get_block_data_cache($cache_key);
        if($cache_data) {
            return $cache_data;
        }
    }
    
    // 获取分类信息
    if($cid > 0) {
        $cate = $run->category->get_cache($cid);
        if(empty($cate)) {
            return array('list' => array(), 'count' => 0);
        }
        $table = $cate['table'];
    } else {
        $table = 'article';
    }
    
    // 查询数据
    $db = $run->db;
    $tablepre = $run->_cfg['db']['master']['tablepre'];
    
    $list = $db->get("SELECT id, title, url, date, intro 
                      FROM {$tablepre}{$table} 
                      WHERE status = 1 
                      ORDER BY {$orderby} " . ($orderway == 1 ? 'ASC' : 'DESC') . "
                      LIMIT ?", 
                     array($limit));
    
    $count = count($list);
    
    // hook block_my_custom_list_arr_after.php
    
    // 设置返回值
    $return = array(
        'list' => $list,
        'count' => $count,
    );
    
    // 写入缓存
    if($cache_key) {
        $run->runtime->set_block_data_cache($cache_key, $return, $life);
    }
    
    // hook block_my_custom_after.php
    
    return $return;
}
```

**在模板中使用：**
```html
{block:my_custom cid="1" limit="5" orderby="id"}
    {loop:$data[list] $v}
        <li><a href="{$v[url]}">{$v[title]}</a></li>
    {/loop}
{/block}
```

- `mid`：模型ID ，cid=0时，这个参数生效，默认为2
- `start`：起始位置，一般不用填写，默认为0
- `limit`：读取多少条，默认为10
- `titlenum`：标题截取长度，显示请用{$v[subject]}

- `dateformat`：显示的时间格式，默认为Y-m-d H:i:s ， 如果要显示为多久之前（dateformat="human_date"）
- `orderby`：排序字段，有id dateline comments，默认为id
- `orderway`：升序还是降序，（1：升序，-1：降序），默认降序
- `showcate`：是否读取内容的分类信息，默认不读取
- `showviews`：是否读取内容的浏览量信息，默认不读取
- `field_format`：是否格式化自定义字段（需安装自定义字段插件）

```php
 */
function random_string($length = 6, $type = 'all') {
    $chars = '';
    
    if ($type == 'letter') {
        $chars = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ';

    for ($i = 0; $i < $length; $i++) {
        $str .= $chars[mt_rand(0, $max)];
    }
    
    return $str;
}
```

```php
            $v['title_cut'] = mb_substr($v['title'], 0, 30, 'utf-8') . '...';
            $v['views_format'] = number_format($v['views']);
        }
        $this->assign('list', $list);
        
        // 方式2：assign自定义函数（不推荐直接在模板中调用控制器定义的函数）
        // 建议使用方式1处理数据
        
        $this->display('index.htm');
    }
}
```

#### 13.2.6 注意事项

1. **函数命名规范**：自定义函数应使用小写字母和下划线，如 `format_price`、`get_heat_level`

2. **避免冲突**：不要定义与PHP内置函数同名的函数

3. **参数处理**：函数应处理各种边界情况，如空值、错误类型等

4. **性能考虑**：复杂的数据处理应在PHP端完成，模板函数应保持简单

5. **安全性**：用户输入的数据必须经过过滤和转义

```php
// 不安全示例
function unsafe_function($content) {
    eval($content);  // 危险！
}

// 安全示例
function safe_function($content) {
    return htmlspecialchars(strip_tags($content));
}
```

6. **缓存考虑**：频繁调用的复杂函数应考虑添加缓存

```php
function expensive_function($key) {
    global $run;
    
    $cache_key = 'func_' . md5($key);
    $cache = $run->runtime->get($cache_key);
    if ($cache !== false) {
        return $cache;
    }
    
    // 复杂计算
    $result = ...;
    
    // 缓存10分钟
    $run->runtime->set($cache_key, $result, 600);
    
    return $result;
}
```

## 十四、模板安全

### 14.1 XSS防护

**自动转义：**
系统会自动对变量进行HTML转义：
```html
<!-- 模板中 -->
{$v[content]}

<!-- 编译后(自动转义) -->
<?php echo isset($v['content']) ? htmlspecialchars($v['content']) : ''; ?>
```

**富文本处理：**
对于需要输出HTML的内容，使用特殊处理：
```html
<!-- 内容详情页(HTML内容) -->
<div class="content">
    {$gdata[content]}
</div>

<!-- 需要允许特定HTML标签时 -->
<div class="content">
    {@strip_tags($v[content], '<p><br><a><img>')}
</div>
```

### 14.2 SQL注入防护

Block模块会自动处理SQL参数：
```html
<!-- 安全: Block参数自动过滤 -->
{block:list cid="{$cid}" limit="10"}
    ...
{/block}
```

### 14.3 文件包含安全

inc包含的文件必须是模板文件：
```html
<!-- 只能包含模板文件 -->
{inc:header.htm}     <!-- ✓ 安全 -->
{inc:../../config.php}  <!-- ✗ 禁止 -->

<!-- 自动过滤路径穿越 -->
{inc:user/header.htm}  <!-- 实际查找 user/inc-header.htm -->
```

### 14.4 模板安全建议

1. **避免使用PHP代码块**
```html
<!-- 不推荐 -->
{php}echo file_get_contents($_GET['file']);{/php}

<!-- 推荐 -->
{php}echo htmlspecialchars($v[title]);{/php}
```

2. **用户输入过滤**
```html
<!-- 搜索表单 -->
<form method="get" action="{$search_url}">
    <input type="text" name="keyword" value="{php echo isset($_GET['keyword']) ? htmlspecialchars($_GET['keyword']) : '';}">
    <button type="submit">搜索</button>
</form>
```

3. **URL安全验证**
```html
<!-- 外部链接添加安全提示 -->
<a href="{$v[url]}" target="_blank" rel="nofollow noopener">
    {$v[title]}
</a>
```

## 十七、常见问题解答

### Q1: 模板不生效？

1. 检查模板文件是否存在
2. 清理 `runcache/lecms_view/` 目录
3. 检查文件名是否正确
4. 检查后台是否启用了该主题

### Q2: Block数据为空？

1. 检查 `cid` 和 `mid` 参数是否正确
2. 确认分类下有内容
3. 检查内容状态是否为已发布

### Q3: 变量显示错误？

1. 检查变量名是否正确
2. 使用 `{if:isset($var)}` 判断变量是否存在

### Q4: 如何调试模板？

```php
// 在控制器中添加调试输出
$this->assign('debug_data', $list);

// 在模板中显示
<pre><?php print_r($debug_data); ?></pre>
```

### Q5: 如何根据"推荐"、"热门"等属性做列表页？

导航添加一个外链"推荐文章"，URL填写：`/flags/1/`

### Q6: 一个HTM页面可以用多个global_开头的block吗？

不可以。一个HTM页面只能有一个 `global_` 开头的block。
