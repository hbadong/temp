## 68. 安全机制总览

LeCMS 在框架层面构建了多层纵深防御体系，覆盖了从网络请求到数据存储的各个环节。

| 安全措施 | 说明 | 实现位置 |
|----------|------|----------|
| **GPC 过滤** | 自动过滤 GET/POST/COOKIE | `init_set()` |
| **参数过滤** | `R()` 函数自动 `htmlspecialchars` | `base.func.php` |
| **SQL 注入防护** | 预处理语句 + where 数组 | `db_*.class.php` |
| **XSS 防护** | 模板变量自动转义 | `view.class.php` |
| **CSRF 防护** | `form_hash` 令牌机制 | `base.func.php` |
| **路径防护** | 防止目录遍历 | `core.class.php` |
| **文件包含防护** | 限制 inc 只包含模板文件 | `view.class.php` |
| **直接访问防护** | `defined('ROOT_PATH') \|\| exit` | 所有 PHP 文件 |
| **控制器验证** | control/action 正则校验 | `init_get()` |

### 68.1 安全文件头

所有 PHP 文件必须以安全文件头开头，防止被直接访问：

```php
<?php
// 所有 PHP 文件必须以此开头
defined('ROOT_PATH') || exit;
```

**作用机制：**
- `ROOT_PATH` 在 `index.php`（入口文件）中定义。
- 如果直接访问 `plugin/le_links/links_model.class.php`，`ROOT_PATH` 未定义，触发 `exit`。
- 只有通过 `index.php` 的框架路由才能正常加载这些文件。

### 68.2 安全获取参数

```php
// 安全获取 IP
function ip() {
    if(isset($_SERVER['HTTP_X_FORWARDED_FOR'])) {
        // 正向代理传来的 IP，可能包含多个，取第一个
        preg_match('#[\d\.]{7,15}#', $_SERVER['HTTP_X_FORWARDED_FOR'], $mat);
        if($mat){
            $ip = $mat[0];
        } else {
            return ip_c();
        }
    } elseif(isset($_SERVER['HTTP_CLIENT_IP'])) {
        $ip = $_SERVER['HTTP_CLIENT_IP'];
    } elseif(isset($_SERVER['REMOTE_ADDR'])) {
        $ip = $_SERVER['REMOTE_ADDR'];
        if($ip == '::1') {$ip='127.0.0.1';}  // IPv6 本地地址转换
    } else {
        $ip = '127.0.0.1';
    }
    // 验证 IP 格式并转换为长整型
    return long2ip(ip2long($ip));
}

// CSRF Token 生成
function form_hash() {
    return md5($_ENV['_config']['auth_key'].$_ENV['_ip']);
}
```

**说明：**
- `ip()` 函数综合判断 `HTTP_X_FORWARDED_FOR` / `HTTP_CLIENT_IP` / `REMOTE_ADDR`，优先使用代理传递的真实 IP。
- 使用 `preg_match` 只提取合法 IP 段，防止 IP 伪造。
- `form_hash()` 基于 `auth_key`（配置中的密钥）和用户 IP 生成哈希，确保令牌不可预测。

## 69. GPC 安全过滤

### 69.1 MAGIC_QUOTES_GPC 检测

在框架初始化阶段，框架检测 PHP 的 `magic_quotes_gpc` 配置：

```php
// init_set.php

if(get_magic_quotes_gpc()) {
    // PHP 自动添加了反斜杠，需要清理
    $_GET    = _stripslashes($_GET);
    $_POST   = _stripslashes($_POST);
    $_COOKIE = _stripslashes($_COOKIE);
    $_REQUEST = _stripslashes($_REQUEST);
}
```

**说明：**
- `magic_quotes_gpc` 在 PHP 5.4 起已废弃，7.4 起移除。
- LeCMS 兼容旧版 PHP，保留了这段兼容代码。
- 新版 PHP 中 `get_magic_quotes_gpc()` 始终返回 `false`，不会执行清理。

### 69.2 _stripslashes() 递归清理

```php
/**
 * 递归去除字符串或数组中的反斜杠
 * @param mixed $value 字符串或数组
 * @return mixed 清理后的数据
 */
function _stripslashes($value) {
    if(is_array($value)) {
        foreach($value as $k => $v) {
            $value[$k] = _stripslashes($v);
        }
        return $value;
    } else {
        return stripslashes($value);
    }
}
```

**说明：**
- 递归处理，支持多维数组。
- 应对 `magic_quotes_gpc` 产生的嵌套转义问题。

### 69.3 R() 函数安全取值

```php
/**
 * 安全获取 GET/POST/COOKIE 参数
 *
 * @param string $name 参数名
 * @param string $type 来源：'G'=GET, 'P'=POST, 'C'=COOKIE, 'GP'=GET优先
 * @param mixed $default 默认值
 * @param string $filter 过滤器：'I'=整数, 'S'=字符串, 'A'=数组, 'B'=布尔
 * @return mixed 安全后的值
 */
function R($name, $type = 'GP', $default = null, $filter = '') {
    switch($type) {
        case 'G':
            $value = isset($_GET[$name]) ? $_GET[$name] : $default;
            break;
        case 'P':
            $value = isset($_POST[$name]) ? $_POST[$name] : $default;
            break;
        case 'C':
            $value = isset($_COOKIE[$name]) ? $_COOKIE[$name] : $default;
            break;
        case 'GP':
        default:
            $value = isset($_POST[$name]) ? $_POST[$name] : (isset($_GET[$name]) ? $_GET[$name] : $default);
            break;
    }

    // 应用过滤器
    switch($filter) {
        case 'I':  // 整数
            return is_array($value) ? 0 : intval($value);
        case 'S':  // 字符串（自动 htmlspecialchars）
            return is_array($value) ? '' : htmlspecialchars((string)$value);
        case 'A':  // 数组
            return is_array($value) ? $value : array($value);
        case 'B':  // 布尔
            return (bool)$value;
    }

    return $value;
}
```

**用法示例：**

```php
$id    = R('id', 'G', 0, 'I');       // GET 参数，转为整数
$name  = R('name', 'P', '', 'S');     // POST 参数，自动 htmlspecialchars
$flag  = R('flag', 'P', false, 'B');  // POST 参数，转为布尔
$arr   = R('ids', 'P', array(), 'A'); // POST 参数，确保为数组
```

### 69.4 完整的 GPC 处理流程

```
[HTTP 请求到达]
       |
       v
[1. 检测 magic_quotes_gpc]
       |
       +-- 开启 → _stripslashes() 递归清理所有 GPC 数据
       |
       v
[2. 初始化 $_ENV['_ip']]
   调用 ip() 函数获取客户端真实 IP
       |
       v
[3. 初始化 $_ENV['_time']]
   记录当前时间戳
       |
       v
[4. 路由分发]
   控制器/方法校验
       |
       v
[5. R() 函数取值]
   按需转义（htmlspecialchars）
       |
       v
[6. 业务逻辑处理]
       |
       v
[7. 输出响应]
   模板自动转义
```

## 70. SQL 注入防护

### 70.1 addslashes() 自动转义

```php
// 在 GPC 处理阶段，框架自动对字符串进行转义

function _addslashes($value) {
    if(is_array($value)) {
        foreach($value as $k => $v) {
            $value[$k] = _addslashes($v);
        }
        return $value;
    } else {
        return addslashes($value);
    }
}

// 应用到所有 GPC 数据
$_GET    = _addslashes($_GET);
$_POST   = _addslashes($_POST);
$_COOKIE = _addslashes($_COOKIE);
```

**说明：**
- `addslashes()` 对单引号、双引号、反斜杠、NUL 字节进行转义。
- 递归处理数组，确保深层数据也被保护。
- 这是 **第一层防御**。

### 70.2 参数化查询（PDO 占位符）

```php
// 底层驱动使用 PDO 预处理语句，参数自动绑定

// 模型层自动使用预处理
$where = array('id' => 1, 'status' => 1);
$list = $this->article->find_fetch($where);

// 等效于以下预处理 SQL
$sql = "SELECT * FROM le_article WHERE id = ? AND status = ?";
$stmt = $this->db->prepare($sql);
$stmt->execute(array(1, 1));
```

**说明：**
- 所有模型操作最终都通过 PDO 预处理语句执行。
- 参数与 SQL 语句分离，从根本上杜绝 SQL 注入。
- 这是 **第二层防御**。

### 70.3 arr2where() 安全构建 WHERE

```php
// arr2where() 使用 ? 占位符，不拼接原始值

$where = array(
    'title' => array('LIKE' => '%test%'),
    'status' => 1,
);

list($where_sql, $args) = $this->db->arr2where($where, $tablepre);
// 结果：
// $where_sql = "`le_title` LIKE ? AND `le_status` = ?"
// $args = ['%test%', 1]

// 最终 SQL
$sql = "SELECT * FROM le_article WHERE {$where_sql}";
$stmt = $this->db->prepare($sql);
$stmt->execute($args);
```

**安全特性：**
- 表名通过反引号包裹（`le_title`）。
- 值全部使用 `?` 占位符，通过 PDO 绑定传递。
- 不支持用户自定义 SQL 片段。

### 70.4 表前缀自动添加

```php
// 所有 SQL 生成时自动添加表前缀

// 模型类只需写裸表名
$this->table = 'article';

// 框架自动拼接
// "SELECT * FROM le_article WHERE ..."  而不是  "SELECT * FROM article WHERE ..."
```

**安全意义：**
- 防止用户通过控制表名注入恶意 SQL。
- 统一管理表前缀，支持多环境配置。

### 70.5 SQL 注入防护 Checklist

| 检查项 | 安全做法 | 危险做法 |
|--------|----------|----------|
| WHERE 条件 | 使用数组 `$where` | 字符串拼接 `"id=$id"` |
| 字符串值 | 通过 `R()` 函数获取 | 直接 `$_GET['id']` |
| 表名 | 模型自动映射 | 动态拼接表名 |
| 排序字段 | 白名单验证 | 直接使用用户输入 |
| 执行 SQL | 预处理语句 | 直接拼接执行 |

## 71. XSS 防护

### 71.1 htmlspecialchars() HTML 转义

```php
/**
 * HTML 转义（最常用的 XSS 防护）
 * @param string $str 待转义的字符串
 * @param int $flags 转义标志
 * @return string 转义后的字符串
 */
function htmlspecialchars($str, $flags = ENT_QUOTES | ENT_HTML5) {
    return htmlspecialchars($str, $flags, 'UTF-8');
}
```

**转义的特殊字符：**

| 原字符 | 转义后 | 说明 |
|--------|--------|------|
| `<` | `&lt;` | HTML 标签开始符 |
| `>` | `&gt;` | HTML 标签结束符 |
| `&` | `&amp;` | 实体引用符 |
| `"` | `&quot;` | 双引号（ENT_QUOTES） |
| `'` | `&#039;` | 单引号（ENT_QUOTES） |

### 71.2 _htmls() 递归转义

```php
/**
 * 递归转义数组中的所有字符串
 * @param mixed $value 字符串或数组
 * @return mixed 转义后的数据
 */
function _htmls($value) {
    if(is_array($value)) {
        foreach($value as $k => $v) {
            $value[$k] = _htmls($v);
        }
        return $value;
    } else {
        return htmlspecialchars((string)$value);
    }
}
```

**说明：**
- 模板引擎在渲染变量时，默认对输出值调用 `_htmls()`。
- 递归处理，确保嵌套数组的每一层都被转义。
- 如果变量包含 HTML（如富文本内容），需在赋值时标记为免转义。

### 71.3 safe_str() 字符串过滤

```php
/**
 * 更严格的安全过滤
 * 移除 HTML 标签、特殊字符
 * @param string $str 输入字符串
 * @return string 过滤后的字符串
 */
function safe_str($str) {
    // 移除 HTML 标签
    $str = strip_tags($str);
    // HTML 转义
    $str = htmlspecialchars($str, ENT_QUOTES, 'UTF-8');
    // 移除不可见字符
    $str = preg_replace('/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/u', '', $str);
    return $str;
}
```

### 71.4 富文本安全的 HTML 输出

对于允许 HTML 的内容（如文章正文），框架提供安全的 HTML 输出方式：

```php
// 文章正文（富文本）
// 在数据入库时使用 HTMLPurifier 过滤
$purifier = new HTMLPurifier();
$content = $purifier->purify($_POST['content']);

// 模板中输出时标记为 raw，跳过自动转义
echo $article['content'];  // 已通过过滤器，安全输出
```

**HTML 白名单策略：**
```php
// 允许的标签和属性
$config = HTMLPurifier_Config::createDefault();
$config->set('HTML.AllowedElements', ['a', 'p', 'br', 'strong', 'em', 'ul', 'ol', 'li', 'img']);
$config->set('HTML.AllowedAttributes', ['a.href', 'img.src', 'img.alt']);
$config->set('URI.AllowedSchemes', ['http' => true, 'https' => true]);
$config->set('HTML.TargetBlank', true);  // 外链自动 target="_blank"
```

## 72. CSRF 防护

### 72.1 form_hash() 生成令牌

```php
/**
 * 生成 CSRF 令牌
 * 基于 auth_key + 用户 IP 的 MD5 哈希
 * @return string 令牌字符串
 */
function form_hash() {
    return md5($_ENV['_config']['auth_key'].$_ENV['_ip']);
}
```

**auth_key 配置：**
```php
// config/config.inc.php
$_ENV['_config']['auth_key'] = 'your-random-secret-key-here';
// 生产环境必须使用强随机字符串
```

### 72.2 form_submit() 校验令牌

```php
/**
 * 校验 CSRF 令牌
 * @param string $hash 客户端提交的令牌
 * @return bool 校验是否通过
 */
function form_submit($hash) {
    $expected = form_hash();
    return $hash === $expected;
}
```

### 72.3 基于 auth_key + 时间戳

LeCMS 的 CSRF 防护结合了时间戳机制，防止令牌被长期利用：

```php
/**
 * 生成带时间戳的 CSRF 令牌
 * @param int $ttl 有效期（秒），默认 7200（2小时）
 * @return string 令牌字符串
 */
function form_hash_with_time($ttl = 7200) {
    $time = $_ENV['_time'];
    // 将时间戳取整到 ttl 间隔
    $time_slot = floor($time / $ttl) * $ttl;
    return md5($_ENV['_config']['auth_key'] . $_ENV['_ip'] . $time_slot);
}

/**
 * 校验带时间戳的令牌
 */
function form_submit_with_time($hash, $ttl = 7200) {
    $time = $_ENV['_time'];
    // 检查当前时间槽和上一个时间槽（防止时钟不同步）
    foreach(array(0, 1) as $i) {
        $time_slot = floor(($time - $i * $ttl) / $ttl) * $ttl;
        if($hash === md5($_ENV['_config']['auth_key'] . $_ENV['_ip'] . $time_slot)) {
            return true;
        }
    }
    return false;
}
```

### 72.4 CSRF 防护在模板中的使用

```html
<!-- 表单中嵌入 CSRF 令牌 -->
<form method="post" action="index.php?user-login">
    <input type="hidden" name="form_hash" value="{form_hash}" />
    <input type="text" name="username" />
    <input type="password" name="password" />
    <button type="submit">登录</button>
</form>
```

```php
// 控制器中校验
public function login() {
    if(empty($_POST)) {
        $this->display();
    } else {
        $hash = R('form_hash', 'P');
        if(!form_submit($hash)) {
            $this->message(0, '表单令牌已过期，请刷新页面重试');
        }

        // 校验通过，继续处理登录逻辑
        $username = R('username', 'P');
        $password = R('password', 'P');
        // ...
    }
}
```

**CSRF 防护的完整流程：**

```
[用户访问表单页面]
    |
    v
[服务器生成 form_hash = md5(auth_key + ip + time_slot)]
    |
    v
[隐藏字段 <input type="hidden" name="form_hash" value="..."> 嵌入表单]
    |
    v
[用户提交表单]
    |
    v
[服务器校验 form_submit(hash)]
    |-- 匹配当前时间槽 → 通过
    |-- 匹配上一个时间槽 → 通过（时钟偏差容错）
    |-- 都不匹配 → 拒绝
```

## 73. 路径与文件安全

### 73.1 路径遍历防护

```php
/**
 * 防止路径遍历攻击
 * 过滤掉 ../ 等路径穿越字符
 * @param string $path 文件路径
 * @return string 安全的路径
 */
function path_safe($path) {
    // 移除 .. 和 . 路径段
    $path = preg_replace('#/\.+#', '/', $path);
    $path = preg_replace('#[^/]+/\.\./#', '', $path);

    // 确保路径不包含 ../ 等穿越序列
    if(strpos($path, '..') !== false) {
        return '';
    }

    // 转为真实路径并验证在合法目录内
    $real = realpath($path);
    $base = realpath(ROOT_PATH);
    if($real && strpos($real, $base) !== 0) {
        return '';
    }

    return $real;
}
```

**示例攻击与防护：**

```
攻击：  ../../etc/passwd
防护后：  /etc/passwd → 不在站点目录内 → 拒绝

攻击：  uploads/../../config.inc.php
防护后：  /config.inc.php → 不在上传目录内 → 拒绝
```

### 73.2 文件包含防护

```php
/**
 * 安全包含文件
 * @param string $file 文件路径
 * @param string $type 类型：'tpl'=模板, 'cls'=类, 'func'=函数
 */
function safe_include($file, $type = 'tpl') {
    // 根据类型检查文件扩展名
    $allowed_ext = array(
        'tpl'  => array('.htm', '.html', '.tpl'),
        'cls'  => array('.class.php', '.php'),
        'func' => array('.func.php', '.php'),
    );

    $ext = strtolower(substr($file, strrpos($file, '.')));

    if(!in_array($ext, $allowed_ext[$type])) {
        trigger_error("安全警告：禁止包含 {$ext} 类型文件", E_USER_WARNING);
        return false;
    }

    // 检查文件是否在允许的目录内
    $real = realpath($file);
    if(!$real) return false;

    $allowed_dirs = array(
        'tpl'  => array(THEME_PATH, PLUGIN_PATH),
        'cls'  => array(CORE_PATH, PLUGIN_PATH),
        'func' => array(CORE_PATH, PLUGIN_PATH),
    );

    foreach($allowed_dirs[$type] as $dir) {
        if(strpos($real, realpath($dir)) === 0) {
            return include $real;
        }
    }

    trigger_error("安全警告：文件不在允许的目录内 - {$file}", E_USER_WARNING);
    return false;
}
```

### 73.4 上传文件安全

```php
/**
 * 安全上传文件
 * @param string $field 表单字段名
 * @param array $allow_ext 允许的扩展名
 * @param int $max_size 最大文件大小（字节）
 * @return array ['success' => bool, 'file' => string, 'error' => string]
 */
function safe_upload($field, $allow_ext = array('jpg', 'jpeg', 'png', 'gif'), $max_size = 2097152) {
    if(!isset($_FILES[$field]) || $_FILES[$field]['error'] !== UPLOAD_ERR_OK) {
        return array('success' => false, 'error' => '上传失败');
    }

    $file = $_FILES[$field];

    // 检查文件大小
    if($file['size'] > $max_size) {
        return array('success' => false, 'error' => '文件大小超过限制');
    }

    // 检查扩展名
    $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
    if(!in_array($ext, $allow_ext)) {
        return array('success' => false, 'error' => '不允许的文件类型');
    }

    // 使用 MIME 类型二次校验
    $finfo = finfo_open(FILEINFO_MIME_TYPE);
    $mime = finfo_file($finfo, $file['tmp_name']);
    finfo_close($finfo);

    $allowed_mimes = array(
        'jpg'  => 'image/jpeg',
        'jpeg' => 'image/jpeg',
        'png'  => 'image/png',
        'gif'  => 'image/gif',
    );

    if($mime !== $allowed_mimes[$ext]) {
        return array('success' => false, 'error' => '文件类型不匹配');
    }

    // 生成安全文件名（防止重名和路径注入）
    $safe_name = md5(uniqid() . $_ENV['_time']) . '.' . $ext;
    $dest = UPLOAD_PATH . date('Y/m/') . $safe_name;

    // 创建目录
    if(!is_dir(dirname($dest))) {
        mkdir(dirname($dest), 0755, true);
    }

    // 移动文件
    if(move_uploaded_file($file['tmp_name'], $dest)) {
        return array('success' => true, 'file' => $safe_name);
    }

    return array('success' => false, 'error' => '文件移动失败');
}
```

### 74.2 模板编译缓存

| 阶段 | 说明 |
|------|------|
| 首次请求 | 读取 `.htm` 模板 → 解析标签 → 编译为 `.php` 文件 |
| 后续请求 | 直接加载 `.php` 编译文件，跳过解析步骤 |
| 模板更新 | 框架检测 `.htm` 修改时间 > `.php` 修改时间，自动重新编译 |

**编译缓存路径：** `runcache/lecms_view/`

### 74.3 二级缓存（L1: Cache, L2: DB keys）

```
请求流程中的缓存层级：

[请求] → [OpCache] → [L1 缓存(内存数组)] → [L2 缓存(Redis/File)] → [数据库]
```

| 层级 | 存储介质 | 生命周期 | 命中率 |
|------|----------|----------|--------|
| OpCache | PHP 内存 | 进程级 | 代码层面 |
| L1 缓存 | PHP 变量 | 单次请求 | 数据层面 |
| L2 缓存 | Redis/File | 可配置 TTL | 跨请求 |
| 数据库 | MySQL | 持久 | 最终数据源 |

**缓存策略示例：**

```php
// 热门文章列表 — 5分钟缓存

        array('status' => 1),
        array('views' => -1),
        0, 10
    );
    $_ENV['_cache']->set('hot_articles', $hot_articles, 300);
}
```

### 74.6 _strip_whitespace() 压缩

```php
/**
 * 移除 PHP 文件中的注释和空白
 * 用于生产环境部署
 * @param string $file PHP 文件路径
 * @return string 压缩后的代码
 */
function _strip_whitespace($file) {
    $code = file_get_contents($file);

    // 移除行注释
    $code = preg_replace('/\/\/[^\n]*/', '', $code);

    // 移除块注释
    $code = preg_replace('/\/\*.*?\*\//s', '', $code);

    // 移除多余空白
    $code = preg_replace('/[ \t]+/', ' ', $code);
    $code = preg_replace('/\n+/', "\n", $code);

    return trim($code);
}
```

### 74.7 数据库查询优化

| 优化策略 | 具体做法 |

### 75.2 错误处理

```php
<?php
// debug.class.php

class debug {

    /**
     * 错误处理器
     * 替换 PHP 默认错误处理器
     */
    public static function error_handler($errno, $errstr, $errfile, $errline) {
        if(!(error_reporting() & $errno)) {
            return;  // 错误码在屏蔽列表内
        }

        $error_types = array(
            E_ERROR             => 'Error',
            E_WARNING           => 'Warning',
            E_PARSE             => 'Parse Error',
            E_NOTICE            => 'Notice',
            E_CORE_ERROR        => 'Core Error',
            E_CORE_WARNING      => 'Core Warning',
            E_COMPILE_ERROR     => 'Compile Error',
            E_COMPILE_WARNING   => 'Compile Warning',
            E_USER_ERROR        => 'User Error',
            E_USER_WARNING      => 'User Warning',
            E_USER_NOTICE       => 'User Notice',
            E_STRICT            => 'Strict',
            E_DEPRECATED        => 'Deprecated',
            E_USER_DEPRECATED   => 'User Deprecated',
        );

        $type = isset($error_types[$errno]) ? $error_types[$errno] : 'Unknown';

        if($_ENV['_config']['system']['debug'] > 0) {
            echo "<div style='color:red;border:1px solid red;padding:10px;'>";
            echo "<strong>{$type}</strong>: {$errstr}<br>";
            echo "File: {$errfile} (Line {$errline})<br>";
            echo "</div>";
        }

        // 记录到日志
        self::log_error("{$type}: {$errstr} in {$errfile}:{$errline}");

        if($errno == E_ERROR || $errno == E_PARSE || $errno == E_COMPILE_ERROR) {
            exit(1);
        }
    }

    /**
     * 异常处理器
     * 捕获未处理的异常
     */
    public static function exception_handler($e) {
        if($_ENV['_config']['system']['debug'] > 0) {
            echo "<div style='color:red;border:1px solid red;padding:10px;'>";
            echo "<strong>Uncaught Exception</strong>: {$e->getMessage()}<br>";
            echo "File: {$e->getFile()} (Line {$e->getLine()})<br>";
            echo "<pre>{$e->getTraceAsString()}</pre>";
            echo "</div>";
        } else {
            echo "服务器内部错误，请稍后再试";
        }

        self::log_error("Exception: {$e->getMessage()} in {$e->getFile()}:{$e->getLine()}");
        exit(1);
    }
}

// 注册错误处理器
set_error_handler(array('debug', 'error_handler'));
set_exception_handler(array('debug', 'exception_handler'));
```

function runtime() {

    return microtime(TRUE) - $start;
