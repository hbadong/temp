## 77. 配置系统

LeCMS 采用分层配置体系，从文件到运行时再到数据库缓存，覆盖了从启动到运行时的所有配置需求。

### 77.1 配置文件层级

| 层级 | 来源 | 说明 |
|------|------|------|
| 基础配置 | `config/config.inc.php` | 数据库、缓存、路径等核心配置，返回 `$_ENV['_config']` 数组 |
| 插件配置 | `config/plugin.inc.php` | 插件启用/禁用状态 |
| 路由配置 | `config/route.inc.php` | 自定义 URL 规则（需开启 `route_open`） |
| 运行时配置 | 数据库 `runtime` 表 | 用户可修改的业务配置（通过 `runtime->xget('cfg')` 读取） |
| 内存缓存 | `$_ENV['_config']` | 框架统一访问接口 |

### 77.3 运行时配置读写（C() 函数）

配置文件加载后，所有配置项存储在 `$_ENV['_config']` 数组中。框架提供了 `C()` 函数作为统一访问接口。

**源码位置**: `d:\phpstudy_pro\WWW\aimuchen100.com\lecms\xiunophp\lib\base.func.php` 第 126 行

```php
/**
 * 读取/设置 配置信息 (Config 的缩写)
 * @param string $key  键值
 * @param string $val  设置值（不传则读取）
 * @return mixed
 */
function C($key, $val = null) {
    if(is_null($val)) return isset($_ENV['_config'][$key]) ? $_ENV['_config'][$key] : $val;
    return $_ENV['_config'][$key] = $val;
}
```

**使用示例**:

```php
// 读取配置
$debug_mode = C('debug');                   // 返回: 0
$db_host = C('db.master.host');             // 注意: 不支持嵌套 key 直接读取

// 设置配置（运行时修改）
C('debug', 1);                              // 设置 debug 为 1
C('my_custom_key', 'my_value');             // 添加自定义配置项

// 三元写法（带默认值）
$lang = C('lang', 'zh-cn');
```

**配置分层优先级**: 文件配置（初始值）→ 运行时 `C()` 修改 → 数据库缓存（`runtime->xget('cfg')` 加载的业务配置）

## 78. 错误处理体系（debug.class.php）

LeCMS 的错误处理体系基于 PHP 原生错误处理机制，通过 `debug` 类实现统一管理。

**源码位置**: `d:\phpstudy_pro\WWW\aimuchen100.com\lecms\xiunophp\lib\debug.class.php`

### 78.1 错误处理初始化流程

```
debug::init_start()
  ├── DEBUG 模式开启
  │   ├── error_reporting(E_ALL | E_STRICT)    // 报告所有错误
  │   └── register_shutdown_function()          // 注册致命错误处理
  ├── DEBUG 模式关闭
  │   └── error_reporting(0)                    // 关闭所有错误输出
  ├── ini_set('display_errors', ...)            // 根据 DEBUG 设置显示
  ├── set_error_handler()                       // PHP 错误处理
  └── set_exception_handler()                   // 异常处理
```

**源码**:

```php
class debug {
    public static function init_start() {
        if(DEBUG) {
            error_reporting(E_ALL | E_STRICT);
            register_shutdown_function(array('debug', 'shutdown_handler'));
        }else{
            error_reporting(0);
        }
        function_exists('ini_set') && ini_set('display_errors', DEBUG ? 'On' : 'Off');
        set_error_handler(array('debug', 'error_handler'));
        set_exception_handler(array('debug', 'exception_handler'));
    }
}
```

### 78.3 线上模式错误处理

当 `DEBUG = 0`（生产模式）时：

```php
public static function error_handler($errno, $errstr, $errfile, $errline) {
    // 通知类错误：只写日志，不中断
    if(in_array($errno, array(E_NOTICE, E_USER_NOTICE, E_DEPRECATED))) {
        log::write($s);  // 记录到日志文件
    } else {
        // 其他错误：记录日志 + 友好提示
        if(!defined('ADMIN_PATH')){
            self::error_die('[程序错误: 请开启调试模式查看详细信息]');
        }
        throw new Exception($s);
    }
}
```

**线上模式行为**:
- E_NOTICE / E_USER_NOTICE / E_DEPRECATED → 仅写日志，程序继续运行
- 其他错误 → 记录日志 + 显示友好错误页面（前台）或抛出异常（后台）

### 78.4 调试模式错误处理

当 `DEBUG > 0` 时：

```php
if(DEBUG) {
    throw new Exception($s);  // 直接抛出异常，显示完整堆栈信息
}
```

调试模式下所有错误都会转化为异常，显示完整的错误文件、行号和堆栈追踪。

### 78.5 致命错误处理（shutdown_handler）

通过 `register_shutdown_function()` 注册，处理 PHP  fatal error：

```php
public static function shutdown_handler() {
    if(empty($_ENV['_exception'])) {
        if($e = error_get_last()) {
            $message = $e['message'];
            $file = $e['file'];
            $line = $e['line'];
            if(R('ajax', 'R')) {
                echo json_encode(array('error' => "[致命错误] : $message File: $file [$line]"));
            }else{
                self::sys_error('[致命错误] : '.$message, $file, $line);
            }
        }
    }
}
```

**触发条件**: 内存耗尽、调用未定义函数、类不存在等致命错误。

### 78.6 异常处理（exception_handler）

```php
public static function exception_handler($e) {
    // 第1步: 正确定位错误文件和行号
    $trace = $e->getTrace();
    if(!empty($trace) && $trace[0]['function'] == 'error_handler') {
        $message = $e->getMessage();
        $file = $trace[0]['args'][2];   // 错误文件
        $line = $trace[0]['args'][3];   // 错误行号
    }else{
        $message = '[程序异常] : '.$e->getMessage();
        $file = $e->getFile();
        $line = $e->getLine();
    }

    // 第2步: 写日志
    log::write("$message File: $file [$line]");

    // 第3步: 根据情况输出
    if(R('ajax', 'R')) {
        // AJAX 请求返回 JSON
        echo json_encode(array('error' => $error));
    }else{
        // 页面请求显示错误页面
        if(DEBUG) {
            self::exception($message, $file, $line, $e->getTraceAsString());
        }else{
            self::sys_error($message, $file, $line);
        }
    }
}
```

**关键特性**:
- 安全过滤：`to_message()` 方法会过滤数据库连接错误信息，防止泄露配置路径
- 只在后台或 DEBUG 模式下显示详细错误信息
- 自动记录错误日志

### 78.7 AJAX / 页面两种错误响应

| 请求类型 | DEBUG=1 | DEBUG=0 |
|---------|---------|---------|
| AJAX 请求 | JSON 含完整堆栈 | JSON 含文件路径和行号 |
| 页面请求 | 渲染 `exception.php` 模板 | 渲染 `sys_error.php` 模板 |
| 致命错误（非后台） | - | `error_die()` 友好提示页面 |

**AJAX 响应格式**:

```json

{"error": "[运行错误] : xxx\nFile: /path/to/file.php [42]\n<br><br>#0 ..."}

// DEBUG=0
{"error": "[程序错误: 请开启调试模式查看详细信息]"}
```

## 79. 日志系统（log.class.php）

LeCMS 日志系统提供多层次的日志记录能力，包括错误日志、跟踪日志和业务日志。

**源码位置**: `d:\phpstudy_pro\WWW\aimuchen100.com\lecms\xiunophp\lib\log.class.php`

### 79.1 日志写入方法

#### `log::write($s, $file)` — 通用日志写入

```php
/**
 * 写入日志
 * @param string $s    写入内容
 * @param string $file 日志文件名（默认: php_error.php）
 */
public static function write($s, $file = 'php_error.php') {
    $file_key = substr($file, 0, -4);  // 去掉 .php 后缀
    // 检查配置开关：$_ENV['_config']['php_error'] 或 $_ENV['_config']['php_error404']
    if( isset($_ENV['_config'][$file_key]) && (int)$_ENV['_config'][$file_key] ){
        $time = isset($_ENV['_time']) ? date('Y-m-d H:i:s', (int)$_ENV['_time']) : date('Y-m-d H:i:s');
        $ip = $_ENV['_ip'];
        $url = self::to_str($_SERVER['REQUEST_URI']);
        $s = self::to_str($s);
        self::write_log('<?php exit;?>'."$time  $ip  $url  $s\r\n", $file);
    }
    return TRUE;
}
```

**日志开关对应关系**:

| 日志类型 | 文件名 | 配置开关 | 说明 |
|---------|--------|---------|------|
| 错误日志 | `php_error.php` | `php_error` | 记录所有错误 |
| 404 日志 | `php_error404.php` | `php_error404` | 记录 404 访问 |

#### `log::write_log($s, $file)` — 底层文件写入

```php
public static function write_log($s, $file) {
    $logfile = LOG_PATH.$file;  // LOG_PATH = ROOT_PATH . 'log/'
    try{
        $fp = fopen($logfile, 'ab+');  // 二进制追加模式
        fwrite($fp, $s);
        fclose($fp);
    }catch(Exception $e) {}
    return TRUE;
}
```

#### `log::trace($s)` — 跟踪调试

```php
/**
 * 跟踪调试（仅 DEBUG 模式下记录）
 * @param string $s 描述信息
 */
public static function trace($s) {
    if(!DEBUG) return;
    empty($_ENV['_trace']) && $_ENV['_trace'] = '';
    $_ENV['_trace'] .= $s.' - '.number_format(microtime(1) - $_ENV['_start_time'], 4)."\r\n";
}
```

#### `log::trace_save($file)` — 保存跟踪记录

```php
/**
 * 保存 trace 到日志文件
 * @param string $file 保存文件名（默认: php_trace.php）
 */
public static function trace_save($file = 'php_trace.php') {
    if(empty($_ENV['_trace'])) return;
    $s = "<?php exit;?>\r\n";
    $s .= $_SERVER['REQUEST_URI']."\r\n";
    $s .= "POST:".print_r($_POST, 1)."\r\n";
    $s .= "SQL:".print_r($_ENV['_sqls'], 1)."\r\n";
    $s .= $_ENV['_trace']."\r\n\r\n";
    self::write_log($s, $file);
}
```

**使用示例**:

```php
log::trace('开始加载内容列表');
// ... 业务代码 ...
log::trace('内容列表加载完成');
// 在控制器析构或 shutdown 中调用
log::trace_save('my_trace.php');
```

#### `log::le_log($s, $file)` — LeCMS 专用日志

```php

    $time = $_ENV['_time'];

    $mtime = date('Y-m-d H:i:s');
    $url = isset($_SERVER['REQUEST_URI']) ? $_SERVER['REQUEST_URI'] : '';
    $logpath = LOG_PATH.'/'.$day;    // log/202607/
    !is_dir($logpath) AND mkdir($logpath, 0777, true);  // 自动创建目录

    if(is_array($s)) $s = serialize($s);
    $s = str_replace(array("\r\n", "\n", "\t"), ' ', $s);
    $s = "<?php exit;?>\t$mtime\t$ip\t$url\t$s\r\n";

    @error_log($s, 3, $logpath."/$file.php");
}
```

### 80.7 lang() 函数详解

**源码位置**: `d:\phpstudy_pro\WWW\aimuchen100.com\lecms\xiunophp\lib\base.func.php` 第 855 行

```php
/**
 * 获取语言包翻译
 * @param string $key 语言包键名
 * @param array  $arr 参数替换数组
 * @return string
 */
function lang($key, $arr = array()) {
    $lang = isset($_SERVER['lang']) ? $_SERVER['lang'] : array();
    if(!isset($lang[$key])) return 'lang['.$key.']';  // 未找到返回 lang[key]
    $s = $lang[$key];
    // 参数替换: {key} → 值
    if(!empty($arr)) {
        foreach($arr as $k=>$v) {
            $s = str_replace('{'.$k.'}', $v, $s);
        }
    }
    return $s;
}
```

**使用示例**:

```php
// 简单翻译

echo lang('username');                // 输出: 用户名

// 带参数替换
// 语言包中定义: 'tpl_file_not_exists' => '模板文件 {tplfile} 不存在'
echo lang('tpl_file_not_exists', array('tplfile' => 'default/index.htm'));
// 输出: 模板文件 default/index.htm 不存在

// 未定义的键
echo lang('undefined_key');           // 输出: lang[undefined_key]
```

> **最佳实践**: 所有面向用户的文本都应该使用 `lang()` 函数，不要硬编码中文。

#### 运行时合并机制

**合并流程** (`core::init_lang()`):

```php
public static function init_lang(){
    $_SERVER['lang'] = array();  // 初始化语言包存储

    // 前台模式
    if( !defined('F_APP_NAME') ){
        // 1. 确定语言: Cookie > 配置 > 默认 zh-cn
        $home_lang = $_ENV['_config']['lang'];  // 默认

        $lang = include LANG_PATH.$home_lang.'.php';
        is_array($lang) && $_SERVER['lang'] = array_merge($_SERVER['lang'], $lang);
    }
}
```

**合并规则**:

```
$_SERVER['lang'] = [
```

### 81.1 后台基类控制器

**源码位置**: `d:\phpstudy_pro\WWW\aimuchen100.com\admin\control\admin_control.class.php`

`admin_control` 继承自 `control` 基类，在构造函数中完成所有初始化工作：

```php
class admin_control extends control {
    public $_uid = 0;          // 当前用户 ID
    public $_user = array();   // 当前用户信息
    public $_group = array();  // 当前用户组信息
    private $data = array();   // 防止重复查询的缓存

    function __construct() {
        // 设置 CSRF Token
        $_ENV['_config']['FORM_HASH'] = form_hash();
        $this->assign('C', $_ENV['_config']);

        // 登录验证
        $r = $this->user->user_token_check();
        if($r['err']){
            $err = 1;
        }else{
            $this->_uid = $r['user']['uid'];
            $this->_user = $r['user'];
            $this->_group = $r['user_group'];
            // 检查用户组权限
            $this->check_user_group();
        }

        // 未登录处理
        if($err) {
            $login_r = $this->admin_safe_login_url(1);
            if(isset($login_r['admin_safe'])){
                $login_url = $login_r['jumpurl'];
            }else{
                $login_url = $login_r;
            }
            if(R('ajax')) {
                $this->message(0, lang('illegal_access'), $login_url);
            }
            exit('<html><body><script>top.location="'.$login_url.'"</script></body></html>');
        }
    }
}
```

### 81.2 登录验证流程

登录验证通过 `user_token_check()` 方法实现，支持 Cookie 和 Session 两种方式：

```

  ├── 解密 token (str_auth 函数)
  ├── 验证 token 是否过期
  ├── 查询用户数据
  ├── 检查用户组状态 (groupid <= 5)
  └── 返回: array('err' => 0/1, 'user' => [...], 'user_group' => [...])
```

**退出登录**:

```php
$this->user->user_token_logout(1);  // 清除 Cookie 中的 token
```

```php
/**
 * 检查用户组权限
 */
protected function check_user_group() {
    // groupid = 1: 超级管理员，跳过检查
    if($this->_group['groupid'] == 1) return;

    // groupid > 5: 被禁用
    if($this->_group['groupid'] > 5) {
        $this->user->user_token_logout(1);
        log::write(lang('access_dis2_log'), 'login_log.php');
        $this->message(0, lang('access_dis2'), -1);
    }
    // 1 < groupid <= 5: 正常用户组，后续通过 purviews JSON 控制菜单
}

/**
 * 检查是否是超级管理员
 */
protected function check_isadmin() {
    if($this->_group['groupid'] != 1) {
        $this->message(0, lang('access_dis1'), -1);
    }
}
```

### 81.5 安全入口机制

LeCMS 后台支持安全入口功能，防止暴力破解后台地址：

```php
/**
 * 获取安全的登录入口
 */
protected function admin_safe_login_url($r = 0){
    $cfg = $this->kv->xget('cfg');
    if(isset($cfg['admin_safe_entrance']) && $cfg['admin_safe_entrance'] && $cfg['admin_safe_auth']){
        // 安全入口已开启
        $login_url = 'index.php?index-login-auth-'.$cfg['admin_safe_auth'];
        $admin_safe_auth = $cfg['admin_safe_auth'];
    }else{
        // 默认登录地址
        $login_url = 'index.php?index-login';
        $admin_safe_auth = '';
    }
    return $login_url;
}
```

**安全入口配置**（后台 → 安全设置）:
- `admin_safe_entrance`: 是否启用安全入口
- `admin_safe_auth`: 安全密钥（用于生成登录 URL）

启用后，只有通过 `index.php?index-login-auth-{密钥}` 才能访问后台登录页。

### 81.6 用户组与权限配置

LeCMS 内置 6 个用户组：

| groupid | 名称 | 说明 |
|---------|------|------|
| 1 | 超级管理员 | 拥有所有权限，跳过权限检查 |
| 2 | 管理员 | 大部分管理权限 |
| 3 | 编辑 | 内容编辑权限 |
| 4 | 作者 | 内容发布权限 |
| 5 | 会员 | 普通用户权限 |
| > 5 | 禁用 | 禁止登录 |

**用户组数据表结构** (`le_user_group`):

| 字段 | 类型 | 说明 |
|------|------|------|
| groupid | int | 用户组 ID（主键、自增） |
| groupname | varchar(20) | 用户组名称 |
| system | tinyint | 是否系统内置（不可删除） |
| purviews | text | 权限配置（JSON 格式） |
| credits | int | 默认积分 |
| post_credits | int | 发帖扣除积分 |
| avatar_max | int | 头像最大尺寸 |

**purviews JSON 格式示例**:

```json
{
    "setting": {
        "title": "系统设置",
        "icon": "fa fa-cogs",
        "href": "",
        "child": [
            {"title": "基本设置", "href": "index.php?setting-index"},
            {"title": "SEO设置", "href": "index.php?setting-seo"}
        ]
    },
    "category": {
        "title": "分类管理",
        "icon": "fa fa-bars",
        "href": "",
        "child": [
            {"title": "分类管理", "href": "index.php?category-index"}
        ]
    }
}
```

> **注意**: `purviews` 字段直接替换默认导航菜单，非超级管理员的菜单完全由此 JSON 控制。
