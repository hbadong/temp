## 10. URL 三种模式

### 10.1 动态模式（默认）

开启条件：`config.inc.php` 中 `'lecms_parseurl' => 0`（默认值）

```
格式: index.php?control-action-key1-value1-key2-value2
简写: index.php?u=control-action-key1-value1-value2
```

**URL 解析示例：**

```
URL: index.php?show-index-cid-1-id-123-page-2

解析结果:
$_GET['control'] = 'show'
$_GET['action']   = 'index'
$_GET['cid']      = '1'
$_GET['id']       = '123'
$_GET['page']     = '2'
```

**Nginx 无需额外配置**，直接通过 `index.php?` 传递参数即可。

**Apache 无需额外配置**，同上。

**PATH_INFO 模式解析**（源码级分析）：

当 URL 为 `http://example.com/index.php/show/index/cid/1/id/123` 时：

```php
// 来自 core.class.php init_get() 第 130-135 行
} elseif (!empty($_SERVER['PATH_INFO'])) {
    $u = $_SERVER['PATH_INFO'];
    // PATH_INFO 值: /show/index/cid/1/id/123
}
```

但 PATH_INFO 模式在 LeCMS 中主要用于框架内部路径解析，前台路由主要使用 `?u=` 参数传递格式。

### 10.2 伪静态模式

开启条件：`config.inc.php` 中 `'lecms_parseurl' => 1`

```php
// install/config.sample.php 第 11 行
'lecms_parseurl' => 0,  // 是否开启前台伪静态，改为 1 启用
```

**分类页 URL：**
```
/分类别名.html          → cate-index-cid=分类ID
/分类别名_2.html        → cate-index-cid=分类ID&page=2
```

**内容页 URL（8种类型）：**

| 类型 | 配置值 | URL 格式 | 示例 | 说明 |
|------|--------|----------|------|------|
| 数字型 | 1 | `/分类ID/内容ID.html` | `/12/123.html` | 纯数字，SEO一般，URL最短 |
| 推荐型 | 2 | `/分类别名/内容ID.html` | `/news/123.html` | 含分类别名，SEO较好，最常用 |
| 别名型 | 3 | `/别名.html` | `/article-alias.html` | 纯别名URL，需维护别名表 |
| 加密型 | 4 | `/加密字符串.html` | `/a1b2c3.html` | 防止ID暴露，需decrypt函数 |
| ID型 | 5 | `/模型ID_内容ID.html` | `/2_123.html` | 跨分类访问，支持多模型 |
| 别名组合 | 6 | `/分类别名/内容别名.html` | `/news/article-alias.html` | 含分类和内容别名，SEO最佳 |
| 灵活型 | 7 | 自定义模板 | `/2024/01/11/123.html` | 支持{ymd}{y}{m}{d}等占位符 |
| HashIDS | 8 | `/HashIDS加密.html` | `/XyZ123.html` | 不可逆加密，安全性最高 |

**各类型详细说明：**

**类型1 - 数字型**（`link_show_type = 1`）
```
URL 格式: /{cid}/{id}.html
示例: /12/123.html
解析: $_GET['cid'] = 12, $_GET['id'] = 123
优点: 实现简单，URL 最短
缺点: 暴露分类 ID，SEO 一般
```

**类型2 - 推荐型**（`link_show_type = 2`）
```
URL 格式: /{cate_alias}/{id}.html
示例: /news/123.html
解析: $cate_arr['news'] = 12 → $_GET['cid'] = 12, $_GET['id'] = 123
优点: 含分类别名，SEO 较好
缺点: 需维护分类别名映射表
```

**类型3 - 别名型**（`link_show_type = 3`）
```
子类型 A（数字组合）: /{cid}_{id}.html
示例: /12_123.html
解析: $_GET['cid'] = 12, $_GET['id'] = 123

子类型 B（内容别名）: /{alias}.html
示例: /my-article.html
解析: 查询 only_alias 表 → $_GET['cid'] = ?, $_GET['id'] = ?
优点: URL 语义化，SEO 好
缺点: 需维护 only_alias 表
```

**类型4 - 加密型**（`link_show_type = 4`）
```
URL 格式: /{encrypted}.html
示例: /a1b2c3.html
解析: decrypt('a1b2c3') → "12_123" → $_GET['cid'] = 12, $_GET['id'] = 123
优点: 隐藏真实 ID，防止爬虫遍历
缺点: 需 decrypt 函数支持
```

**类型5 - ID型**（`link_show_type = 5`）
```
子类型 A（纯数字）: /{id}.html
示例: /123.html
解析: $_GET['mid'] = 2, $_GET['id'] = 123

子类型 B（模型组合）: /{mid}_{id}.html
示例: /2_123.html
解析: mid_check(2) → $_GET['mid'] = 2, $_GET['id'] = 123
优点: 支持跨分类多模型
缺点: URL 中暴露模型 ID
```

**类型6 - 别名组合型**（`link_show_type = 6`）
```
子类型 A（cid_id 组合）: /{cate_alias}/{cid}_{id}.html
示例: /news/12_123.html

子类型 B（内容别名）: /{cate_alias}/{alias}.html
示例: /news/my-article.html
解析: $cate_arr['news'] = 12 → 查 only_alias → $_GET['cid'] = 12, $_GET['id'] = 123
优点: 双别名，SEO 最佳
缺点: 需维护两个别名表
```

**类型7 - 灵活型**（`link_show_type = 7`）
```
配置模板: link_show = 'article/{ymd}/{alias}.html'
支持占位符:
  {cid}       → 分类ID
  {mid}       → 模型ID
  {id}        → 内容ID
  {alias}     → 内容别名
  {cate_alias}→ 分类别名
  {password}  → 加密内容
  {ymd}       → 日期 (20240101)
  {y}         → 年份 (2024)
  {m}         → 月份 (01)
  {d}         → 日期 (01)
  {auth_key}  → 授权密钥
  {hashids}   → HashIDS 加密

示例:
  link_show = 'article/{ymd}/{alias}.html'
  → /article/20240101/my-article.html

  link_show = 'blog/{y}/{m}/{id}.html'
  → /blog/2024/01/123.html
```

**类型8 - HashIDS**（`link_show_type = 8`）
```
URL 格式: /{hashids}.html
示例: /XyZ123.html
解析: hashids_decrypt('XyZ123') → [12, 123] → $_GET['cid'] = 12, $_GET['id'] = 123
优点: 不可逆加密，安全性最高
缺点: 依赖 HashIDS 扩展
```

**Nginx Rewrite 规则：**

```nginx
# nginx.conf 或站点配置文件
server {
    listen 80;
    server_name example.com;
    root /path/to/lecms;
    index index.php;

    # LeCMS 伪静态重写规则
    location / {
        # 排除已存在的文件和目录
        if (-f $request_filename) {
            break;
        }
        if (-d $request_filename) {
            break;
        }

        # 伪静态重写：所有请求转发到 index.php
        rewrite ^/(.+)$ /index.php?rewrite=$1 last;
    }

    # PHP 处理
    location ~ \.php$ {
        fastcgi_pass   127.0.0.1:9000;
        fastcgi_index   index.php;
        fastcgi_param   SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include         fastcgi_params;
    }

    # 静态文件缓存
    location ~* \.(js|css|png|jpg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 7d;
        add_header Cache-Control "public";
    }
}
```

**Apache Rewrite 规则（.htaccess）：**

```apache
# LeCMS 伪静态重写规则 - .htaccess
```

## 11. 伪静态 URL 解析全流程

### 11.1 解析总流程图

```
用户请求: /article/php-tutorial.html
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                      Web 服务器 (Nginx/Apache)                   │
│  rewrite ^/(.+) /index.php?rewrite=$1 last;                    │
│  转换为: /index.php?rewrite=article/php-tutorial.html            │
└─────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                      index.php 入口                             │
```

```php
// lecms/xiunophp/lib/core.class.php 第 123-175 行
public static function init_get() {
    // 伪静态模式：委托给 parseurl_control 处理
    if (!empty($_ENV['_config'][APP_NAME . '_parseurl'])) {
        self::parseurl_control();
    } else {
        // ========== 普通动态模式 ==========

        // 1. 获取原始 URL（三种来源优先级）
        if (isset($_GET['u'])) {
            // 来源1: ?u=control-action-key-value
            $u = $_GET['u'];
            unset($_GET['u']);
        } elseif (!empty($_SERVER['PATH_INFO'])) {
            // 来源2: PATH_INFO（框架内部使用）
            $u = $_SERVER['PATH_INFO'];
        } else {
            // 来源3: QUERY_STRING（直接参数传递）
            $_GET = array();
            $u = $_SERVER["QUERY_STRING"];
        }

        // 2. 清除 URL 后缀（.html）
        $url_suffix = C('url_suffix');
        if ($url_suffix) {
            $suf_len = strlen($url_suffix);
            if (substr($u, -($suf_len)) == $url_suffix) {
                $u = substr($u, 0, -$suf_len);
            }
        }

        // 3. 处理带 & 的参数（兼容非标准 URL）
        // 例如: &page=1&limit=15 → page-1-limit-15
        if (strpos($u, '&') !== false && strpos($u, '=') !== false) {
            $u = str_replace(array('&', '='), '-', $u);
        }

        // 4. 按 - 分割为数组
        $uarr = explode('-', $u);

        // 5. 第1段 → control（控制器名）
        if (isset($uarr[0])) {
            $_GET['control'] = $uarr[0];
            array_shift($uarr);
        }

        // 6. 第2段 → action（方法名）
        if (isset($uarr[0])) {
            $_GET['action'] = $uarr[0];
            array_shift($uarr);
        }

        // 7. 后续段 → 键值对参数（每2段一组）
        $num = count($uarr);
        for ($i = 0; $i < $num; $i += 2) {
            isset($uarr[$i + 1]) && $_GET[$uarr[$i]] = $uarr[$i + 1];
        }
    }

    // ========== 安全校验 ==========

    // 8. control/action 只允许 \w 字符（字母数字下划线），非法则 fallback
    $_GET['control'] = isset($_GET['control']) && preg_match('/^\w+$/', $_GET['control'])
        ? strtolower($_GET['control']) : 'index';
    $_GET['action'] = isset($_GET['action']) && preg_match('/^\w+$/', $_GET['action'])
        ? strtolower($_GET['action']) : 'index';

    // 9. 限制访问特殊控制器（直接转为 404）
    if (in_array($_GET['control'], array('parseurl', 'error404', 'base'))) {
        $_GET['control'] = 'error404';
        $_GET['action'] = 'index';
    }
}
```

**URL 解析执行顺序说明：**

```
优先级: ?u= 参数 > PATH_INFO > QUERY_STRING

1. 优先检查 $_GET['u'] - 最灵活的传递方式
2. 其次检查 $_SERVER['PATH_INFO'] - 框架内部路径
3. 最后使用 $_SERVER['QUERY_STRING'] - 标准查询字符串
```

```php
// lecms/control/parseurl_control.class.php 第 176-226 行
protected function category_url($cfg = array(), $uri = '') {
    // hook: parseurl_control_category_url_before.php

    // 1. 获取分类映射表（alias → cid）
    // 例如: $cate_arr = ['news' => 1, 'blog' => 2, 'help' => 5]
    $cate_arr = array_flip($cfg['cate_arr']);

    // 2. 无后缀 URL 的 301 重定向
    // 例如: /news 访问时，301 到 /news.html
    if (isset($cate_arr[$uri])) {
        http_location($cfg['weburl'] . $uri . $cfg['link_cate_end'], '301');
    }

    // 3. 预设默认控制器
    $_GET['control'] = 'cate';
    $_GET['action'] = 'index';

    $len = strlen($cfg['link_cate_end']);

    // 4. 分类首页 URL: /news.html
    // 匹配逻辑: 去掉后缀 → 查找 alias → 设置 cid
    if (substr($uri, -$len) == $cfg['link_cate_end']) {
        $newurl = substr($uri, 0, -$len);
        if (isset($cate_arr[$newurl])) {
            $_GET['cid'] = (int) $cate_arr[$newurl];
            return true;  // ★ 匹配成功
        }
    }

    // 5. 分类分页 URL: /news_2.html
    // 匹配逻辑: 去掉分页后缀 → 按分页符分割 → 查找 alias → 设置 cid + page
    if (strpos($uri, $cfg['link_cate_page_pre']) !== FALSE) {
        $len = strlen($cfg['link_cate_page_end']);
        if (substr($uri, -$len) == $cfg['link_cate_page_end']) {
            $newurl = substr($uri, 0, -$len);
            $u_arr = explode($cfg['link_cate_page_pre'], $newurl);

            if (isset($cate_arr[$u_arr[0]])) {
                $_GET['cid'] = (int) $cate_arr[$u_arr[0]];
                if (isset($u_arr[1])) {
                    if ($this->integer_check($u_arr[1])) {
                        $_GET['page'] = $u_arr[1];
                    } else {
                        core::error404();  // 分页参数非法 → 404
                    }
                }
                return true;  // ★ 匹配成功
            }
        }
    }

    // hook: parseurl_control_category_url_after.php

    // 6. 匹配失败，清理预设
    unset($_GET['control']);
    unset($_GET['action']);
    return false;
}
```

```
第3步: 预设 control='cate', action='index'

第4步: 检查后缀 .html → $newurl = 'news_2'

第5步: 检查分页符 _ → $u_arr = ['news', '2']

第7步: integer_check('2') → true → $_GET['page'] = 2

第8步: return true → 匹配成功
```

```php
// lecms/control/parseurl_control.class.php 第 229-434 行
protected function content_url($cfg = array(), $uri = '') {
    // hook: parseurl_control_content_url_before.php

    // 1. 去掉 URL 后缀
    $link_show_end = $cfg['link_show_end'];
    $link_show_end_len = strlen($link_show_end);
    $cate_arr = array_flip($cfg['cate_arr']);
    $newurl = $link_show_end_len ? substr($uri, 0, -$link_show_end_len) : $uri;

    // 2. 预设控制器
    $_GET['control'] = 'show';
    $_GET['action'] = 'index';

    // hook: parseurl_control_content_url_switch_before.php

    // 3. 按 link_show_type 分发到不同的解析逻辑
    switch ($cfg['link_show_type']) {

        // ========== 类型1: 数字型 ==========
        case 1:
            // hook: parseurl_control_content_url_switch_1_before.php
            // URL: /12/123.html → $newurl: "12/123"
            // 正则: /(\d+)\/(\d+)/ → $mat[1]=12, $mat[2]=123
            preg_match("/^(\d+)\/(\d+)$/i", $newurl, $mat);
            if (isset($mat[2])) {
                $_GET['cid'] = $mat[1];   // 分类ID
                $_GET['id'] = $mat[2];    // 内容ID
                return true;
            }
            // hook: parseurl_control_content_url_switch_1_after.php
            break;

        // ========== 类型2: 推荐型 ==========
        case 2:
            // hook: parseurl_control_content_url_switch_2_before.php
            // URL: /news/123.html → $newurl: "news/123"
            // 正则: /(\w+)\/(\d+)/ → $mat[1]=news, $mat[2]=123
            preg_match("/^(\w+)\/(\d+)$/i", $newurl, $mat);
            if (isset($mat[2]) && isset($cate_arr[$mat[1]])) {
                $_GET['cid'] = $cate_arr[$mat[1]];  // 通过别名查 cid
                $_GET['id'] = $mat[2];
                return true;
            }
            // hook: parseurl_control_content_url_switch_2_after.php
            break;

        // ========== 类型3: 别名型 ==========
        case 3:
            // hook: parseurl_control_content_url_switch_3_before.php
            // 子类型A: 数字组合 /12_123.html
            preg_match("/^(\d+)\_(\d+)$/i", $newurl, $mat);
            if (isset($mat[2])) {
                $_GET['cid'] = $mat[1];
                $_GET['id'] = $mat[2];
                return true;
            }
            // 子类型B: 别名查询 /article-alias.html
            elseif (preg_match('/^[a-zA-Z0-9-_]+$/i', $newurl)) {
                // 从 only_alias 表查询 alias → cid, id
                $row = $this->only_alias->get($newurl);
                if (!empty($row)) {
                    $_GET['cid'] = $row['cid'];
                    $_GET['id'] = $row['id'];
                    return true;
                }
            }
            // hook: parseurl_control_content_url_switch_3_after.php
            break;

        // ========== 类型4: 加密型 ==========
        case 4:
            // hook: parseurl_control_content_url_switch_4_before.php
            // URL: /a1b2c3.html → decrypt('a1b2c3') → "12_123"
            $newurl = decrypt($newurl);
            preg_match("/^(\d+)\_(\d+)$/i", $newurl, $mat);
            if (isset($mat[2])) {
                $_GET['cid'] = $mat[1];
                $_GET['id'] = $mat[2];
                return true;
            }
            // hook: parseurl_control_content_url_switch_4_after.php
            break;

        // ========== 类型5: ID型 ==========
        case 5:
            // hook: parseurl_control_content_url_switch_5_before.php
            // 子类型A: 纯数字 /123.html（默认模型 mid=2）
            if ($this->integer_check($newurl)) {
                $_GET['mid'] = 2;
                $_GET['id'] = $newurl;
                return true;
            }
            // 子类型B: 模型ID组合 /2_123.html
            preg_match("/^(\d+)\_(\d+)$/i", $newurl, $mat);
            if (isset($mat[2])) {
                if (!$this->mid_check($mat[1], $cfg)) { core::error404(); }
                $_GET['mid'] = $mat[1];
                $_GET['id'] = $mat[2];
                return true;
            }
            // hook: parseurl_control_content_url_switch_5_after.php
            break;

        // ========== 类型6: 别名组合型 ==========
        case 6:
            // hook: parseurl_control_content_url_switch_6_before.php
            // URL: /news/article-alias.html → $newurl: "news/article-alias"
            $u_arr = explode('/', $newurl);
            if (isset($u_arr[1]) && isset($cate_arr[$u_arr[0]])) {
                $cid = (int) $cate_arr[$u_arr[0]];
                // 子类型A: cid_id 组合 /news/12_123.html
                preg_match("/^(\d+)\_(\d+)$/i", $u_arr[1], $mat);
                if (isset($mat[2]) && $mat[1] == $cid) {
                    $_GET['cid'] = $mat[1];
                    $_GET['id'] = $mat[2];
                    return true;
                }
                // 子类型B: 别名查询 /news/article-alias.html
                elseif (preg_match('/^[a-zA-Z0-9-_]+$/i', $u_arr[1])) {
                    $row = $this->only_alias->get($u_arr[1]);
                    if (!empty($row) && $row['cid'] == $cid) {
                        $_GET['cid'] = $row['cid'];
                        $_GET['id'] = $row['id'];
                        return true;
                    }
                }
            }
            // hook: parseurl_control_content_url_switch_6_after.php
            break;

        // ========== 类型7: 灵活型（自定义模板）==========
        case 7:
            // hook: parseurl_control_content_url_switch_7_before.php
            // 配置示例: link_show = 'article/{ymd}/{alias}.html'
            // 将模板占位符转换为正则命名捕获组

            // 步骤1: preg_quote 转义模板中的特殊字符
            $quote = preg_quote($cfg['link_show'], '#');

            // 步骤2: 占位符 → 正则命名捕获组 映射
            $quote = strtr($quote, array(
                '\{cid\}'      => '(?<cid>\d+)',          // 分类ID
                '\{mid\}'      => '(?<mid>\d+)',          // 模型ID
                '\{id\}'       => '(?<id>\d+)',           // 内容ID
                '\{alias\}'    => '(?<alias>\w+)',        // 内容别名
                '\{cate_alias\}' => '(?<cate_alias>\w+)', // 分类别名
                '\{password\}' => '(?<password>\w+)',     // 加密内容
                '\{ymd\}'      => '(?<ymd>\d{8})',        // 日期: 20240101
                '\{y\}'        => '(?<y>\d{4})',          // 年份: 2024
                '\{m\}'        => '(?<m>\d{2})',          // 月份: 01
                '\{d\}'        => '(?<d>\d{2})',          // 日期: 01
                '\{auth_key\}' => '(?<auth_key>\w+)',     // 授权密钥
                '\{hashids\}'  => '(?<hashids>\w+)',      // HashIDS
            ));

            // hook: parseurl_control_content_url_switch_7_quote_after.php

            // 步骤3: 正则匹配
            // 例如: link_show='article/{ymd}/{alias}.html'
            // 生成正则: article/(?<ymd>\d{8})/(?<alias>\w+)\.html
            preg_match('#' . $quote . '#', $uri, $mat);

            if ($mat) {
                // 步骤4: 提取日期参数
                isset($mat['ymd']) AND $_GET['date_ymd'] = $mat['ymd'];
                isset($mat['y'])   AND $_GET['date_y']   = $mat['y'];
                isset($mat['m'])   AND $_GET['date_m']   = $mat['m'];
                isset($mat['d'])   AND $_GET['date_d']   = $mat['d'];

                // 步骤5: auth_key 安全验证
                $auth_key = $_ENV['_config']['auth_key'];
                if (isset($mat['auth_key']) && $mat['auth_key'] != substr(md5($auth_key), 0, 6)) {
                    core::error404();
                }

                // 步骤6: 按优先级解析参数组合
                if (isset($mat['cid']) && isset($mat['id'])) {
                    // {cid}/{id} 组合
                    $_GET['cid'] = $mat['cid'];
                    $_GET['id'] = $mat['id'];
                    return true;
                } elseif (isset($mat['mid']) && isset($mat['id']) && $this->mid_check($mat['mid'], $cfg)) {
                    // {mid}/{id} 组合
                    $_GET['mid'] = $mat['mid'];
                    $_GET['id'] = $mat['id'];
                    return true;
                } elseif (isset($mat['cate_alias']) && isset($mat['id'])) {
                    // {cate_alias}/{id} 组合
                    $_GET['cid'] = isset($cate_arr[$mat['cate_alias']]) ? $cate_arr[$mat['cate_alias']] : 0;
                    empty($_GET['cid']) && core::error404();
                    $_GET['id'] = $mat['id'];
                    return true;
                } elseif (isset($mat['password'])) {
                    // {password} 加密内容
                    $newurl = decrypt($mat['password']);
                    preg_match("/^(\d+)\_(\d+)$/i", $newurl, $mat);
                    if (isset($mat[2])) {
                        $_GET['cid'] = $mat[1];
                        $_GET['id'] = $mat[2];
                        return true;
                    }
                } elseif (isset($mat['alias'])) {
                    // {alias} 别名查询
                    // 先尝试 cid_id 组合
                    preg_match("/^(\d+)\_(\d+)$/i", $mat['alias'], $mat2);
                    if (isset($mat2[2])) {
                        $_GET['cid'] = $mat2[1];
                        $_GET['id'] = $mat2[2];
                        return true;
                    }
                    // 从 only_alias 表查询
                    $row = $this->only_alias->get($mat['alias']);
                    if (!empty($row)) {
                        $_GET['cid'] = $row['cid'];
                        $_GET['id'] = $row['id'];
                        return true;
                    }
                } elseif (isset($mat['hashids'])) {
                    // {hashids} 解密
                    $newurl = hashids_decrypt($mat['hashids']);
                    if (is_array($newurl) && isset($newurl[1])) {
                        $_GET['cid'] = $newurl[0];
                        $_GET['id'] = $newurl[1];
                        return true;
                    }
                }

                // 步骤7: 兜底解析（单模型纯ID）
                // 例如: article/id.html → 只有 {id} 无 {cid}
                if (isset($mat['id']) && $this->integer_check($mat['id'])) {
                    $u_arr = explode('/', $uri);
                    // 验证 URL 前缀与模板一致
                    if (substr($cfg['link_show'], 0, strlen($u_arr[0])) == $u_arr[0]) {
                        $_GET['mid'] = 2;
                        $_GET['id'] = $mat['id'];
                        return true;
                    }
                }
            }
            // hook: parseurl_control_content_url_switch_7_after.php
            break;

        // ========== 类型8: HashIDS ==========
        case 8:
            // hook: parseurl_control_content_url_switch_8_before.php
            // URL: /XyZ123.html → hashids_decrypt('XyZ123') → [12, 123]
            $newurl = hashids_decrypt($newurl);
            if (is_array($newurl) && isset($newurl[1])) {
                $_GET['cid'] = $newurl[0];
                $_GET['id'] = $newurl[1];
                return true;
            }
            // hook: parseurl_control_content_url_switch_8_after.php
            break;

        // hook: parseurl_control_content_url_switch_end.php
    }

    // hook: parseurl_control_content_url_after.php

    // 4. 匹配失败，清理预设
    unset($_GET['control']);
    unset($_GET['action']);
    return false;
}
```

```php
protected function other_url() {
    // 伪静态模式下，访问动态 URL 的回退解析
    // URL 格式: /index.php?control-action-key-value

    if (isset($_GET['u'])) {
        $u = $_GET['u'];
        unset($_GET['u']);
    } elseif (!empty($_SERVER['PATH_INFO'])) {
        $u = R('PATH_INFO', 'S');
    } else {
        $_GET = array();
        $u = R('QUERY_STRING', 'S');
    }

    // 清除 URL 后缀
    $url_suffix = C('url_suffix');
    if ($url_suffix) {
        $suf_len = strlen($url_suffix);
        if (substr($u, -($suf_len)) == $url_suffix) $u = substr($u, 0, -$suf_len);
    }

    // 解析额外参数（&key=value 格式）
    $uarr = explode('&', $u);
    $u = $uarr[0];
    if (count($uarr) > 1) {
        array_shift($uarr);
        foreach ($uarr as $v) {
            $varr = explode('=', $v);
            $_GET[$varr[0]] = isset($varr[1]) ? urldecode($varr[1]) : '';
        }
    }

    // 按 - 分割
    $uarr = explode('-', $u);
    if (count($uarr) < 2) { core::error404(); }

    // 控制器
    if (isset($uarr[0])) {
        $_GET['control'] = empty($uarr[0]) ? 'index' : strtolower($uarr[0]);
        array_shift($uarr);
    }

    // 方法
    if (isset($uarr[0])) {
        $_GET['action'] = empty($uarr[0]) ? 'index' : strtolower($uarr[0]);
        array_shift($uarr);
    }

    // 伪静态下，禁止直接访问已被伪静态化的控制器首页
    $dis_control = array('index', 'show', 'cate', 'tag');
    if (in_array($_GET['control'], $dis_control) && $_GET['action'] == 'index') {
        core::error404();
    }

    // 参数
    $num = count($uarr);
    for ($i = 0; $i < $num; $i += 2) {
        isset($uarr[$i + 1]) && $_GET[$uarr[$i]] = $uarr[$i + 1];

}
```

```php
private function page_check($param) {
    // 格式: page_N（N 为正整数）
    // 返回: N 或 false
    if (empty($param)) {
        return false;
    } else {
        preg_match('/^page_([1-9]\d*)$/', $param, $mat);
        if (isset($mat[1])) {
            return $mat[1];
        } else {
            return false;
        }
    }
}

// 正整数参数验证
private function integer_check($param) {
    // 正则: /^[1-9]\d*$/（不含前导零的正整数）
    if (empty($param)) {
        return false;
    } elseif (preg_match($this->integer_pattern, $param)) {
        return true;
    } else {
        return false;
    }
}

// 模型 ID 验证（模型 ID > 1，排除单页模型）
private function mid_check($mid, $cfg) {
    if ($mid > 1 && isset($cfg['table_arr'][$mid])) {
        return true;
    } else {
        return false;
    }
}
```

### 13.2 路由匹配原理（Hook 机制）

路由匹配**不通过硬编码实现**，而是通过框架的 **Hook（钩子）机制** 由插件完成。

**Hook 机制工作流程：**

```php
// lecms/xiunophp/lib/core.class.php 第 544-566 行
public static function process_hook($matches) {
    $str = "\n";
    if (!is_dir(PLUGIN_PATH) || !empty($_ENV['_config']['plugin_disable'])) return $str;

    $plugins = core::get_plugins();
    if (empty($plugins['enable'])) return $str;

    $plugin_enable = array_keys($plugins['enable']);
    foreach ($plugin_enable as $p) {
        // 检查插件主目录下的 hook 文件
        $file = PLUGIN_PATH . $p . '/' . $matches[1];
        if (is_file($file)) {
            $s = file_get_contents($file);
            $str .= self::clear_code($s);
        }
        // 检查插件 hook/ 子目录下的 hook 文件
        $file = PLUGIN_PATH . $p . '/hook/' . $matches[1];
        if (is_file($file)) {
            $s = file_get_contents($file);
            $str .= self::clear_code($s);
        }
    }
    return $str;
}
```

**路由匹配在 `parseurl_control` 中的 Hook 插入点：**

```
parseurl_control::index() 中的相关 Hook:

1. parseurl_control_index_other_before.php  ← 路由匹配在此插入
2. parseurl_control_index_other_after.php

在 other_url() 方法中:
3. parseurl_control_other_url_before.php
4. parseurl_control_other_url_after.php
```

**路由匹配插件的实现原理：**

```php
// 插件文件: lecms/plugin/route/hook/parseurl_control_index_other_before.php
// （这是路由匹配的实际实现逻辑，需通过插件提供）

<?php
// 伪代码：路由匹配逻辑
if (!empty($_ENV['_config']['route_open']) && !empty($_ENV['_route'])) {
    $request_uri = $_SERVER['REQUEST_URI'];
    // 去掉查询字符串
    $request_uri = parse_url($request_uri, PHP_URL_PATH);
    // 去掉前后斜杠
    $request_uri = trim($request_uri, '/');

    foreach ($_ENV['_route'] as $pattern => $target) {
        // 正则匹配
        if (preg_match('#^' . $pattern . '$#i', $request_uri, $matches)) {
            // 反向引用替换
            $target = preg_replace_callback('/\$(\d+)/', function($m) use ($matches) {
                return isset($matches[$m[1]]) ? $matches[$m[1]] : '';
            }, $target);

            // 解析目标 URL: 'show-index-cid-2-id-123'
            $tarr = explode('-', $target);
            if (isset($tarr[0])) {
                $_GET['control'] = $tarr[0];
                array_shift($tarr);
            }
            if (isset($tarr[0])) {
                $_GET['action'] = $tarr[0];
                array_shift($tarr);
            }
            // 键值对参数
            $num = count($tarr);
            for ($i = 0; $i < $num; $i += 2) {
                isset($tarr[$i + 1]) && $_GET[$tarr[$i]] = $tarr[$i + 1];
            }
            return true;  // 匹配成功，停止后续解析
        }
    }
}
```

### 13.3 通配符与反向引用规则

**路由规则语法：**

```php
$_ENV['_route'] = array(
    // 基本格式: '正则表达式' => 'control-action-key1-value1-key2-value2'

    // ========== 固定路径（无参数）==========
    'about\.html$' => 'cate-index-cid-5',

    // ========== 单参数 ==========
    // (\d+) 捕获第一组 → $1
    'article/(\d+)\.html$' => 'show-index-cid-2-id-$1',

    // ========== 多参数 ==========
    // (\d+) 捕获第一组 → $1
    // (\d+) 捕获第二组 → $2
    'news/(\d+)_(\d+)\.html$' => 'show-index-cid-$1-id-$2',

    // ========== 通配符 ==========
    // .* 匹配任意字符（贪婪）
    'docs/(.*)\.html$' => 'show-index-cid-3-alias-$1',

    // ========== 字符类 ==========
    // [a-z] 小写字母
    // [a-zA-Z0-9-] 字母数字横线
    'tag-([a-zA-Z0-9-]+)\.html$' => 'tag-index-name-$1',

    // ========== 可选匹配 ==========
    // ? 表示前一个字符可选
    'product(s)?/(\d+)\.html$' => 'show-index-cid-4-id-$2',

    // ========== 命名捕获（PHP 7+）==========
    // (?P<name>...) 命名捕获组
    'user/(?P<uid>\d+)\.html$' => 'my-index-uid-$1',
);
```

**反向引用（$1, $2...）替换规则：**

```php
// 路由匹配时的反向引用替换过程

// 1. 用户请求: /article/123.html
// 2. 正则匹配: 'article/(\d+)\.html$' → $matches = ['article/123.html', '123']
// 3. 反向引用替换:
//    '$1' → '123'
//    原始目标: 'show-index-cid-2-id-$1'
//    替换后:   'show-index-cid-2-id-123'
// 4. 解析控制/方法/参数:
//    control = 'show'
//    action  = 'index'
//    cid     = '2'
//    id      = '123'
```

**正则表达式转义注意事项：**

```php
// URL 中的特殊字符需要转义
'about\.html$'    // . → \. （. 在正则中匹配任意字符）
'help\-center\.html$'  // - → \- （在字符类外的 - 需要转义）
'产品/(.*)\.html$'    // / 不需要转义
```

## 13.5 常见问题 (FAQ)

### 13.5.1 路由不生效

**问题：** 配置了路由规则但访问时仍然显示404

**解决方案：**
1. 检查 `config.inc.php` 中 `route_open` 是否设置为 `1`
2. 清理 `runcache/` 目录下的所有缓存文件
3. 检查正则表达式是否正确，使用在线正则测试工具验证
4. 确保路由规则在 `$_ENV['_route']` 数组内

### 13.5.2 正则匹配错误

**问题：** URL 无法匹配到预期的路由规则

**解决方案：**
1. 检查正则表达式的分隔符，建议使用 `#` 而不是 `/`
2. 确保正则末尾有 `$` 锚定结束位置
3. 检查反向引用编号是否正确（`$1`, `$2` 从1开始）

**示例对比：**
```php
// 错误：使用了 / 作为分隔符，且缺少结束锚定
'article/(\d+)/' => 'show-index-cid-2-id-$1',

// 正确：使用 # 作为分隔符，添加结束锚定
'article/(\d+)\.html$' => 'show-index-cid-2-id-$1',
```

### 13.5.3 控制器不存在

**问题：** 路由指向的控制器文件不存在

**解决方案：**
1. 确保控制器文件命名格式正确：`{control}_control.class.php`
2. 确保控制器类名格式正确：`class {control}_control extends base_control`
3. 检查控制器文件是否位于正确的目录 `lecms/control/`

### 13.5.4 缓存问题

**问题：** 修改路由规则后页面仍然显示旧的路由结果

**解决方案：**
```bash
# 清理所有缓存
rm -rf runcache/*.php
rm -rf runcache/lecms_control/*.php

# 如果开启了 DEBUG 模式，可以临时开启调试来刷新缓存
# 修改 config.inc.php 中 'debug' => '1'
```

### 13.5.5 路由优先级冲突

**问题：** 多个路由规则匹配到了同一个 URL

**解决方案：**
1. 将更具体的路由规则放在前面
2. 使用更精确的正则表达式

**示例：**
```php
// 错误：通用规则在前，具体规则无法匹配
'product/(\d+)\.html$' => 'show-index-cid-3-id-$1',  // 会匹配所有
'product/ebook/(\d+)\.html$' => 'show-index-cid-4-id-$1',  // 永远不会匹配

// 正确：具体规则在前
'product/ebook/(\d+)\.html$' => 'show-index-cid-4-id-$1',
'product/(\d+)\.html$' => 'show-index-cid-3-id-$1',
```

### 13.5.6 路由目标格式错误

**问题：** 路由匹配成功但控制器报错

**解决方案：**
```php
// 检查目标 URL 格式是否正确
// 正确格式: control-action-key1-value1-key2-value2
'show-index-cid-2-id-123'    // ✓ 正确
'cate-index-cid-5'           // ✓ 正确
'show index cid 2'            // ✗ 错误（不能有空格）
'show-index-cid=2-id=123'     // ✗ 错误（不能有等号）
```

### 13.5.7 伪静态和自定义路由共存问题

**问题：** 同时开启伪静态和自定义路由时出现冲突

**解决方案：**
```
执行顺序:
1. parseurl_control::index() 中的系统 URL 解析
2. → 系统解析不匹配
3. → 进入 other_url()
4. → Hook: parseurl_control_index_other_before.php
5. → 自定义路由匹配（$_ENV['_route']）

自定义路由是最后执行的回退机制，
因此只要系统 URL 能匹配的，会优先走系统解析。
```

## 13.7 最佳实践

### 13.7.1 路由命名规范

1. **使用语义化 URL**
   ```php
   // 推荐
   'about-us\.html$' => 'about-index'
   
   // 不推荐
   'page5\.html$' => 'about-index'
   ```

2. **使用连字符分隔单词**
   ```php
   // 推荐
   'our-team\.html$' => 'team-index'
   
   // 不推荐
   'ourteam\.html$' => 'team-index'
   ```

3. **保持 URL 简洁**
   ```php
   // 推荐
   'products\.html$' => 'product-index'
   
   // 不推荐
   'list-of-all-products\.html$' => 'product-index'
   ```

### 13.7.2 性能优化

1. **将常用路由放在前面**
   ```php
   $_ENV['_route'] = array(
       // 常用路由放前面，优先匹配
       'index\.html$' => 'index-index',
       'about\.html$' => 'about-index',
       'contact\.html$' => 'contact-index',
       
       // 较少访问的路由放后面
       'sitemap\.xml$' => 'sitemap-index',
   );
   ```

2. **避免过于复杂的正则**
   ```php
   // 简单优先
   'help\.html$' => 'help-index',
   
   // 避免过度复杂的正则
   '^(?:(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{6,})$\.html$'
   ```

3. **使用精确匹配**
   ```php
   // 使用 ^ 和 $ 锚定（虽然路由匹配已自动添加锚定）
   'about\.html$' => 'about-index'
   
   // 避免过度匹配
   'about' => 'about-index'  // 会匹配 aboutus.html
   ```

### 13.7.3 SEO 优化

1. **包含关键词**
   ```php
   // 推荐：URL 包含关键词
   'seo-course\.html$' => 'course-index-category-seo'
   
   // 不推荐
   'page10\.html$' => 'course-index-category-seo'
   ```

2. **使用静态化 URL**
   ```php
   // 推荐
   'tutorial/php-basics\.html$' => 'tutorial-index-name-php-basics'
   
   // 不推荐
   'tutorial\?id=10' => 'tutorial-index-id-10'
   ```

## 14. URL 生成器完整源码

### 14.1 `urls_model` 所有方法

```php
// lecms/model/urls_model.class.php 完整源码

class urls extends model {
    private $data = array();

    function __construct() {
        $this->table = '';
        $this->pri = array('id');
        $this->maxid = 'id';
    }

    // 获取 cfg 配置
    function __get($var) {
        if ($var == 'cfg') {
            return $this->cfg = $this->runtime->xget();
        } else {
            return parent::__get($var);
        }
    }

    // ========== 首页分页 URL ==========
    public function index_url($mid = 2, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?index-index-mid-2-page-{page}.html
            return $this->cfg['weburl'] . 'index.php?index-index-mid-'
                . $mid . '-page-{page}' . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: index_{mid}_{page}.html
            if ($mid > 2) {
                return $this->cfg['weburl'] . 'index_' . $mid . '_{page}'
                    . $_ENV['_config']['url_suffix'];
            } else {
                return $this->cfg['weburl'] . 'index_{page}'
                    . $_ENV['_config']['url_suffix'];
            }
        }
    }

    // ========== 模型页 URL ==========
    public function model_url($table = 'table', $mid = 2, $page = FALSE, $extra = array()) {
        if (!isset($this->cfg)) {
            $this->cfg = $extra['cfg'];
        }
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?model--mid-2-page-{page}.html
            $s = $page ? '-page-{page}' : '';
            return $this->cfg['weburl'] . 'index.php?model--mid-'
                . $mid . $s . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: {table}/{page}/
            $s = $page ? '/page_{page}' : '';
            return $this->cfg['weburl'] . $table . $s . '/';
        }
    }

    // ========== 搜索页 URL ==========
    public function search_url($mid = 2, $keyword = '', $page = FALSE, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?search--mid-2-keyword-{keyword}-page-{page}.html
            $s = $page ? '-page-{page}' : '';
            return $this->cfg['weburl'] . 'index.php?search--mid-'
                . $mid . '-keyword-' . urlencode($keyword) . $s
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: search/{keyword}/page_{page}/
            $s = $page ? '/page_{page}' : '';
            if ($mid > 2) {
                return $this->cfg['weburl'] . 'search/mid_' . $mid . '/'
                    . urlencode($keyword) . $s . '/';
            } else {
                return $this->cfg['weburl'] . 'search/'
                    . urlencode($keyword) . $s . '/';
            }
        }
    }

    // ========== 搜索入口 URL ==========
    public function so_url($extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?search-so.html
            return $this->cfg['weburl'] . 'index.php?search-so'
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: so.html
            return $this->cfg['weburl'] . 'so'
                . $_ENV['_config']['url_suffix'];
        }
    }

    // ========== 用户中心 URL ==========
    public function user_url($action = 'index', $control = 'user', $page = false, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        $allow_control = array('user', 'my');
        if (!in_array($control, $allow_control)) {
            return '';  // 只允许 user 和 my 控制器
        }

        $s = '';
        if ($page) {
            $s .= $page ? '-page-{page}' : '';
        }
        // 附加参数
        if ($extra) {
            foreach ($extra as $k => $v) {
                $s .= '-' . $k . '-' . $v;
            }
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?user-login.html
            return $this->cfg['weburl'] . 'index.php?'
                . $control . '-' . $action . $s
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: user-login.html
            return $this->cfg['weburl'] . $control . '-' . $action . $s
                . $_ENV['_config']['url_suffix'];
        }
    }

    // ========== 热门标签 URL ==========
    public function hot_tag_url($extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?tag-top.html
            return $this->cfg['weburl'] . 'index.php?tag-top'
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: 使用 link_tag_top 配置
            return $this->cfg['weburl'] . $this->cfg['link_tag_top'];
        }
    }

    // ========== 全部标签 URL ==========
    public function tag_all_url($mid = 2, $page = FALSE, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        $s = '';
        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?tag-all-mid-2-page-{page}.html
            $mid > 2 && $s .= '-mid-' . $mid;
            $page && $s .= '-page-{page}';
            $url = $this->cfg['weburl'] . 'index.php?tag-all' . $s
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: tag_all/{mid}/{page}/
            $mid > 2 && $s .= '/' . $mid;
            $page && $s = empty($s) ? '/{page}' : $s . '_{page}';
            $url = $this->cfg['weburl'] . 'tag_all' . $s . '/';
        }

        return $url;
    }

    // ========== 属性内容 URL ==========
    public function flag_url($mid = 2, $flag = 1, $page = FALSE, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?flags--mid-2-flag-tuijian-page-{page}.html
            $s = $page ? '-page-{page}' : '';
            return $this->cfg['weburl'] . 'index.php?flags--mid-'
                . $mid . '-flag-' . $flag . $s
                . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: flags/{mid}_{flag}/page_{page}/
            return $this->cfg['weburl'] . 'flags/'
                . ($mid > 2 ? $mid . '_' . $flag : $flag)
                . ($page ? '/page_{page}' : '') . '/';
        }
    }

    // ========== 个人空间 URL ==========
    public function space_url($uid = 0, $page = FALSE, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }
        if (empty($uid)) { return ''; }

        if (empty($_ENV['_config']['lecms_parseurl'])) {
            // 动态模式: index.php?space--uid-123-page-{page}.html
            $s = $page ? '-page-{page}' : '';
            return $this->cfg['weburl'] . 'index.php?space--uid-'
                . $uid . $s . $_ENV['_config']['url_suffix'];
        } else {
            // 伪静态模式: 使用 link_space_pre/end 配置
            return $this->cfg['weburl'] . $this->cfg['link_space_pre']
                . $uid . ($page ? '/page_{page}' : '')
                . $this->cfg['link_space_end'];
        }
    }

    // ========== 用户头像 URL ==========
    public function user_avatar($uid = 0, $avatar_file = '', $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }

        if ($uid) {
            if ($avatar_file && substr($avatar_file, 0, 14) != 'upload/avatar/') {
                $avatar = 'upload/avatar/' . $avatar_file;
            } else {
                // 默认路径: upload/avatar/012/123.png
                $avatar = 'upload/avatar/'
                    . substr(sprintf("%09d", $uid), 0, 3) . '/'
                    . $uid . '.png';
            }

            if (is_file(ROOT_PATH . $avatar)) {
                return $this->cfg['weburl'] . $avatar;
            } else {
                if (isset($extra['user'])) {
                    $user = $extra['user'];
                } else {
                    $user = $this->user->get($uid);
                }
                if (isset($user['avatar']) && $user['avatar']
                    && is_file(ROOT_PATH . $user['avatar'])) {
                    return $this->cfg['weburl'] . $user['avatar'];
                }
                return $this->cfg['weburl'] . 'static/img/avatar.png';
            }
        } else {
            return $this->cfg['weburl'] . 'static/img/avatar.png';
        }
    }

    // ========== 附件下载 URL ==========
    public function attach_url($mid = 0, $aid = 0, $extra = array()) {
        if (isset($this->cfg['url_path']) && !empty($this->cfg['url_path'])) {
            $this->cfg['weburl'] = $this->cfg['webdir'];
        }
        // 附件不做伪静态
        return $this->cfg['weburl'] . 'index.php?attach--mid-'
            . $mid . '-id-' . $aid . $_ENV['_config']['url_suffix'];
    }
```

### 14.2 `category_model::category_url()` 完整实现

```php
// lecms/model/category_model.class.php 第 552-602 行
public function category_url(&$cate, $page = FALSE, $extra = array()) {
    $url = '';
    $cid = isset($cate['cid']) ? (int) $cate['cid'] : 0;
    $alias = isset($cate['alias']) ? $cate['alias'] : '';

    // 相对 URL 支持
    if ((isset($this->cfg['url_path']) && !empty($this->cfg['url_path']))
        || (isset($extra['url_path']) && !empty($extra['url_path']))) {
        unset($extra['url_path']);
        $this->cfg['weburl'] = $this->cfg['webdir'];
    }

    if (empty($cid) || empty($alias)) {
        return '';  // cid 和 alias 不能为空
    }

    $lecms_parseurl = empty($_ENV['_config']['lecms_parseurl']) ? 0 : 1;

    if (empty($lecms_parseurl)) {
        // 动态模式: index.php?cate--cid-{cid}-page-{page}.html
        $url .= $this->cfg['weburl'] . 'index.php?cate--cid-'
            . $cid . ($page ? '-page-{page}' : '');
    } else {
        // 伪静态模式
        if ($page) {
            // 分页: /{alias}_{page_prefix}{page}{page_suffix}
            $url .= $this->cfg['weburl'] . $alias
                . $this->cfg['link_cate_page_pre'] . '{page}';
        } else {
            // 首页: /{alias}
            $url .= $this->cfg['weburl'] . $alias;
        }
    }

    // 附加参数
    if ($extra) {
        foreach ($extra as $k => $v) {
            if (empty($lecms_parseurl)) {
                // 动态模式附加参数: -key-value
                $url .= '-' . $k . '-' . $v;
            } else {
                // 伪静态模式附加参数: /key-value
                $url .= '/' . $k . '-' . $v;
            }
        }
    }

    // URL 后缀
    if (empty($lecms_parseurl)) {
        // 动态模式: .html
        $url .= $_ENV['_config']['url_suffix'];
    } else {
        if ($page) {
            // 分页后缀: _2.html
            $url .= $this->cfg['link_cate_page_end'];
        } else {
            // 首页后缀: .html
            $url .= $this->cfg['link_cate_end'];
        }
    }

    return $url;
}
```

## 16. 路由系统总结

### 16.1 核心要点

1. **三种 URL 模式**：动态模式（默认）、伪静态模式、自定义路由模式
2. **8 种内容页 URL 格式**：灵活应对不同 SEO 需求，支持数字、别名、加密、灵活型、HashIDS 等
3. **完整的 URL 解析链**：站点地图 → 分类 → 内容 → 标签 → 搜索 → 评论 → 首页分页 → 标签集合 → 用户 → 模型 → 属性 → 空间 → 动态回退 → 自定义路由
4. **Hook 插件机制**：路由匹配、控制器执行、视图渲染均可通过 Hook 扩展
5. **URL 生成器**：统一的 `urls_model` 提供所有类型 URL 的生成方法
6. **控制器编译缓存**：原始控制器 + Hook 注入 → 编译缓存到 `runcache/`
7. **安全过滤**：control/action 只允许 `\w` 字符，拦截特殊控制器
8. **301 重定向**：无后缀 URL 自动重定向到带后缀版本

### 16.2 关键配置项

```php
// 伪静态总开关

// URL 全局后缀

// 内容页 URL 格式类型 (1-8)
```

### 16.4 动态模式 vs 伪静态模式对比

| 对比维度 | 动态模式 | 伪静态模式 |
|----------|----------|-----------|

### 16.5 路由系统特性

1. **双模式运行**：支持动态 URL 和伪静态 URL 两种模式，通过 `lecms_parseurl` 配置项切换
2. **8 种内容 URL 格式**：灵活应对不同 SEO 需求
3. **完整的 URL 解析链**：分类→内容→标签→搜索→评论→模型→属性，覆盖所有页面类型
4. **URL 后缀可配置**：支持 `.html`、`.htm`、无后缀等
5. **自定义路由支持**：通过 `route.inc.php` 配置自定义规则，正则匹配 + 反向引用
6. **Hook 插件机制**：路由匹配、控制器执行等关键节点均有 Hook 扩展点

### 16.6 学习路径
