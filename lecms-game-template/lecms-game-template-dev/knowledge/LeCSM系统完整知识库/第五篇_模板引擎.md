## 21. 模板编译流程（9步）

### 21.1 编译流程

```
模板文件 (.htm)
    ↓
view::display() 发起渲染
    ↓
view::tpl_process() 模板编译（9个步骤）
    ↓
写入编译缓存 (runcache/lecms_view/)
    ↓
include 编译后的 PHP 文件
    ↓
输出 HTML
```

### 21.2 九步编译详解

```php
private function tpl_process($tpl_file) {
    $s = file_get_contents($tpl_file);

    // 第1步: 解析 {inc:} 包含标签
    $s = preg_replace_callback('#\{inc\:([\w|\/\.]+)\}#',
                               array($this, 'process_inc'), $s);

    // 第2步: 解析 {hook:} Hook标签
    $s = preg_replace_callback('#\{hook\:([\w\.]+)\}#',
                               array('core', 'process_hook'), $s);

    // 第3步: 解析 {php} PHP代码
    $s = preg_replace('#\{php\}(.*?)\{\/php\}#s', '<?php \\1 ?>', $s);

    // 第4步: 解析 {block:} Block标签
    $s = preg_replace_callback(
        '#\{block\:([a-zA-Z_]\w*)\040?([^\n\}]*?)\}(.*?){\/block}#s',
        array($this, 'process_block'), $s);

    // 第5步: 解析 {loop:} 循环标签
    while(preg_match('#\{loop\:\$'.$reg_arr.'(?:\040\$[a-zA-Z_]\w*){1,2}\}.*?\{\/loop\}#s', $s))
        $s = preg_replace_callback('#\{loop\:(\$'.$reg_arr.'(?:\040\$[a-zA-Z_]\w*){1,2})\}(.*?)\{\/loop\}#s',
                                   array($this, 'process_loop'), $s);

    // 第6步: 解析 {if:} 条件标签
    while(preg_match('#\{if\:[^\n\}]+\}.*?\{\/if\}#s', $s))
        $s = preg_replace_callback('#\{if\:([^\n\}]+)\}(.*?)\{\/if\}#s',
                                   array($this, 'process_if'), $s);

    // 第7步: 解析变量 {$var} 和 {@expr}
    $s = preg_replace('#\{\@([^\}]+)\}#', '<?php echo(\\1); ?>', $s);
    $s = preg_replace_callback('#\{(\$'.$reg_arr.')\}#',
                              array($this, 'process_vars'), $s);

    // 第8步: 解析 {lang:} 语言标签
    $s = preg_replace_callback('#\{lang\:([\w\.]+)\}#',
                              array($this, 'process_lang'), $s);

    // 第9步: 代码压缩（可选）
    if(defined('CODE_COMPRESS') && CODE_COMPRESS == 1 && DEBUG == 0) {
        $s = str_replace(array("\r\n", "\n", "\t"), '', $s);
        $s = preg_replace("/\s(?=\s)/","\\1",$s);
        $s = str_replace("> <","><",$s);
    }

    // 组合模板
    $head_str = empty($this->head_arr) ? '' : implode("\r\n", $this->head_arr);
    $s = "<?php defined('APP_NAME') || exit('Access Denied'); $head_str\r\n?>$s";

    return $s;
}
```

### 21.3 模板缓存路径

```php
private function get_tplfile($filename) {
    $view_dir = APP_NAME.($_ENV['_view_diy'] ? '_view_diy' : '_view').'/';
    $php_file = RUNTIME_PATH.$view_dir.$_ENV['_theme'].','.$filename.'.php';

    if(!is_file($php_file) || DEBUG) {
        // 编译模板
        $tpl_file = core::get_original_file($filename, VIEW_PATH.$_ENV['_theme'].'/');
        if($tpl_file) {
            FW($php_file, $this->tpl_process($tpl_file));
        }
    }

    return $php_file;
}
```

**缓存文件路径示例：**
```
模板: view/default/index.htm
    ↓ 编译
缓存: runcache/lecms_view/default,index.htm.php
```

### 21.4 模板编译策略

LeCMS 模板引擎采用 **"编译一次，多次执行"** 的策略，通过将模板编译为 PHP 代码并缓存，实现接近原生 PHP 的性能。

**编译触发条件**:

```php
if(!is_file($php_file) || DEBUG) {
    // 重新编译: 缓存文件不存在 或 DEBUG 模式开启
    $tpl_file = core::get_original_file($filename, VIEW_PATH.$_ENV['_theme'].'/');
    if($tpl_file) {
        FW($php_file, $this->tpl_process($tpl_file));
    }
}
```

| 条件 | DEBUG=0（生产模式） | DEBUG=1（开发模式） |
|------|-------------------|-------------------|
| 缓存文件存在 | 直接使用缓存 | 强制重新编译 |
| 缓存文件不存在 | 编译并缓存 | 编译（不缓存持久化） |
| 模板源文件修改 | 需手动删除缓存 | 自动检测到变更 |

**编译缓存清理策略**:

```php
// 模板修改后需清理的缓存目录
_rmdir(RUNTIME_PATH.'lecms_view/'.$theme, 1);  // 前台模板编译缓存
_rmdir(RUNTIME_PATH.'admin_view/', 1);         // 后台模板编译缓存
_rmdir(RUNTIME_PATH.'core_lang/', 1);          // 框架语言包缓存
_rmdir(RUNTIME_PATH.'lang/', 1);               // 业务语言包缓存
```

### 21.5 主题覆盖机制

LeCMS 支持多主题切换和模板文件覆盖，通过 `$_ENV['_theme']` 控制当前使用的主题目录。

**主题切换**:

```php
// 后台切换主题后，$_ENV['_theme'] 被更新
$_ENV['_theme'] = 'default';  // 或 'mobile', 'jiaoyu', 'justnews'
```

**模板文件查找优先级**:

```
get_original_file('index.htm', VIEW_PATH . $_ENV['_theme'] . '/')
  │
  ├── 1. 插件覆盖: plugin/{插件名}/{APP_NAME}/view/{主题}/{模板}
  ├── 2. 插件覆盖: plugin/{插件名}/view/{主题}/{模板}
  ├── 3. 插件覆盖: plugin/{插件名}/view/{模板}
  ├── 4. 核心模板: view/{主题}/{模板}
  └── 5. 返回 FALSE（模板不存在）
```

**主题目录结构**:

```
view/
├── default/                  ← 默认主题
│   ├── index.htm
│   ├── article_show.htm
│   ├── article_list.htm
│   ├── inc-header.htm
│   ├── inc-footer.htm
│   ├── style/
│   │   ├── css/
│   │   └── js/
│   └── user/
│       ├── index.htm
│       └── login.htm
├── mobile/                   ← 移动端主题
├── jiaoyu/                   ← 教育主题
└── justnews/                 ← 新闻主题
```

**DIY 模板模式** (`_view_diy`):

```php
// 当 $_ENV['_view_diy'] 为 true 时，编译结果中插入 DIY 标记
if($_ENV['_view_diy']) {
    $this->block_id++;
    $before .= '<span block_diy="before" block_id="'.$this->block_id.'"></span>';
    $after .= '<span block_diy="after" block_id="'.$this->block_id.'"></span>';
}
```

DIY 标记用于可视化编辑器的定位，允许在后台直接编辑模板中的 Block 区域。

## 22. 模板标签完整语法

### 22.1 变量标签

#### 普通变量输出 `{$var}`

```html
<!-- 简单变量 -->
<h1>{$cfg[webname]}</h1>

<!-- 数组元素 -->
<p>{$gdata[title]}</p>
<img src="{$v[pic][0]}" />

<!-- 多维数组 -->
<span>{$v[user][username]}</span>
```

**编译后：**
```php
<h1><?php echo isset($cfg['webname']) ? $cfg['webname'] : ''; ?></h1>
<p><?php echo isset($gdata['title']) ? $gdata['title'] : ''; ?></p>
```

#### 运算输出 `{@expr}`

```html
<!-- 数学运算 -->
<p>总计: {@$v[views] + 100}</p>
<p>价格: {@$price * 0.8}</p>

<!-- 字符串处理 -->
<h1>{@mb_substr($v[title], 0, 20)}</h1>

<!-- 三元运算 -->
<p>{@$v[status] ? '已发布' : '草稿'}</p>

<!-- 函数调用 -->
<span>{@date('Y-m-d', $v[dateline])}</span>
```

**编译后：**
```php
<p>总计: <?php echo($v['views'] + 100); ?></p>
<p>价格: <?php echo($price * 0.8); ?></p>
```

### 22.2 循环标签 `{loop:}`

```html
<!-- 一维数组循环 -->
<ul>
{loop:$list $v}
    <li>{$v[title]}</li>
{/loop}
</ul>

<!-- 键值循环 -->
{loop:$list $k $v}
    <div data-id="{$k}">{$v}</div>
{/loop}

<!-- 多维数组 -->
{loop:$cate_list $cate}
    <div class="category">
        <h3>{$cate[name]}</h3>
        {loop:$cate[article] $article}
            <p>{$article[title]}</p>
        {/loop}
    </div>
{/loop}
```

**编译后：**
```php
<ul>
<?php if(isset($list) && is_array($list)) { foreach($list as $v) { ?>
    <li><?php echo isset($v['title']) ? $v['title'] : ''; ?></li>
<?php }} ?>
</ul>
```

### 22.3 条件标签 `{if:}`

```html
<!-- 简单 if -->
{if:$user[uid]}
    <p>欢迎，{$user[username]}</p>
{/if}

<!-- if-else -->
{if:$type == 'article'}
    <i class="fa fa-file-text"></i>
{else}
    <i class="fa fa-file"></i>
{/if}

<!-- 多条件 -->
{if:$is_top && $is_recommend}
    <span class="badge">推荐</span>
{elseif:$is_top}
    <span class="badge">置顶</span>
{else}
    <span class="badge">普通</span>
{/if}
```

**编译后：**
```php
<?php if($user['uid']) { ?>
    <p>欢迎，<?php echo isset($user['username']) ? $user['username'] : ''; ?></p>
<?php } ?>
```

### 22.4 包含标签 `{inc:}`

```html
<!-- 包含公共头部 -->
{inc:header.htm}

<!-- 包含公共底部 -->
{inc:footer.htm}

<!-- 包含子目录模板 -->
{inc:user/header.htm}
```

**编译后：**
```php
<?php include ROOT_PATH.'view/default/inc-header.htm'; ?>
```

**注意：** inc 引入的文件名不能用 `-`，只能用 `_`

```html
<!-- 正确 -->
{inc:sidebar_tags.htm}

<!-- 错误 -->
{inc:sidebar-tags.htm}
```

### 22.5 Block 标签 `{block:}`

```html
<!-- 内容列表 -->
{block:list cid="1" mid="2" limit="10" orderby="id" orderway="-1"}
    {loop:$data[list] $v}
        <a href="{$v[url]}">{$v[subject]}</a>
    {/loop}
{/block}

<!-- 分类树 -->
{block:category_tree}
    {loop:$category $v}
        <a href="{$v[url]}">{$v[name]}</a>
    {/loop}
{/block}

<!-- 全局内容块（每个页面只能有一个） -->
{block:global_show show_prev_next="1" dateformat="Y-m-d"}{/block}
<!-- 之后通过 $gdata 访问 -->
<h1>{$gdata[title]}</h1>
```

### 22.6 语言标签 `{lang:}`

```html
<p>{lang:welcome}</p>
<span>{lang:submit}</span>
<a>{lang:login}</a>
```

**编译后：**
```php
<p><?php echo '欢迎访问'; ?></p>
```

### 22.7 Hook 标签 `{hook:}`

```html
<!-- 在模板中插入 Hook 点 -->
<div class="sidebar">
    {hook:sidebar_top}

    <!-- 侧边栏内容 -->

    {hook:sidebar_bottom}
</div>

<!-- 用于插件扩展 -->
{hook:article_show_bottom}
```

### 22.8 PHP 代码 `{php}`

```html
<!-- 执行 PHP 代码 -->
{php}
    $time = date('Y-m-d H:i:s');
    echo "当前时间: $time";
{/php}
```

**编译后：**
```php
<?php
    $time = date('Y-m-d H:i:s');
    echo "当前时间: $time";
?>
```

### 24.3 自定义 Block 开发

```php
<?php
defined('ROOT_PATH') || exit;

/**
 * 自定义内容列表 Block
 *
 * 参数说明：
 * @param int cid 分类 ID
 * @param int limit 显示数量
 * @param string orderby 排序字段
 * @param int life 缓存时间（秒）
 *
 * @return array
 */
function block_my_custom($conf) {
    global $run;

    // hook block_my_custom_before.php

    // 获取参数
    $cid = isset($conf['cid']) ? intval($conf['cid']) : 0;
    $limit = isset($conf['limit']) ? intval($conf['limit']) : 10;
    $orderby = isset($conf['orderby']) ? $conf['orderby'] : 'id';
    $orderway = isset($conf['orderway']) && $conf['orderway'] == 1 ? 1 : -1;
    $life = isset($conf['life']) ? intval($conf['life']) : 0;

    // hook block_my_custom_conf_after.php

    // 缓存处理
    $cache_key = $life ? md5('my_custom'.serialize(array($cid, $limit, $orderby, $orderway))) : '';
    if($cache_key) {
        $cache_data = $run->runtime->get_block_data_cache($cache_key);
        if($cache_data) {
            return $cache_data;
        }
    }

    // 构建查询条件
    $where = array();
    if($cid > 0) {
        $where['cid'] = $cid;
    }

    // 查询数据
    $list = $run->cms_content->find_fetch(
        $where,
        array($orderby => $orderway),
        0,
        $limit
    );

    // hook block_my_custom_list_arr_after.php

    // 设置返回值
    $return = array(
        'list' => $list,
        'count' => count($list),
    );

    // 写入缓存
    if($cache_key) {
        $run->runtime->set_block_data_cache($cache_key, $return, $life);
    }

    // hook block_my_custom_after.php

    return $return;
}
```

## 28. 模板安全机制

### 28.1 APP_NAME 安全检查

**实现位置：** `view.class.php` 第9步编译

```php
$head_str = empty($this->head_arr) ? '' : implode("\r\n", $this->head_arr);
$s = "<?php defined('APP_NAME') || exit('Access Denied'); $head_str\r\n?>$s";
```

**工作原理：**

```php
<?php defined('APP_NAME') || exit('Access Denied');
// ... Block 函数定义
// ... 全局变量赋值
?>
<!-- 模板 HTML 内容 -->
```

**安全性分析：**

1. **防止直接访问编译文件：**
   - 如果直接通过 URL 访问 `runcache/lecms_view/default,index.htm.php`
   - `APP_NAME` 常量未定义，`defined('APP_NAME')` 返回 false
   - `|| exit('Access Denied')` 执行，终止脚本

2. **必须在入口文件中定义：**
   ```php
   // index.php（入口文件）
   define('APP_NAME', 'lecms');
   define('ROOT_PATH', dirname(__FILE__) . '/');
   require ROOT_PATH . 'xiunophp/xiunophp.php';
   ```

### 28.2 其他安全机制

#### PHP 标签清理

```php
// 第3步编译时清理已有 PHP 标签
$s = preg_replace('#(?:\<\?.*?\?\>|\<\?.*)#s', '', $s);
```

**作用：** 防止模板中包含恶意 PHP 代码，统一通过 `{php}` 标签管理。

#### 变量 isset 保护

```php
// 所有 {$var} 输出都自动包裹 isset 检查
<?php echo(isset($v['title']) ? $v['title'] : ''); ?>
```

**作用：** 防止 Notice 级别的 PHP 错误暴露系统信息。

#### 参数转义

```php
// Block 参数值通过 addslashes 转义
$config_arr[strtolower($m[1][$k])] = addslashes($v);
```

**作用：** 防止模板 Block 参数中的特殊字符导致 SQL 注入。

#### 文件名限制

```php
// inc 模板文件名限制为 (英文 数字 _ .)
// 正则: #\{inc\:([\w\|/\.]+)\}#
```

**作用：** 防止路径穿越攻击。

#### 排序字段白名单

```php

$orderby = isset($conf['orderby']) && in_array($conf['orderby'],
    array('id', 'dateline', 'lasttime', 'comments')) ? $conf['orderby'] : 'id';
```

### 28.5 变量转义机制详解

LeCMS 模板引擎设计了 **5 层变量输出安全机制**：

#### 第 1 层: 安全头保护

```php
<?php defined('APP_NAME') || exit('Access Denied');
```
每份编译后的模板文件都以这行开头，防止直接访问编译后的 `.php` 文件。

#### 第 2 层: isset 变量保护

```php
// 所有 {$xxx} 变量输出都包裹 isset 检查
<?php echo(isset($vars) ? $vars : ''); ?>
```
如果模板变量未通过 `assign()` 传递，输出空字符串而非报错。

#### 第 3 层: PHP 标签清除

```php
// 第 3 步编译时清除原生 PHP 标签
$s = preg_replace('#(?:\<\?.*?\?\>|\<\?.*)#s', '', $s);
```
防止模板中包含恶意 PHP 代码。

#### 第 4 层: 变量格式化

```php
// rep_vars() 方法将模板变量格式转为合法 PHP 语法
$s = preg_replace('#\[(\w+)\]#', "['\\1']", $s);      // $arr[a] → $arr['a']
$s = preg_replace('#\[\"(\w+)\"\]#', "['\\1']", $s);   // $arr["a"] → $arr['a']
$s = preg_replace('#\[\'(\d+)\'\]#', '[\\1]', $s);    // $arr['0'] → $arr[0]
```

#### 第 5 层: htmlspecialchars 转义

```php
// {$var} 输出时通过 htmlspecialchars 转义（view.class.php 中）
$s = preg_replace_callback('#\{(\$'.$reg_arr.')\}#', array($this, 'process_vars'), $s);
// process_vars 内部: echo htmlspecialchars($vars, ENT_QUOTES, 'UTF-8')
```

### 28.6 表达式输出（{@...}）安全说明

`{@expr}` 语法直接输出 PHP 表达式结果，**不进行任何转义**：

```html
<!-- 安全: 输出纯数字 -->
<p>浏览量: {@$v[views] + 100}</p>

<!-- 安全: 使用 date() 格式化 -->
<span>{@date('Y-m-d', $v[dateline])}</span>

<!-- 危险: 直接输出用户输入的内容 -->
<p>{@$_GET['keyword']}</p>  <!-- XSS 风险！ -->

<!-- 安全写法: 先转义再输出 -->
<p>{@htmlspecialchars($_GET['keyword'], ENT_QUOTES, 'UTF-8')}</p>
```

**安全规则**:
- 使用 `{@...}` 时，开发者自行保证输出内容的安全性
- 涉及用户输入的场景，必须手动调用 `htmlspecialchars()`
- 建议优先使用 `{$var}`（自动转义），仅在必要时使用 `{@expr}`

### 28.7 模板路径校验

**inc 模板文件名限制**:

```php
// 正则: #\{inc\:([\w\|/\.]+)\}#
// 只允许: 字母、数字、下划线、竖线、斜杠、点号
```

这防止了路径穿越攻击，例如 `{inc:../../etc/passwd}` 会被正则拒绝。

**display() 方法的安全限制**:

```php
public function display($filename = null) {
    $_ENV['_tplname'] = is_null($filename)
        ? $_GET['control'].'_'.$_GET['action'].'.htm'
        : $filename;
    // 模板名只能包含 (英文 数字 _ .)
}
```

**模板查找通过 `get_original_file()`**:

```php
$tpl_file = core::get_original_file($filename, VIEW_PATH.$_ENV['_theme'].'/');
```
`get_original_file()` 仅在同名目录下查找文件，不会遍历上级目录。

### A. 模板编译正则表达式汇总

| 步骤 | 标签 | 探测正则 | 替换正则 |
|------|------|----------|----------|
| 1 | `{inc:}` | `#\{inc\:([\w\|/\.]+)\}#` | 回调 `process_inc` |
| 2 | `{hook:}` | `#\{hook\:([\w\.]+)\}#` | 回调 `core::process_hook` |
| 3 | `{php}` | `#\{php\}(.*?)\{\/php\}#s` | `<?php \1 ?>` |
| 4 | `{block:}` | `#\{block\:([a-zA-Z_]\w*)\040?([^\n\}]*?)\}(.*?){\/block}#s` | 回调 `process_block` |
| 5 | `{loop:}` | `#\{loop\:\$reg_arr(?:\040\$[a-zA-Z_]\w*){1,2}\}.*?\{\/loop\}#s` | 回调 `process_loop` |
| 6 | `{if:}` | `#\{if\:[^\n\}]+\}.*?\{\/if\}#s` | 回调 `process_if` |
| 7a | `{@expr}` | `#\{\@([^\}]+)\}#` | `<?php echo(\1); ?>` |
| 7b | `{$var}` | `#\{(\$reg_arr)\}#` | 回调 `process_vars` |
| 8 | `{lang:}` | `#\{lang\:([\w\.]+)\}#` | 回调 `process_lang` |

**注：** 第5、6步使用 `while` 循环确保嵌套标签被正确编译。

### B. 变量正则表达式详解

```php
$reg_arr = '[a-zA-Z_]\w*(?:\[\w+\]|\[\'\w+\'\]|\[\"\w+\"\]|\[\$[a-zA-Z_]\w*\])*';
```

**合法变量示例：**
```
$abc
$abc[a]
$abc['a']
$abc["a"]
$abc[a][b]
$abc['a']['b']
$abc[0]
$abc[$i]
$v[user][username]
$cfg[webname]
```

**不合法变量示例：**
```
$abc[$a[b]]     // 下标不能是表达式
$123abc         // 不能以数字开头
$abc-[a]        // 不能包含 -
$abc [a]        // 变量和下标间不能有空格
```

### C. Block 文件命名与函数命名规范

```
文件: block_{name}.lib.php
函数: block_{name}($conf)
```

**global_ 前缀约定：**
- 文件名为 `block_global_{name}.lib.php`
- 函数名为 `block_global_{name}($conf)`
- 数据输出到 `$gdata` 变量（在模板头部执行）
- 通常用于页面核心数据（内容详情、分类列表等）

### D. 缓存机制说明

**Block 数据缓存流程：**
```php
// 1. 生成缓存键
$cache_params = array($cid, $mid, $limit, $orderby, ...);
$cache_key = $life ? md5('block_name'.serialize($cache_params)) : '';

// 2. 读取缓存
if($cache_key) {
    $cache_data = $run->runtime->get_block_data_cache($cache_key);
    if($cache_data) return $cache_data;
}

// 3. 写入缓存
if($cache_key) {
    $run->runtime->set_block_data_cache($cache_key, $ret, $life);
}
```

**缓存表结构：**
- 表名：`lecms_runtime`
- 字段：`name`（缓存键）、`value`（序列化数据）、`life`（过期时间）

## 32. 模板函数速查补充

### 32.1 自定义函数定义方式

在 LeCMS 模板中，可以通过以下方式定义和使用自定义函数：

**方式一：通过插件 Hook 定义全局函数**

```php
// plugin/my_functions/hook/view_class_tpl_process_func.php
<?php
defined('ROOT_PATH') || exit;

// 相对时间格式化
function friend_date($timestamp) {
    $second = time() - $timestamp;
    if ($second <= 0) return '刚刚';
    if ($second < 60) return $second . '秒前';
    $minute = intval($second / 60);
    if ($minute < 60) return $minute . '分钟前';
    $hour = intval($second / 3600);
    if ($hour < 24) return $hour . '小时前';
    $day = intval($second / 86400);
    if ($day < 30) return $day . '天前';
    return date('Y-m-d', $timestamp);
}
```

**方式二：在模板中直接调用**

```html
<span>{@friend_date($v[dateline])}</span>
<span>{@format_price($v[price])}</span>
<span>{@mb_substr($v[title], 0, 20, 'utf-8')}</span>
```

### 32.2 常用自定义函数速查表

| 函数名 | 功能 | 示例 |
|--------|------|------|
| `friend_date($timestamp)` | 相对时间 | `{@friend_date($v[dateline])}` |
| `format_price($amount, $currency)` | 金额格式化 | `{@format_price($v[price], '¥')}` |
| `xcutstr($string, $length)` | 字符串截取 | `{@xcutstr($v[title], 20)}` |
| `get_heat_level($views)` | 热度等级 | `{@get_heat_level($v[views])}` |
| `highlight_keyword($content, $keyword)` | 关键词高亮 | `{@highlight_keyword($v[content], $keyword)}` |
| `format_size($bytes)` | 文件大小格式化 | `{@format_size($v[filesize])}` |
| `remove_emoji($content)` | 去除表情 | `{@remove_emoji($v[content])}` |

### 32.3 注意事项

1. **函数命名规范**：自定义函数应使用小写字母和下划线，如 `format_price`、`get_heat_level`
2. **避免冲突**：不要定义与 PHP 内置函数同名的函数
3. **安全性**：用户输入的数据必须经过过滤和转义
4. **缓存考虑**：频繁调用的复杂函数应考虑添加缓存
