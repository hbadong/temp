## 54. 案例1：友情链接插件完整实现

### 54.1 目录结构

```
lecms/plugin/le_links/
├── conf.php                                # 插件配置文件
├── install.php                             # 安装脚本（建表 + 注册）

├── links_control.class.php                 # 后台控制器层
```

### 54.2 conf.php — 插件元信息

```php
<?php
return array(
    'name' => '友情链接',                    // 插件名称
    'brief' => '友情链接管理插件',           // 简要说明
    'version' => '1.0.0',                    // 当前版本号
    'cms_version' => '3.0.0',               // 最低兼容 CMS 版本
    'update' => '2025-01-04',               // 更新日期
    'author' => '你的名字',                  // 作者
    'authorurl' => 'https://example.com',   // 作者链接
    'setting' => '',                         // 插件设置项（JSON 格式）
);
```

**说明：**
- `cms_version`：插件要求的最低 CMS 版本，低于此版本将禁止安装。
- `setting`：可选的插件设置项，用于在后台设置页面中展示表单。
- 返回的数组会被框架解析为插件注册信息。

### 54.3 install.php — 安装脚本

```php
<?php
defined('ROOT_PATH') || exit;

$tableprefix = $_ENV['_config']['db']['master']['tablepre'];

$sql = "CREATE TABLE IF NOT EXISTS ".$tableprefix."links (
  id int(10) unsigned NOT NULL AUTO_INCREMENT,
  name varchar(80) NOT NULL DEFAULT '' COMMENT '链接名称',
  url varchar(255) NOT NULL DEFAULT '' COMMENT '链接地址',
  orderby smallint(5) unsigned NOT NULL DEFAULT '0' COMMENT '排序权重',
  dateline int(10) unsigned NOT NULL DEFAULT '0' COMMENT '添加时间戳',
  PRIMARY KEY (id),
  KEY idx_orderby (orderby)
) ENGINE=MyISAM DEFAULT CHARSET=utf8 COLLATE=utf8_general_ci;";

$this->db->query($sql);
```

**说明：**
- `$this->db`：安装脚本中可直接使用 `$this->db` 执行 SQL。
- 表名使用 `$_ENV['_config']['db']['master']['tablepre']` 获取当前前缀。
- `CREATE TABLE IF NOT EXISTS` 保证重复安装不报错。
- 安装脚本在插件点击"安装"时执行一次。

### 54.4 数据模型

```php
<?php
defined('ROOT_PATH') or exit;

class links extends model {

    function __construct() {
        $this->table = 'links';          // 表名（不含前缀，框架自动拼接）
        $this->pri = array('id');        // 主键字段数组
        $this->maxid = 'id';             // 自增主键字段
    }

    /**
     * 带智能翻页的列表查询
     * 当偏移量超过总数一半时，反向查询避免全表扫描
     */
    public function list_arr($where, $orderby, $orderway, $start, $limit, $total) {
        if($start > 1000 && $total > 2000 && $start > $total/2) {
            // 翻到了最后一页，反向查找更快
            $orderway = -$orderway;
            $newstart = $total - $start - $limit;
            if($newstart < 0) {
                $limit += $newstart;
                $newstart = 0;
            }
            $list_arr = $this->find_fetch($where, array($orderby => $orderway),
                                         $newstart, $limit);
            return array_reverse($list_arr, TRUE);
        } else {
            return $this->find_fetch($where, array($orderby => $orderway),
                                     $start, $limit);
        }
    }
}
```

**说明：**
- 模型类继承 `model` 基类，只需指定 `$this->table`、`$this->pri`、`$this->maxid`。
- `find_fetch()` 方法会自动根据 `$this->table` 和 `$this->pri` 拼接 SQL。
- `list_arr()` 是一个高级优化：当翻页到数据后半段时，从末尾反向查询，避免 `LIMIT` 在大偏移量时的全表扫描问题。

### 54.5 后台控制器

```php
<?php
defined('ROOT_PATH') or exit;

class links_control extends admin_control {

    /**
     * 列表页
     */
    public function index() {
        $this->display();       // 渲染 links_index.htm 模板
    }

    /**
     * 接口：获取链接列表（供前端表格 AJAX 调用）
     * 返回 JSON 格式分页数据
     */
    public function get_list(){
        $page  = intval($_REQUEST['page']) ?: 1;
        $limit = intval($_REQUEST['limit']) ?: 15;

        $where = array();
        $total = $this->links->find_count($where);

        $list = $this->links->list_arr($where, 'id', -1,
                                     ($page-1)*$limit, $limit, $total);

        echo json_encode(array(
            'code'  => 0,
            'msg'   => '',
            'count' => $total,
            'data'  => $list,
        ));
        exit;
    }

    /**
     * 添加/编辑页面
     * GET 请求显示表单，POST 请求保存数据
     */
    public function add() {
        if(empty($_POST)) {
            // 显示添加表单
            $data = array('orderby' => 0);
            $this->assign('data', $data);
            $this->display('links_set.htm');
        } else {
            // 处理添加请求
            $name = trim(strip_tags(R('name', 'P')));
            $url  = trim(R('url', 'P'));

            empty($name) && E(1, '链接名称不能为空');
            empty($url)  && E(1, '链接地址不能为空');

            $data = array(
                'name'    => $name,
                'url'     => $url,
                'dateline' => $_ENV['_time'],
                'orderby' => intval(R('orderby', 'P')),
            );

            $id = $this->links->create($data);
            if(!$id) {
                E(1, '添加失败');
            }
            E(0, '添加成功');
        }
    }

    /**
     * 编辑操作（与 add 类似，GET 显示表单，POST 保存更新）
     */
    public function edit() {
        if(empty($_POST)) {
            $id = intval(R('id'));
            $data = $this->links->get($id);
            if(empty($data)) {
                $this->message(0, '数据不存在', -1);
            }
            $this->assign('data', $data);
            $this->display('links_set.htm');
        } else {
            $id   = intval(R('id', 'P'));
            $name = trim(strip_tags(R('name', 'P')));
            $url  = trim(R('url', 'P'));

            empty($id)   && E(1, '参数错误');
            empty($name) && E(1, '链接名称不能为空');
            empty($url)  && E(1, '链接地址不能为空');

            $data = array(
                'id'      => $id,
                'name'    => $name,
                'url'     => $url,
                'orderby' => intval(R('orderby', 'P')),
            );

            if(!$this->links->update($data)) {
                E(1, '更新失败');
            }
            E(0, '更新成功');
        }
    }

    /**
     * 删除操作
     */
    public function del() {
        $id = (int)R('id', 'P');
        empty($id) && E(1, '参数错误');

        if(!$this->links->delete($id)) {
            E(1, '删除失败');
        }
        E(0, '删除成功');
    }
}
```

**说明：**
- 控制器类继承 `admin_control`，在后台访问时 `index.php?links-index` 自动路由到此。
- `E()` 函数用于快速输出 JSON 结果（code + msg），前台请求则跳转。
- `$this->message()` 用于后台消息提示并跳转。
- `R('name', 'P')`：安全获取 POST 参数，`'P'` 表示 POST，`'G'` 表示 GET。
- `admin_control` 基类自动注入 `$this->links` 模型对象（驼峰转换）。

### 54.6 Block 标签

```php
<?php
defined('ROOT_PATH') || exit;

function block_links($conf) {
    global $run;

    $where = array();

    // hook block_links_before.php

    $orderby  = isset($conf['orderby']) &&
                in_array($conf['orderby'], array('id', 'orderby')) ?
                $conf['orderby'] : 'id';
    $orderway = isset($conf['orderway']) && $conf['orderway'] == 1 ? 1 : -1;
    $start    = _int($conf, 'start');
    $limit    = _int($conf, 'limit', 10);

    $arr = $run->links->find_fetch($where, array($orderby => $orderway),
                                   $start, $limit);

    // hook block_links_after.php

    return $arr;
}
```

**说明：**
- Block 函数返回一个数组，供模板标签 `{block:links ...}` 使用。
- `$conf` 参数是标签属性值数组，例如 `{block:links limit=5 orderby=orderby}`。
- `_int($conf, 'limit', 10)`：安全获取整数配置，第三个参数为默认值。
- `orderby` 做了白名单过滤，防止 SQL 注入。
- Hook 点 `block_links_before.php` 和 `block_links_after.php` 允许其他插件在查询前后扩展逻辑。
- Block 函数内的查询结果会被 `filecache/` 目录自动缓存，减少数据库查询。

### 54.7 后台菜单注入

```php
<?php
defined('ROOT_PATH') or exit;

// 文件命名规则：{控制器名}_control_init_{hook点}.php
// 框架在初始化 links_control 之前，自动加载此文件

$menu['menuInfo']['plugin']['child'][] = array(
    'title'  => '友情链接',
    'href'   => 'index.php?links-index',
    'icon'   => 'fa fa-link',
    'target' => '_self'
);
```

**说明：**
- 这是 LeCMS 的 **Hook 机制**（钩子机制）的典型应用。
- 文件名格式：`{控制器}_control_init_{事件点}.php`，框架在初始化对应控制器前自动 `include` 该文件。
- 通过向 `$menu['menuInfo']['plugin']['child']` 数组 push 一个菜单项，即可在后台插件菜单下新增子菜单。
- 不需要修改核心文件，符合 **开闭原则**。
- 可用的 Hook 点由框架在对应位置预留，通常以 `do_action()` 函数调用。

### 54.8 前台调用

```html
<!-- 模板中调用 Block 标签 -->
{block:links limit=10 orderby=id orderway=-1}
{loop:$links $v}
    <li>
        <a href="{$v[url]}" target="_blank" title="{$v[name]}">{$v[name]}</a>
    </li>
{/loop}
{/block}
```

**说明：**
- `{block:links ...}` 调用 `block_links()` 函数，返回数据赋值给 `$links` 变量。
- `limit`：返回条数，默认 10。
- `orderby`：排序字段，默认 `id`。
- `orderway`：`1` 为升序，`-1` 为降序。
- `{loop:$links $v}` 遍历数组，`$v` 为每条数据。
- 数组元素通过 `{$v[字段名]}` 方式访问。

## 55. 案例2：随机缩略图插件（le_rand_pic）

### 55.1 插件概述

`le_rand_pic` 是一个轻量级的 **Hook 类型插件**，它不拥有独立的后台页面，而是通过监听框架事件自动完成功能。它的核心作用是：当内容模型（文章、页面等）没有设置缩略图时，自动从预配置的图片池中随机选取一张作为缩略图，提升网站视觉效果。

### 55.2 核心文件结构

```
lecms/plugin/le_rand_pic/
├── conf.php                                  # 插件配置
├── install.php                               # 安装脚本（创建图片池表）
├── rand_pic_model.class.php                  # 图片池数据模型
├── cms_content_model_format_before.php       # Hook 拦截点
├── rand_pic_index.htm                        # 后台配置页面
├── rand_pic_control.class.php                # 后台控制器
├── admin_admin_control_init_nav_after.php    # 注入后台菜单
└── lang_zh_cn_admin.php                      # 后台语言包
```

### 55.3 Hook 配置

```php
<?php
// conf.php
return array(
    'name' => '随机缩略图',
    'brief' => '内容无缩略图时自动分配随机图片',
    'version' => '1.0.0',
    'cms_version' => '3.0.0',
    'update' => '2025-02-15',
    'author' => '你的名字',
    'authorurl' => 'https://example.com',
    'setting' => '',
    'hook' => array(
        'cms_content_model_format_before',    // 声明监听的 Hook 点
    ),
);
```

**说明：**
- `'hook'` 字段声明插件需要监听的事件点，框架启动时自动注册。
- `cms_content_model_format_before` 是一个在内容格式化输出前触发的事件，正好可以在此时修改缩略图字段。

### 55.4 拦截逻辑实现

```php
<?php
// cms_content_model_format_before.php
// 这个文件在 cms_content_model 的 format() 方法执行前被加载
// Hook 点命名规则：{目标模块}_{方法名}_before.php

defined('ROOT_PATH') || exit;

// $GLOBALS['_content'] 是即将格式化的内容对象引用
global $_content;

// 如果缩略图已存在，不处理
if(!empty($_content->thumb) && $_content->thumb != '') {
    return;
}

// 从图片池随机取一张
$pic = $GLOBALS['run']->rand_pic->find_fetch(array(), array('id' => 'RAND()'), 0, 1);
if(!empty($pic)) {
    $_content->thumb = $pic[0]['pic_url'];
}
```

**说明：**
- Hook 文件通过命名约定自动加载：`{模块}_{方法}_before.php` 在目标方法执行前加载。
- 通过 `global $_content` 获取内容对象引用，直接修改其属性。
- `$_content->thumb` 即为内容的缩略图字段。
- `find_fetch()` 的第二个参数 `array('id' => 'RAND()')` 表示随机排序。
- 这种"无侵入"方式不需要修改任何核心文件。

### 55.5 工作原理

```
[用户发布文章，未上传缩略图]
        |
        v
[cms_content_model->format() 被调用]
        |
        v
[框架检测到 hook: cms_content_model_format_before]
        |
        v
[加载 cms_content_model_format_before.php]
        |
        v
[检测 $_content->thumb 为空]
        |
        v
[从 rand_pic 表随机取一张图片 URL]
        |
        v
[赋值给 $_content->thumb]
        |
        v
[format() 继续执行，输出带缩略图的文章]
```

**Hook 机制优势：**
- 解耦：插件与核心代码完全隔离。
- 可组合：多个插件可以监听同一个 Hook，按加载顺序依次执行。
- 可扩展：框架在任何方法调用前后都预留了 Hook 点。

## 56. 案例3：其他常见插件类型速览

### 56.1 内容采集插件

内容采集插件通过 **Hook 拦截 `cms_content_model_create_before`**，在内容入库前自动：
- 采集远程网页内容
- 提取标题、正文、缩略图
- 自动生成摘要和标签

- 在 `{模型}_model_format_before` 中格式化自定义字段的输出

### 56.3 支付网关插件

支付插件通常包含：
- `pay_control.class.php`：处理支付回调（异步通知 URL）

## 57. 案例4：自定义路由

### 57.1 路由机制概述

LeCMS 默认路由格式为 `index.php?{控制器}-{方法}-{参数}`，但这不利于 SEO。通过 **自定义路由系统**，可以实现类似 `example.com/article/12345.html` 的伪静态 URL。自定义路由需要以下组件配合：

| 组件 | 作用 |
|------|------|
| `route.inc.php` | URL 匹配规则配置 |
| `parseurl_control` | URL 解析控制器 |
| 插件 | 注册路由规则并实现 URL 解析逻辑 |

### 57.2 route.inc.php 配置

```php
<?php
// route.inc.php — 自定义路由配置文件
// 返回二维数组，第一维为匹配模式，第二维为控制器映射

return array(
    // 文章详情页路由
    '/article/(\d+)\.html' => array(
        'control' => 'cms',
        'action' => 'article',
        'params' => array('id' => 1),  // 1 表示第一个正则捕获组
    ),

    // 栏目列表页路由
    '/list/(\d+)\.html' => array(
        'control' => 'cms',
        'action' => 'list',
        'params' => array('cid' => 1),
    ),

    // 标签页路由
    '/tag/([a-zA-Z0-9_-]+)\.html' => array(
        'control' => 'cms',
        'action' => 'tag',
        'params' => array('tag' => 1),
    ),

    // 自定义页面路由
    '/page/([a-zA-Z0-9_-]+)\.html' => array(
        'control' => 'cms',
        'action' => 'page',
        'params' => array('slug' => 1),
    ),

    // 搜索路由
    '/search\.html' => array(
        'control' => 'cms',
        'action' => 'search',
        'params' => array(),
    ),
);
```

**说明：**
- 文件位于站点根目录或插件目录下。
- 键为正则表达式，框架按顺序匹配，第一个命中即停止。
- 值为路由目标，包含 `control`（控制器）、`action`（方法）、`params`（参数映射）。
- `params` 中的数字对应正则表达式的捕获组序号（从 1 开始）。

### 57.3 parseurl_control 实现

```php
<?php
// parseurl_control.class.php
defined('ROOT_PATH') || exit;

class parseurl_control extends control {

    /**
     * URL 解析入口
     * 框架在 init 阶段调用此方法
     */
    public function index() {
        // 获取当前请求的路径（不含域名和 query string）
        $request_uri = $_SERVER['REQUEST_URI'];
        $path = parse_url($request_uri, PHP_URL_PATH);

        // 去除站点根目录前缀
        $base = $_ENV['_config']['site']['base_url'] ?? '/';
        if($base != '/' && strpos($path, $base) === 0) {
            $path = substr($path, strlen($base));
        }

        // 去除末尾斜杠
        $path = rtrim($path, '/');

        // 加载路由规则文件
        $route_file = $GLOBALS['_plugin']['route_file'] ?? ROUTE_PATH;
        if(!file_exists($route_file)) {
            $this->_not_found();
            return;
        }
        $routes = include $route_file;

        // 逐条匹配路由规则
        foreach($routes as $pattern => $target) {
            if(preg_match('#^'.$pattern.'$#i', $path, $matches)) {
                // 命中路由，解析参数
                $this->_dispatch($target, $matches);
                return;
            }
        }

        // 未匹配任何路由
        $this->_not_found();
    }

    /**
     * 分发到目标控制器
     */
    private function _dispatch($target, $matches) {
        $control_name = $target['control'] . '_control';
        $action_name  = $target['action'];
        $params       = $target['params'];

        // 构造 GET 参数
        foreach($params as $param_name => $match_index) {
            if($match_index > 0 && isset($matches[$match_index])) {
                $_GET[$param_name] = $matches[$match_index];
            }
        }

        // 实例化目标控制器并执行
        $obj = new $control_name();
        if(method_exists($obj, $action_name)) {
            call_user_func(array($obj, $action_name));
        } else {
            $this->_not_found();
        }
        exit;
    }

    private function _not_found() {
        header('HTTP/1.1 404 Not Found');
        echo '404 Not Found';
        exit;
    }
}
```

### 57.4 插件配合与 URL 解析

自定义路由需要以插件形式注册到框架的初始化流程中：

```php
<?php
// 插件核心文件：le_route/route.php（注册文件）

// 在框架初始化时声明路由文件路径
add_action('init', function() {
    // 将路由文件路径写入全局变量
    $GLOBALS['_plugin']['route_file'] = PLUGIN_PATH . 'le_route/route.inc.php';

    // 注册 parseurl_control 为默认控制器
    // 当 URL 不匹配任何控制器-方法格式时，框架调用此控制器
    $GLOBALS['_config']['default_control'] = 'parseurl';
});
```

### 57.5 SEO 友好的 URL 方案

结合 LeCMS 的 URL 生成函数，可以在模板中自动生成伪静态链接：

```php
<?php
/**
 * 生成文章伪静态链接
 * @param array $article 文章数据数组
 * @return string 完整 URL
 */
function url_article($article) {
    $base = $_ENV['_config']['site']['base_url'];
    return $base . '/article/' . $article['id'] . '.html';
}

/**
 * 生成栏目列表伪静态链接
 * @param int $cid 栏目 ID
 * @return string 完整 URL
 */
function url_list($cid) {
    $base = $_ENV['_config']['site']['base_url'];
    return $base . '/list/' . $cid . '.html';
}

/**
 * 生成标签页伪静态链接
 * @param string $tag 标签名
 * @return string 完整 URL
 */
function url_tag($tag) {
    $base = $_ENV['_config']['site']['base_url'];
    return $base . '/tag/' . urlencode($tag) . '.html';
}
```

**高级路由方案 — 数据库驱动路由：**

对于文章标题 URL（如 `/article/hello-world.html`），可以将标题映射关系存储在数据表中，通过路由插件查找标题对应的文章 ID，实现可读性更强的 URL：

```
/article/hello-world.html  →  查询 title_map 表 →  文章 ID: 1234 → 跳转到 /article/1234.html
```

这种方式需要维护一个 `title_map` 表，在文章发布/修改时同步更新映射关系。

## 附录：插件开发 Checklist

开发新插件时可按以下步骤检查：

| 步骤 | 检查项 |
|------|--------|
| 1 | `conf.php` 配置信息完整，`name`、`version`、`cms_version` 已填写 |
| 2 | `install.php` 建表语句使用 `$_ENV['_config']['db']['master']['tablepre']` 获取前缀 |
| 3 | 所有 PHP 文件首行包含 `defined('ROOT_PATH') || exit;` |
| 4 | 模型类继承 `model`，正确设置 `$this->table`、`$this->pri`、`$this->maxid` |
| 5 | 控制器类继承 `admin_control`（后台）或 `control`（前台） |
| 6 | 参数获取使用 `R('name', 'P')` 或 `R('name', 'G')` 而非直接 `$_POST` |
| 7 | Block 标签函数名格式为 `block_{插件名}($conf)` |
| 8 | 模板变量输出时注意是否需要转义 |
| 9 | Hook 文件名格式正确：`{模块}_{方法}_{before/after}.php` |
| 10 | 菜单注入通过 Hook 完成，不修改核心文件 |
