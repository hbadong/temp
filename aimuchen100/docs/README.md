## 七、文档维护规范

1. **新增文档**：在对应分类目录下创建，文件头加 YAML 元数据（`kind/name/category/scope/source_files/last_updated`）
2. **修改现有文档**：更新正文后，必须同步修改 `last_updated` 字段
3. **跨文档引用**：使用相对路径，例如 `[LECMS 配置系统](../LECMS%20配置系统%20—%20基于%20PHP%20数组的配置文件与运行时缓存机制/LECMS%20配置系统%20—%20基于%20PHP%20数组的配置文件与运行时缓存机制.md)`
4. **删除文档**：避免直接删除文件，优先合并内容到主文档；如必须删除，更新本 README 导航表
