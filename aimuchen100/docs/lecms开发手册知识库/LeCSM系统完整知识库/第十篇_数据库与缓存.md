## 60. 数据库配置

### 60.1 完整配置示例

```php
// config/config.inc.php

$_ENV['_config']['db'] = array(
    'type' => 'pdo_mysql',  // 驱动类型

    // 主库（写操作：INSERT / UPDATE / DELETE）
    'master' => array(
        'host'     => '127.0.0.1',
        'port'     => '3306',
        'user'     => 'aimuchen100',
        'password' => 'aimuchen100',
        'name'     => 'aimuchen100',
        'tablepre' => 'le_',           // 表前缀
        'charset'  => 'utf8mb4',
        'engine'   => 'MyISAM',
    ),

    // 从库（读操作：SELECT）
    // 框架随机选择一台从库，实现负载均衡
    'slaves' => array(
        array(
            'host'     => '127.0.0.1',
            'port'     => '3306',
            'user'     => 'aimuchen100',
            'password' => 'aimuchen100',
            'name'     => 'aimuchen100',
            'charset'  => 'utf8mb4',
            'engine'   => 'MyISAM',
        ),
    ),

    // 单点分发节点（用于 maxid / count 等需要一致性的操作）
    'arbiter' => array(
        'host'     => '127.0.0.1',
        'port'     => '3306',
        'user'     => 'aimuchen100',
        'password' => 'aimuchen100',
        'name'     => 'aimuchen100',
        'charset'  => 'utf8mb4',
        'engine'   => 'MyISAM',
    ),
);
```

**配置项说明：**

| 字段 | 说明 |
|------|------|
| `type` | 数据库驱动类型，支持 `pdo_mysql` |
| `master` | 主库连接信息，所有写操作都走主库 |
| `slaves` | 从库数组，读操作随机选择一台 |
| `arbiter` | 单点分发节点，用于 `maxid`、`count` 等操作保证数据一致性 |
| `tablepre` | 表前缀，框架自动拼接 |
| `charset` | 数据库字符集，推荐 `utf8mb4` |
| `engine` | 默认存储引擎，推荐 `MyISAM`（读多写少的 CMS 场景）或 `InnoDB`（需要事务的场景） |

### 60.2 数据库操作

```php
// ==========================================
// 通过 $this->db 进行底层数据库操作
// ==========================================

// 获取表前缀
$tablepre = $this->db->tablepre;

// 执行原生 SQL 查询
$sql = "SELECT * FROM {$tablepre}article WHERE id = 1";
$stmt = $this->db->query($sql);
$row = $stmt->fetch(PDO::FETCH_ASSOC);

// 获取所有结果
$list = $stmt->fetchAll(PDO::FETCH_ASSOC);

// 获取最后插入的 ID
$last_id = $this->db->insert_id();

// 获取影响的行数
$affected = $this->db->affected_rows();

// ==========================================
// 通过 Model 进行 ORM 操作（推荐）
// ==========================================

// 创建一条记录
$id = $this->article->create(array(
    'title'   => '文章标题',
    'content' => '文章内容',
    'status'  => 1,
    'dateline' => $_ENV['_time'],
));

// 读取一条记录（按主键）
$article = $this->article->get($id);

// 更新一条记录（需要包含主键）
$this->article->update(array(
    'id'      => $id,
    'title'   => '新标题',
    'status'  => 0,
));

// 删除一条记录
$this->article->delete($id);

// 条件查询（按 WHERE）
$where = array('status' => 1, 'cid' => 2);
$list = $this->article->find_fetch($where);

// 带排序和分页
$list = $this->article->find_fetch($where, array('dateline' => -1), 0, 10);

// 统计总数
$total = $this->article->find_count($where);

// ==========================================
// 事务处理
// ==========================================

$this->db->begin();
try {
    $this->article->create($data1);
    $this->category->update($data2);
    $this->db->commit();
} catch(Exception $e) {
    $this->db->rollback();
    // 处理错误
}
```

## 61. 数据库驱动详解（db_pdo_mysql）

### 61.1 三连接架构

`db_pdo_mysql.class.php`（约 847 行）是 LeCMS 的默认数据库驱动，它维护了 **三个独立的 PDO 连接**：

| 连接名称 | 用途 | 说明 |
|----------|------|------|
| `wlink` | 写连接 | INSERT / UPDATE / DELETE / DDL 操作 |
| `rlink` | 读连接 | SELECT 查询操作 |
| `xlink` | 计数连接 | maxid / count 等需要一致性的计数操作 |

**连接初始化逻辑：**

```php
// 初始化主库（写连接）
$this->wlink = new PDO("mysql:host={$master['host']};port={$master['port']};dbname={$master['name']};charset={$master['charset']}", $master['user'], $master['password']);
$this->wlink->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

// 初始化从库（读连接）— 随机选择一台
if(!empty($this->conf['slaves'])) {
    $slave = $this->conf['slaves'][array_rand($this->conf['slaves'])];
    $this->rlink = new PDO("mysql:host={$slave['host']};...", ...);
} else {
    // 无从库时读写共用主库
    $this->rlink = $this->wlink;
}

// 初始化 arbiter（计数连接）
if(isset($this->conf['arbiter'])) {
    $this->xlink = new PDO("mysql:host={$arbiter['host']};...", ...);
} else {
    $this->xlink = $this->wlink;
}
```

**主从分离的策略：**
- 所有 `query()` 方法（SELECT）自动使用 `rlink`。
- 所有 `exec()` 方法（INSERT/UPDATE/DELETE）自动使用 `wlink`。
- `maxid()`、`count()` 等计数方法使用 `xlink`，避免从库延迟导致的数据不一致。

### 61.2 键名系统

LeCMS 内部使用统一的键名格式来标识数据行，格式为：

```
{table}-{field}-{value}
```

**示例：**

```
article-12345      → article 表中 id=12345 的记录
links-10           → links 表中 id=10 的记录
user-100           → user 表中 id=100 的记录
```

**key2arr() 解析函数：**

```php
/**
 * 将键名解析为数组
 * @param string $key 例如 "article-12345"
 * @return array ['table' => 'article', 'field' => 'id', 'value' => '12345']
 */
public function key2arr($key) {
    $a = explode('-', $key, 3);
    return array(
        'table'  => $a[0],
        'field'  => $a[1],
        'value'  => $a[2],
    );
}
```

**这种键名系统的作用：**
- 为内存缓存（如 APCu、Yac）提供唯一的键标识。
- 统一了不同表的访问入口。
- `model` 基类在 `get()` / `set()` / `update()` / `delete()` 等方法中自动构造键名。

### 61.3 arr2where() — WHERE 条件构建器

```php
/**
 * 将 PHP 数组转换为安全的 SQL WHERE 子句
 * @param array $arr 条件数组
 * @param string $tablepre 表前缀（用于自动添加前缀）
 * @return array ['where' => 'xxx', 'args' => array()]
 */
public function arr2where($arr, $tablepre) {
    $where = '';
    $args = array();
    foreach($arr as $k => $v) {
        if(is_array($v)) {
            // 处理操作符：array('IN' => [1,2,3])
            foreach($v as $op => $ov) {
                $op = strtoupper($op);
                if($op == 'IN') {
                    $placeholders = rtrim(str_repeat('?,', count($ov)), ',');
                    $where .= " AND `{$tablepre}{$k}` IN ({$placeholders})";
                    $args = array_merge($args, $ov);
                } elseif($op == 'LIKE') {
                    $where .= " AND `{$tablepre}{$k}` LIKE ?";
                    $args[] = $ov;
                } elseif($op == 'BETWEEN') {
                    $where .= " AND `{$tablepre}{$k}` BETWEEN ? AND ?";
                    $args = array_merge($args, $ov);
                } else {
                    // >= > < <= !=
                    $where .= " AND `{$tablepre}{$k}` {$op} ?";
                    $args[] = $ov;
                }
            }
        } else {
            // 默认等于
            $where .= " AND `{$tablepre}{$k}` = ?";
            $args[] = $v;
        }
    }
    // 去除开头的 AND
    $where = ltrim($where, ' AND');
    return array('where' => $where, 'args' => $args);
}
```

**使用示例：**

```php
$where = array('status' => 1, 'cid' => array('IN' => [1, 2]));
list($where_sql, $args) = $this->db->arr2where($where, 'le_');
// 结果：
// $where_sql = "`le_status` = ? AND `le_cid` IN (?,?)"
// $args = [1, 1, 2]
```

### 61.4 arr2sql() — SET 条件构建器

```php
/**
 * 将数组转换为 SQL SET 子句
 * @param array $arr 数据数组
 * @param string $tablepre 表前缀
 * @return array ['set' => 'xxx', 'args' => array()]
 */
public function arr2sql($arr, $tablepre) {
    $set = '';
    $args = array();
    foreach($arr as $k => $v) {
        // 跳过主键
        if($this->is_pri($k)) continue;
        $set .= " `{$tablepre}{$k}` = ?,";
        $args[] = $v;
    }
    $set = rtrim($set, ',');
    return array('set' => $set, 'args' => $args);
}
```

### 61.6 主从分离机制

框架在 `model` 基类中根据操作类型自动选择连接：

| 操作 | 方法 | 使用连接 |
|------|------|----------|
| `find_fetch()` / `find_fetch_key()` | SELECT | rlink（从库） |
| `get()` | SELECT by PK | rlink |
| `find_count()` / `find_maxid()` | SELECT COUNT(*) | xlink（arbiter） |
| `create()` | INSERT | wlink（主库） |
| `update()` | UPDATE | wlink |
| `delete()` / `find_delete()` | DELETE | wlink |
| `truncate()` | TRUNCATE | wlink |

### 61.8 数据层详细分析

LeCMS 的数据层采用 **"统一键值对存储 + ORM 映射"** 的设计，所有数据操作最终都通过 Key-Value 进行。

#### 61.8.1 键名系统（Key Naming）

LeCMS 内部使用统一的键名格式来标识数据行：

```
{table}-{field}-{value}
```

**示例**:

```
article-12345      → article 表中 id=12345 的记录
links-10           → links 表中 id=10 的记录
user-100           → user 表中 id=100 的记录
```

**Key 格式说明**:

| Key 类型 | 格式 | 示例 | 来源方法 |
|----------|------|------|---------|
| 数据 Key | `{table}-{pri1}-{val1}[-{pri2}-{val2}...]` | `user-uid-1` | `pri2key()` |
| maxid Key | `{table}-{maxid_field}` | `user-uid` | `cache_db_maxid()` |
| count Key | `{table}` | `user` | `cache_db_count()` |

**`pri2key()` 实现**:

```php
public function pri2key($arr) {
    $s = $this->table;
    foreach($this->pri as $v) {
        $s .= "-$v-".$arr[$v];
    }
    return $s;
    // 示例: $this->table='user', $this->pri=['uid']
    //        $arr=['uid'=>1, 'username'=>'test']
    //        → "user-uid-1"
}
```

#### 61.8.2 数据读取流程

```
读取一条数据: $article = $this->article->get(1)
  │
  ├── 1. 生成 Key: "article-id-1"
  ├── 2. 检查 L1 缓存 ($unique)
  │   └── 命中? → 直接返回
  │
  ├── 3. 检查 L2 缓存 (Cache)
  │   ├── 命中? → 写入 L1 → 返回
  │   └── 未命中 → 继续
  │
  ├── 4. 查询数据库 (rlink)
  │   └── $this->db->get("article-id-1")
  │
  ├── 5. 回填缓存
  │   ├── 写入 L2 Cache
  │   └── 写入 L1 ($unique)
  │
  └── 6. 返回数据
```

#### 61.8.3 数据写入流程

```
写入一条数据: $this->article->create($data)
  │
  ├── 1. 获取 maxid + 1
  ├── 2. 写入数据库 (wlink)
  │   └── $this->db->set($key, $data)
  │
  ├── 3. 写入 L2 Cache
  │   └── $this->cache->set($key, $data)
  │
  ├── 4. 写入 L1 ($unique)
  │   └── $this->unique[$key] = $data
  │
  ├── 5. 更新 count +1
  └── 6. 返回自增 ID
```

#### 61.8.4 Where 条件构建器

DB 驱动的 `where` 条件支持以下操作符：

| 操作符 | 语法 | SQL 生成示例 |
|--------|------|------------|
| `=` | `array('uid' => 1)` | `WHERE uid = 1` |
| `>` | `array('uid' => array('>' => 1))` | `WHERE uid > 1` |
| `<` | `array('uid' => array('<' => 1))` | `WHERE uid < 1` |
| `>=` | `array('uid' => array('>=' => 1))` | `WHERE uid >= 1` |
| `<=` | `array('uid' => array('<=' => 1))` | `WHERE uid <= 1` |
| `!=` | `array('uid' => array('!=' => 1))` | `WHERE uid != 1` |
| `LIKE` | `array('title' => array('LIKE' => '%test%'))` | `WHERE title LIKE '%test%'` |
| `IN` | `array('uid' => array('IN' => array(1,2,3)))` | `WHERE uid IN (1,2,3)` |
| `NOT IN` | `array('uid' => array('NOT IN' => array(1,2,3)))` | `WHERE uid NOT IN (1,2,3)` |
| `BETWEEN` | `array('dateline' => array('BETWEEN' => array(0, 100)))` | `WHERE dateline BETWEEN 0 AND 100` |
| `FIND_IN_SET` | `array('tags' => array('FIND_IN_SET' => 'news'))` | `WHERE FIND_IN_SET('news', tags)` |

**组合条件示例**:

```php
// 查询 uid=1 且 dateline 在 1000-2000 之间且 status=1 的文章
$where = array(
    'AND' => array(
        'uid' => 1,
        'status' => 1,
        'dateline' => array('BETWEEN' => array(1000, 2000)),
    ),
);
// WHERE uid = 1 AND status = 1 AND dateline BETWEEN 1000 AND 2000
```

## 62. db_interface 接口完整参考

```php
// xiunophp/db/db_interface.class.php

interface db_interface {

    // ==========================================
    // 单条操作（CRUD）
    // ==========================================

    /**
     * 根据主键读取一条记录
     * @param string $key 键名，格式 "table-field-value"
     * @return array|null
     */
    public function get($key);

    /**
     * 写入一条记录（自动 INSERT 或 REPLACE）
     * @param string $key 键名，格式 "table-field-value"
     * @param array $data 数据数组
     * @return int 插入的 ID
     */
    public function set($key, $data);

    /**
     * 更新一条记录
     * @param string $key 键名，格式 "table-field-value"
     * @param array $data 数据数组
     * @return bool
     */
    public function update($key, $data);

    /**
     * 删除一条记录
     * @param string $key 键名
     * @return bool
     */
    public function delete($key);

    // ==========================================
    // 计数操作
    // ==========================================

    /**
     * 获取指定表的最大 ID（用于自增主键获取）
     * @param string $key 键名
     * @param string $val 当前值
     * @return int
     */
    public function maxid($key, $val);

    /**
     * 统计满足条件的记录数
     * @param string $table 表名
     * @param array $val WHERE 条件数组
     * @return int
     */
    public function count($table, $val);

    /**
     * 清空表
     * @param string $table 表名
     * @return bool
     */
    public function truncate($table);

    // ==========================================
    // 批量操作
    // ==========================================

    /**
     * 批量读取多条记录（按键名数组）
     * @param array $keys 键名数组
     * @return array 数据数组
     */
    public function multi_get($keys);

    /**
     * 条件查询（支持 WHERE / ORDER / LIMIT）
     * @param array $arr WHERE 条件
     * @param array $orderby 排序 ['field' => 1/-1]
     * @param int $start 偏移量
     * @param int $limit 条数
     * @return array
     */
    public function find_fetch($arr, $orderby = array(), $start = 0, $limit = 0);

    /**
     * 条件查询并以键名索引返回
     * @return array
     */
    public function find_fetch_key();

    /**
     * 批量更新
     * @param array $arr WHERE 条件
     * @param array $update SET 数据
     * @return bool
     */
    public function find_update($arr, $update);

    /**
     * 批量删除
     * @param array $arr WHERE 条件
     * @return bool
     */
    public function find_delete($arr);

    /**
     * 条件统计
     * @param string $table 表名
     * @param array $arr WHERE 条件
     * @return int
     */
    public function find_count($table, $arr);

    /**
     * 获取条件中的最大 ID
     * @param string $table 表名
     * @param array $arr WHERE 条件
     * @return int
     */
    public function find_maxid($table, $arr);

    // ==========================================
    // 索引管理
    // ==========================================

    /**
     * 创建索引
     */
    public function index_create($table, $name, $fields);

    /**
     * 删除索引
     */
    public function index_drop($table, $name);

    // ==========================================
    // 表管理
    // ==========================================

    /**
     * 获取字段值（SELECT single field）
     */
    public function get_field($table, $field, $value);

    /**
     * 检查表是否存在
     * @param string $table 表名
     * @return bool
     */
    public function exist_table($table);

    /**
     * 创建数据表
     * @param string $name 表名（含前缀）
     * @param array $columns 字段定义
     * @param string $primary 主键字段
     * @param string $extra 附加 SQL（ENGINE / CHARSET）
     * @return bool
     */
    public function table_create($name, $columns, $primary, $extra);

    /**
     * 删除数据表
     * @param string $table 表名
     * @return bool
     */
    public function table_drop($table);

    /**
     * 删除数据库
     * @param string $name 数据库名
     * @return bool
     */
    public function delete_db($name);
}
```

## 64. 缓存系统

### 64.1 cache_interface 接口

```php
// xiunophp/cache/cache_interface.class.php

interface cache_interface {
    // 基础操作
    public function get($key);
    public function set($key, $value, $ttl = 0);
    public function delete($key);
    public function clear();

    // 批量操作
    public function multi_get($keys);
    public function multi_set($arr, $ttl = 0);
    public function multi_delete($keys);

    // 扩展操作
    public function increment($key, $step = 1);
    public function decrement($key, $step = 1);
    public function exists($key);

    // 生命周期管理
    public function ttl($key);
    public function set_ttl($key, $ttl);

    // 信息
    public function info();
    public function size();
}
```

### 64.2 六种缓存驱动对比

| 驱动 | 类名 | 性能 | 特性 | 适用场景 |
|------|------|------|------|----------|
| **File** | `cache_file.class.php` | 慢 | 无依赖，文件系统存储 | 单机小站、开发环境 |
| **Memcache** | `cache_memcache.class.php` | 快 | 多服务器分布式支持 | 多台服务器需要共享缓存 |
| **Memcached** | `cache_memcached.class.php` | 更快 | 二进制协议，性能优于 Memcache | 高性能分布式场景 |
| **Redis** | `cache_redis.class.php` | 快 | 丰富数据结构（Hash / Set / ZSet） | 排行榜、队列、复杂场景 |
| **Yac** | `cache_yac.class.php` | 最快 | 共享内存，PHP 扩展 | 单机高性能，无持久化 |
| **APC** | `cache_apc.class.php` | 快 | PHP 内置扩展 | 单机简单缓存 |

**缓存配置示例：**

```php
// config/config.inc.php

// 使用 Redis 作为缓存驱动
$_ENV['_config']['cache']['type'] = 'redis';
$_ENV['_config']['cache']['redis'] = array(
    'host'    => '127.0.0.1',
    'port'    => 6379,
    'timeout' => 1,
    'auth'    => '',
    'db'      => 0,
);

// 使用 Memcached
$_ENV['_config']['cache']['type'] = 'memcached';
$_ENV['_config']['cache']['memcached'] = array(
    array('host' => '127.0.0.1', 'port' => 11211),
    array('host' => '127.0.0.1', 'port' => 11212),  // 多节点
);

// 使用 File（默认，无需额外配置）
$_ENV['_config']['cache']['type'] = 'file';
```

### 64.3 二级缓存（L2 Cache）

LeCMS 采用 **两级缓存架构**：

```
L1 Cache（db_interface 内置）
├── 键名格式：table-field-value
├── 生命周期：单次请求内
└── 存储：内存数组（PHP 变量）

L2 Cache（cache_interface 实现）
├── 键名格式：自定义
├── 生命周期：可配置 TTL
└── 存储：File / Redis / Memcached 等
```

**二级缓存映射表（l2_cache）：**

```php
// L2 缓存的键到 L1 键的映射
// 格式：l2_key => [l1_key1, l1_key2, ...]
// 当 L2 缓存失效时，框架自动清除所有相关的 L1 缓存

$_ENV['_l2_cache'] = array(
    // 示例：热门文章列表缓存
    'hot_articles' => array(
        'article-12345', 'article-12346', 'article-12347',
    ),
    // 示例：栏目统计缓存
    'category_123_stats' => array(
        'category-123-count', 'category-123-maxid',
    ),
);
```

**工作原理：**

```
[页面请求]
    |
    v
[查询 Block: hot_articles]
    |
    v
[检查 L2 缓存：get('hot_articles')]
    |-- 命中 → 直接返回 L2 缓存数据
    |-- 未命中
            |
            v
        [查询 L1 缓存（内存数组）]
            |-- 命中 → 返回并写入 L2 缓存
            |-- 未命中
                    |
                    v
                [查询数据库]
                    |
                    v
                [写入 L1 缓存]
                    |
                    v
                [写入 L2 缓存]
```

### 64.5 数据库驱动详细对比

| 驱动 | 类文件 | PHP 版本 | PECL 扩展 | 推荐度 | 说明 |
|------|--------|---------|-----------|--------|------|
| `mysql` | `db_mysql.class.php` | PHP 5.5- | 无（内置） | ⭐⭐ | 最老的扩展，已废弃。LeCMS 仍保留兼容。 |
| `mysqli` | `db_mysqli.class.php` | PHP 5.0+ | 无（内置） | ⭐⭐⭐⭐ | 面向对象写法，支持预处理。推荐兼容方案。 |

**`pdo_mysql` 驱动核心特性**:

```php
class db_pdo_mysql implements db_interface {
    public $tablepre;      // 表前缀
    public $conf = array(); // 配置引用（引用传递）

    // 三连接模型
    public function __get($var) {
        if($var == 'wlink') {       // 写主库: INSERT/UPDATE/DELETE
            // 连接 master 节点
        } elseif($var == 'rlink') { // 读从库: SELECT
            // 随机选择 slaves 节点
        } elseif($var == 'xlink') { // 单点分发: maxid/count
            // 连接 arbiter 节点
        }
    }
}
```

|------|---------|------|
| 新项目 | pdo_mysql | 框架默认推荐，功能最全 |
| 老环境 | mysqli | 无需额外扩展，面向对象 |
| 遗留系统 | mysql | 仅用于兼容老代码 |
| 文档型数据 | mongodb | 需自行实现驱动 |

## 65. KV 存储模型

### 65.1 kv_model — 通用键值对

`kv_model` 提供简单的 Key-Value 存储，支持 TTL（过期时间）：

```php
<?php
// kv_model.class.php

class kv_model extends model {

    function __construct() {
        $this->table = 'kv';
        $this->pri = array('k');
        $this->maxid = 'k';
    }

    /**
     * 获取值
     */
    public function get($key) {
        $kv = parent::get($key);
        // 检查 TTL
        if($kv && $kv['ttl'] > 0 && $kv['dateline'] + $kv['ttl'] < $_ENV['_time']) {
            // 已过期，删除并返回 null
            parent::delete($key);
            return null;
        }
        return $kv ? $kv['v'] : null;
    }

    /**
     * 设置值
     * @param string $key 键名
     * @param mixed $value 值（自动序列化）
     * @param int $ttl 过期时间（秒），0 表示永不过期
     * @return bool
     */
    public function set($key, $value, $ttl = 0) {
        $data = array(
            'k'        => $key,
            'v'        => serialize($value),
            'ttl'      => $ttl,
            'dateline' => $_ENV['_time'],
        );
        return parent::set($key, $data);
    }
}
```

**KV 表结构：**

```sql
CREATE TABLE le_kv (
  k varchar(80) NOT NULL DEFAULT '' COMMENT '键名',
  v text NOT NULL COMMENT '值（序列化存储）',
  ttl int(10) unsigned NOT NULL DEFAULT '0' COMMENT '过期时间（秒），0=永不过期',
  dateline int(10) unsigned NOT NULL DEFAULT '0' COMMENT '写入时间',
  PRIMARY KEY (k)
) ENGINE=MyISAM DEFAULT CHARSET=utf8;
```

### 65.2 runtime_model — 运行时配置

`runtime_model` 专门用于存储系统运行时配置，如 CMS 设置、插件设置等：

```php
<?php
// runtime_model.class.php

class runtime_model extends model {

    function __construct() {
        $this->table = 'runtime';
        $this->pri = array('name');
        $this->maxid = 'name';
    }

    /**
     * 获取配置值
     * @param string $name 配置名
     * @param mixed $default 默认值
     * @return mixed
     */
    public function get($name, $default = null) {
        $kv = parent::get($name);
        return $kv ? unserialize($kv['value']) : $default;
    }

    /**
     * 设置配置值
     * @param string $name 配置名
     * @param mixed $value 值（自动序列化）
     * @return bool
     */
    public function set($name, $value) {
        return parent::set($name, array(
            'name'    => $name,
            'value'   => serialize($value),
            'dateline' => $_ENV['_time'],
        ));
    }
}
```

**runtime 表结构：**

```sql
CREATE TABLE le_runtime (
  name varchar(80) NOT NULL DEFAULT '' COMMENT '配置名',
  value text NOT NULL COMMENT '配置值（序列化）',
  dateline int(10) unsigned NOT NULL DEFAULT '0' COMMENT '更新时间',
  PRIMARY KEY (name)
) ENGINE=MyISAM DEFAULT CHARSET=utf8;
```

**runtime_model 的使用场景：**

| 配置名 | 说明 | 示例值 |
|--------|------|--------|
| `cfg` | CMS 全局配置 | serialize(['site_name' => '...', 'seo_title' => '...']) |
| `cache_article_hot` | 热门文章缓存 | serialize([1, 2, 3, 4, 5]) |
| `cache_category_tree` | 栏目树缓存 | serialize([...]) |

## 附录：数据库性能优化建议

| 优化项 | 说明 |
|--------|------|
| 索引优化 | 为 WHERE、ORDER BY、JOIN 的字段添加索引 |
| 避免 SELECT * | 只查询需要的字段 |
| 分页优化 | 使用 `WHERE id > ? LIMIT n` 替代 `LIMIT n, m`（深分页问题） |
| 从库只读 | 确保从库不承担写操作 |
| 缓存热点数据 | 热门列表、统计数据放入 L2 缓存 |
| 表分区 | 大表（如日志表）按时间分区 |
| 归档策略 | 将过期数据归档到历史表 |
| 避免大事务 | 事务保持最小粒度，减少锁持有时间 |
