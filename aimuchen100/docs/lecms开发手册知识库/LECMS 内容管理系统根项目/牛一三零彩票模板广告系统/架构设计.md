模块采用按业务域划分的扁平目录结构：每个业务（如 lnys、bzjp、amjr 等）独立一个子目录，内含一套标准 PHP 模板文件（guding.php/tubiao.php/tuwen.php/vip.php/youxiajiao.php）和可选的 {业务}.js；所有模板通过 $_GET 参数（dhid、adid、s、type 等）接收投放标识与模式，动态拼接 HTML 并通过 document.writeln 输出可嵌入第三方站点的 JS 片段。
- 通用静态资源集中在 static/ 下（css/js/img/layer/nav/s），各业务目录 images/ 存放对应 PC/移动端 GIF/JPG 素材。
- 特殊年份/站点聚合目录 2026yunshi/ 复用 lnys 模板并叠加 bmny/bzcy/bzjp/mzgr/sjjx/sndy/zsys/zwcy 等子业务，体现模板继承式复用。
- 根目录 index.html 仅做 302 跳转至外部域名，说明该目录本身不作为入口页面，而是被外部站点通过 <script src=".../lnys/guding.php?dhid=..."> 方式引入。
- 依赖方向单向：PHP 模板 → 本地 images/static → 外链 v.youxuancdn.com 或 tg.ffceshi.com 的落地页，无后端数据库交互。
