- 每个业务目录统一提供 guding.php（固定横幅）、tubiao.php（图标导航）、tuwen.php（图文列表）、vip.php（表单落地页）、youxiajiao.php（悬浮角标）五类模板，命名与职责严格一致。
- 所有 PHP 模板内置相同的 isMobile() 函数，通过 HTTP_X_WAP_PROFILE、HTTP_VIA、USER_AGENT、ACCEPT 头判断移动端，分别输出不同尺寸的 HTML 片段。
- 链接统一通过 $u = $_SERVER['REQUEST_SCHEME'].'://'.$_SERVER['SERVER_NAME'] 拼接当前域名，再替换相对路径中的 href=' 与 src=' 前缀，避免跨域引用问题。
- 广告跳转链接遵循 https://v.youxuancdn.com/niu/{s}/{adid}/{dhid} 格式，其中 s 由 GET 参数 s 决定（1→'s'，否则'a'），dhid 作为渠道追踪参数透传。
- HTML 输出统一使用 document.writeln('<...>') 包裹，便于第三方站点直接通过 <script> 标签引入执行。
- 模板间共享 static/ 下的公共 JS/CSS/图片资源，业务专属图片则放在各自目录的 images/ 下并按 pcwap 后缀区分端类型（如 lnyspcguding.gif、lnyswapguding.gif）。
