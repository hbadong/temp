> ⚠️ **文档-代码一致性说明**：本文档原描述的 `blog_Quietlee`、`default`、`justnews` 三套主题，是 LECMS 通用发行版的默认主题。当前 `aimuchen100` 项目实际携带的主题为 `game`、`game955`、`game955m`、`macfkm` 四套（详见各自 `info.ini`）。下文以通用发行版主题为准进行说明。

本模块按主题目录划分，每个主题均为自包含的 LECMS 模板包：
- 通用发行版根目录下 `blog_Quietlee/`、`default/`、`justnews/` 三个主题各自拥有独立的 `info.ini` 元数据文件（name/brief/version/update/author），由 LECMS 主题管理器识别。
- **当前 aimuchen100 项目**实际主题为 `game`（默认）、`game955`、`game955m`（移动端）、`macfkm` 共 4 套，其中 `game955m` 是 `game955` 的移动版姊妹主题。
- 每个主题遵循统一结构：`.htm` 模板文件（index.htm、article_show.htm、page_show.htm、search.htm 等）+ `inc-*.htm` 可复用片段（header/footer/sidebar）+ `static/` 或 `css/js/img/fonts` 静态资源 + 可选的 `user/` 用户中心子模板。
- 模板通过 LECMS 模板引擎语法渲染：`{inc:xxx.htm}` 引入片段、`{block:list ...}` 调用数据块、`{loop:$data[list] $v}` 遍历列表、`{php}...{/php}` 嵌入 PHP 逻辑、`{$cfg[tpl]}` 引用当前主题路径。
- `blog_Quietlee` 主题额外包含 `系统二改文件/` 目录，存放对 LECMS 核心 block 库（`block_global_blog.lib.php`、`block_global_cate.lib.php`）和控制器（`index_control.class.php`）的二次开发补丁，表明该主题依赖对系统层的修改以实现三图模式等功能。
- 依赖方向单向：主题仅消费 LECMS 提供的模板标签与 `$cfg/$data/$gdata` 变量，不反向依赖后端逻辑。
