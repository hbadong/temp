- 模板入口文件以 `{inc:header.htm}` 开头、`{inc:footer.htm}` 结尾，公共头部与尾部通过 inc 片段复用。
- 数据获取统一使用 `{block:list|list_flag|list_top|global_blog ...}` 标签，参数化指定 cid/mid/limit/dateformat/showviews/intronum 等过滤条件。
- 列表渲染采用 `{loop:$data[list] $v}...{/loop}` 遍历，字段访问使用 `{$v[url]}`、`{$v[subject]}`、`{$v[intro]}` 等键名约定。
- 主题内资源引用统一通过 `{$cfg[tpl]}` 前缀拼接路径，确保多主题切换时资源路径正确。
- 每个主题根目录必须包含 `info.ini`，以 `#模版信息` 注释开头，声明 name/brief/version/update/author/authorurl 七项元数据。
- 复杂逻辑通过 `{php}...{/php}` 内联 PHP 代码实现（如 array_slice 截取列表、rank 计数器），而非外部 JS。
