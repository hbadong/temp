- 安装步骤通过 `$_GET['do']` 白名单校验后分支处理，每个步骤对应一个 `view/` 下的同名模板文件。
- 所有用户输入统一通过 `isset($_POST[...]) ? trim(...) : ''` 方式获取并使用 `js_back()` 进行非空与格式校验后返回。
- 数据库操作失败统一调用 `js_back()` 输出错误信息并 `exit`，成功进度通过 `js_show()` 输出 JS 片段并 flush 缓冲。
- 多语言文本集中放在 `lang/*.php` 文件中以关联数组形式 return，页面中通过 `lang('key')` 或 `R()` 函数引用。
- 数据库驱动扩展通过独立文件（`mysql.install.php` / `mysqli.install.php` / `pdo_mysql.install.php`）实现，由主流程按 `dbtype` 动态 include，避免条件判断混杂。
- 配置文件生成采用读取 `.sample.php` 模板后用 `preg_replace` 替换占位符的方式，而非直接拼接字符串。
