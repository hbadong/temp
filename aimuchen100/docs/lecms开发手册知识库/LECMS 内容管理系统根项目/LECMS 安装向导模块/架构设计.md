单入口控制器模式：`index.php` 作为唯一入口，通过 `$_GET['do']` 路由到 `lang`、`license`、`check_env`、`check_db`、`complete` 五个安装步骤；每个步骤由独立的 `view/` 模板文件渲染，业务逻辑集中在 `index.php` 中按分支处理。
- 分层结构：`index.php`（路由与流程控制）→ `function.php`（通用函数库：目录权限检测 `_dir_write`、SQL 分割 `split_sql`、JS 输出 `js_show/js_back`）→ `view/*.php`（纯模板）→ `data/*.sql`（表结构与初始数据）。
- 数据库驱动插件化：`mysql.install.php`、`mysqli.install.php`、`pdo_mysql.install.php` 三个独立文件分别实现三种 MySQL 扩展的建库、建表、导入 SQL、创建创始管理员和写入配置，由 `index.php` 根据用户选择的 `dbtype` 动态 include。
- 配置生成：通过正则替换 `config.sample.php` 中的占位符生成最终的 `lecms/config/config.inc.php`，同时复制 `plugin.sample.php` 和可选的 `route.sample.php` 到目标目录。
- 国际化：`lang/zh-cn.php` 与 `lang/en.php` 返回关联数组，通过 `R()` 框架函数从 cookie 或 GET 参数读取当前语言。
- 依赖方向：安装模块仅依赖 XiunoPHP 框架的 `base.func.php` 和 PHP 内置函数，不反向依赖被安装的目标应用。
