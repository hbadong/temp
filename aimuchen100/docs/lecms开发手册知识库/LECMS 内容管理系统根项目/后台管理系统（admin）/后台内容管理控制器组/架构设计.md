本模块由 7 个独立的 PHP 控制器文件组成，均继承自 `admin_control` 基类，遵循统一的 MVC 控制器模式：每个控制器通过 `index()` 渲染列表页面、`get_list()` 返回 JSON 数据（code/msg/count/data 结构）、`set()/set_field()` 支持行内编辑、`add()/edit()` 处理表单提交、`del()/batch_del()` 执行删除。控制器之间通过依赖注入访问共享服务：`$this->models`（模型元数据）、`$this->category`（分类树）、`$this->cms_content`/`cms_content_comment`/`cms_content_attach`/`cms_content_flag`（各业务表 ORM）、`$this->kv`（键值缓存）、`$this->runtime`（运行时缓存）。所有控制器在构造时根据 `mid` 参数动态绑定对应模型的表名（默认 article），并通过 `$_ENV['_config']['admin_lang']` 切换中英文显示。模板渲染使用 `$this->display()`，AJAX 响应通过 `exit(json_encode(...))` 直接输出。
