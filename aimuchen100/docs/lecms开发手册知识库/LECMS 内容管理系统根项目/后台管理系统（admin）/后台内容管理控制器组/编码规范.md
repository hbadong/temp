- 所有控制器以 `class xxx_control extends admin_control` 形式声明，并在文件开头使用 `defined('ROOT_PATH') or exit;` 保护。
- 列表接口统一实现 `index()` 渲染视图 + `get_list()` 返回 JSON，JSON 结构固定为 `{code:0, msg:'', count:N, data:[...]}`。
- 行内编辑统一通过 `set()` 或 `set_field()` 方法处理，参数通过 `R('field','P')`、`R('id','P')`、`R('value','P')` 读取。
- 错误处理统一使用 `E(code, msg)` 抛出异常，成功响应使用 `E(0, lang('...'))` 返回。
- 多语言支持通过 `$_ENV['_config']['admin_lang'] == 'zh-cn'` 判断，中文使用 `lang()` 函数，英文直接使用字段名首字母大写。
- 每个公共方法前后插入 `hook admin_xxx_control_method_before.php` / `hook admin_xxx_control_method_after.php` 钩子供扩展。
- 模型表名通过 `$this->_table` 和 `$this->_mid` 动态确定，ORM 对象 table 属性设为 `cms_{$this->_table}` 前缀。
