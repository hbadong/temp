- 每个控制方法都采用 GET/POST 双分支：空 POST 时通过 `xget('cfg')` 取配置并用 `form::get_*` 构建 `$input` 数组，非空 POST 时用 `R('field','P')` 取值并通过 `xset(...,'cfg')` 写入。
- POST 处理开头统一调用 `_trim($_POST)` 进行输入清洗，随后用 `R('field','P')` 配合类型转换 `(int)` 获取参数。
- 保存成功后统一执行 `$this->kv->save_changed()` 和 `$this->runtime->delete('cfg')` 刷新缓存，再通过 `E(0, lang('edit_successfully'))` 返回结果。
- 每个方法前后插入 `// hook admin_xxx_method_before.php` 与 `// hook admin_xxx_method_after.php` 注释作为扩展钩子。
- 错误提示统一通过 `E(code, lang_key)` 抛出，成功消息使用 `lang('opt_successfully')` 或 `lang('edit_successfully')`。
- 主题相关操作先调用私有 `check_theme($dir)` 校验目录名安全性与存在性，再执行启用或删除，且支持在主题目录下 `enable.php` 执行初始化脚本。
