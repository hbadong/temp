三个控制器类均继承自 `admin_control`，遵循统一的 MVC 控制器模式：每个方法对应一个设置页面或操作（如 `index`、`seo`、`link`、`user`、`attach`、`image`、`comment`、`email`、`security`、`other`、`theme/index`、`db/get_list` 等）。数据持久化通过 `this->kv`（键值存储）和 `this->runtime`（运行时缓存）完成，GET 请求读取 `xget('cfg')` 渲染表单，POST 请求通过 `R('field','P')` 取值后调用 `xset(...,'cfg')` 写入，再统一执行 `save_changed()` 并 `runtime->delete('cfg')` 清除缓存。部分全局配置（如伪静态开关、debug/lang）直接正则替换 `config.inc.php` 文件。模板渲染统一通过 `assign()` + `display()`，输入构建使用 `form::get_text` / `layui_loop` 等辅助函数。所有方法前后均预留 `hook admin_xxx_before.php` / `after.php` 扩展点，便于插件注入逻辑。
