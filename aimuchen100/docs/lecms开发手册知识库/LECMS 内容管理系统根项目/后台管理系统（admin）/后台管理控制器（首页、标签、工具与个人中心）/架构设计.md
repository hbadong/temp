四个文件均为继承自 `admin_control` 的 MVC 控制器类，遵循统一的请求-响应模式：通过 `R()` 获取参数、`E()` 统一返回 JSON 结果、`$this->assign()/display()` 渲染模板。依赖方向为单向：控制器调用框架提供的 `user`、`db`、`runtime`、`models`、`category`、`cms_content`、`cms_content_tag` 等模型/服务实例，不反向依赖视图或前端代码。`index_control` 负责后台入口与安全登录；`tag_control` 基于 `_mid` 动态切换数据表实现多模型标签管理；`tool_control` 封装缓存与日志清理及统计重建；`my_control` 处理管理员个人资料与密码修改。所有方法均通过 `hook admin_xxx_control_xxx_before.php` / `after.php` 钩子扩展点暴露扩展能力。
