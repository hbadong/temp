- 每个控制器方法前后成对插入 `hook admin_<controller>_control_<method>_(before|after).php` 钩子注释，供外部插件注入逻辑。
- 参数获取统一使用 `R('field', 'P'|'G'|'S'|'R')` 辅助函数，返回值统一通过 `E(code, msg)` 输出 JSON 并终止执行。
- 模板变量通过 `$this->assign(key, value)` 或 `$this->assign_value()` 传递，页面渲染统一调用 `$this->display()`。
- 表单字段通过 `form::get_text/get_number/get_textarea` 生成带 `placeholder`、`maxlength`、`lay-verify` 属性的 HTML，错误提示使用 `lang()` 国际化。
- 数据库操作统一通过 `$this->cms_content_tag`、`$this->user`、`$this->db` 等已注入的模型实例进行，避免直接 SQL 拼接。
