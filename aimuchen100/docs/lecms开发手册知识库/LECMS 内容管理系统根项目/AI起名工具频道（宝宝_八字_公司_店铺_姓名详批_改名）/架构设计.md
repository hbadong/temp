模块采用「单入口渲染器 + 多工具页面」的扁平结构：
- `tools_wrapper.php` 定义全局渲染类 `ToolsRenderer`（renderHead/renderBodyOpen/renderTabs/renderFooter/renderEnd）及辅助函数（tools_get_site_url、tools_esc、tools_get_api_config），是所有工具页共享的公共层。
- `index.php` 为频道首页聚合入口，以卡片网格展示六个工具；其余 `baobao.php`、`bazi.php`、`gongsi.php`、`dianpu.php`、`xingming.php`、`gaiming.php` 各对应一个工具表单页，结构高度一致：声明 `$current_page`、调用 `require tools_wrapper.php`、输出 SEO JSON-LD、渲染头部导航与表单、注入 `TOOLS_CONFIG`、加载 `tools.js`。
- `tools.js` 是统一前端逻辑：日期选择器联动、按钮组切换、表单校验、按 `type` 分支组装 POST 数据、AJAX 调用 `TOOLS_CONFIG.api` 后根据返回 `res.url` 拼接参数跳转到外部结果域。
- 依赖方向单向向下：每个工具页 → `tools_wrapper.php` → 外部 API（`tg.ffceshi.com`），CSS 由 `tools.css` 集中管理，JS 由 `tools.js` 统一管理，无跨文件相互引用。
- 在 WordPress 环境中可通过 `get_option('qm_api_config')` 覆盖默认 API 配置，非 WP 环境直接回退到硬编码默认值，保证独立运行能力。
