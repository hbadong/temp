index.php 作为唯一 Web 入口，定义 ROOT_PATH、APP_NAME=lecms、APP_PATH、FRAMEWORK_PATH 常量后 require xiunophx.php 启动框架；若 APP_PATH/config/config.inc.php 不存在则重定向至 install/ 完成首次安装。运行时依赖 runtime_cache（缓存、路由、模型基类）和 lecms_core（MVC控制器、模型、插件扩展），admin_panel 提供后台控制层，themes 与 static_assets 共同构成前台展示层，tools_module 与 lottery_templates 作为独立业务频道挂载在站点根目录下。各子模块通过统一的 XiunoPHP 路由与 HOOK 机制与核心框架交互，形成「入口→框架→核心→业务模块」的分层结构。
