- 所有模型类继承框架 `model` 基类，通过 `$this->table` 和 `$this->pri` 声明表名与主键，使用 `parent::get/set/delete` 配合 `xget/xset/xsave` 实现带过期时间的键值缓存。
- 控制器统一继承 `base_control`，在构造函数中通过 `$this->runtime->xget()` 获取全站配置，并通过 `$this->assign()` 向视图传递变量。
- 模板中使用 `{block:func(conf)}` 语法调用块函数，块函数命名约定为 `block_xxx($conf)`，返回数组供模板遍历渲染。
- 运行时编译产物统一写入 RUNTIME_PATH 对应子目录（`_control`、`_model`、`_view`、`core_lang`、`lang`、`filecache`），开发时通过 DEBUG 标志跳过缓存直接读取源码。
- 插件扩展通过 `// hook xxx.php` 注释标记插入点，由 `core::process_hook()` 扫描 PLUGIN_PATH 下同名文件或 `hook/` 子目录自动注入。
- 工具函数以 `_` 前缀命名（如 `_json_encode`、`_rmdir`、`_htmls`），业务函数以 `misc_` 前缀命名以避免与框架函数冲突。
