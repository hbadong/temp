本模块是 LECMS 框架的核心运行时层，采用 MVC + 插件钩子架构：
- 入口与核心：`_lecms.php` 定义 `core`、`debug`、`log`、`model`、`view`、`control` 等全局类，以及 `misc.func.php` 中的大量工具函数（IP解析、URL生成、加解密、文件操作等）。
- 控制器层：`lecms_control/` 下 `base_control.class.php` 为所有前台控制器的基类，封装用户登录态、站点配置、URL 等公共属性；`index_control.class.php` 继承自 base_control 实现首页逻辑。
- 模型层：`lecms_model/` 中每个 `*_model.class.php` 继承框架 `model` 基类，通过 `__get` 动态加载 db/cache 实例，实现统一的键值存取与多级缓存（db → memcache/l2_cache）。
- 视图层：`lecms_view/default/index.htm.php` 是编译后的模板产物，由 `view::display()` 将 `.htm` 模板编译为 PHP 并缓存到 RUNTIME_PATH。
- 语言包：`core_lang/zh-cn.php` 和 `lang/zh-cn.php` 分别存放核心与应用级中文文案，经 `core::init_lang()` 编译到 RUNTIME_PATH 下的 `core_lang/` 和 `lang/` 目录。
- 依赖方向：控制器 → 模型 → (db_interface / cache_interface) → 存储后端；view 仅负责渲染，不直接访问数据源；core 通过 `process_hook` 注入插件代码，形成单向扩展点。
