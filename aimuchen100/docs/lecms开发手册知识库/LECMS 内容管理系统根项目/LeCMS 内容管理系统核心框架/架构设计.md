模块采用经典的 MVC 分层架构，以 xiunophp 子目录为内置轻量框架内核，lecms/ 根目录承载业务层：
- 入口与路由：xiunophp.php 作为统一入口，定义常量路径（CONFIG_PATH、CONTROL_PATH、MODEL_PATH、BLOCK_PATH、PLUGIN_PATH、LANG_PATH、RUNTIME_PATH），根据 DEBUG 模式决定直接加载源码或合并生成 _lecms.php 运行缓存；core::init_start() 完成自动加载、URL 解析、控制器调度。
- 控制层 control/：所有控制器继承 base_control.class.php，后者封装用户登录态、站点关闭、SEO 变量注入、伪静态开关等公共逻辑，具体业务控制器如 index_control、show_control、user_control 等通过 $_GET[control]/$_GET[action] 动态加载。
- 模型层 model/：每个数据表对应一个 *model.class.php，继承自 xiunophp/lib/model.class.php，使用统一的 find_fetch/mget/format 等方法访问数据库，custom_model 提供用户自定义表扩展。
- 模板块 block/：以独立 .lib.php 函数形式实现页面区块渲染（如 block_list、block_user_info、block_global_search），通过 $run->runtime 读写缓存，供模板调用。
- 配置 config/：config.inc.php 集中管理数据库、缓存、主题、语言、调试等全局配置；plugin.inc.php 启用已安装插件。
- 插件系统 plugin/：每个插件为独立目录，包含 conf.php、控制钩子文件（*_after.php）、模板钩子（*.htm）、语言包和可选的 block 扩展，通过 hook 机制无侵入扩展核心。
- 国际化 lang/：按 zh-cn.php/en.php 分离前台与后台语言文件。
- 依赖方向：control → model/block → runtime/cache/db，插件仅通过钩子注入，不修改核心代码。
