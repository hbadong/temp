- 所有 PHP 文件顶部统一使用 `defined('ROOT_PATH') or exit;` 防止直接访问
- 控制器类继承 base_control，模型类继承 xiunophp/lib/model.class.php，保持统一的基类方法调用
- 在关键执行点插入注释形式的钩子标记（如 `// hook xxx_before.php`、`// hook xxx_after.php`），由 core 运行时动态加载同名 .php 文件实现扩展
- 模板块函数统一接收 `$conf` 配置数组参数，通过 `_int()` 等辅助函数安全取值，并返回固定结构的数组（如 list/cate_name/cate_url）
- 配置项通过 `$_ENV['_config']` 全局数组集中管理，运行时通过 `C()` 或 `$this->_cfg` 读取，避免硬编码
- URL 路由统一通过 `R()` 函数获取，区分 GET/POST 参数（'G'/'P' 后缀），支持伪静态 URL 后缀 `.html`
