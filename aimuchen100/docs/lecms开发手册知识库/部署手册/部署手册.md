# LECMS 部署手册

> 适用版本：LECMS 3.0.4 + XiunoPHP 1.0.0
> 适用 PHP：5.4.0 ≤ PHP < 8.2.0
> 适用 DB：MySQL 5.6+ / MariaDB 10.3+

---

## 一、部署前准备

### 1.1 服务器最低配置

| 项 | 最低 | 推荐 |
|---|---|---|
| CPU | 1 核 | 2 核+ |
| 内存 | 512MB | 2GB+ |
| 磁盘 | 2GB | 20GB+ |
| 操作系统 | Linux | Ubuntu 20.04 / Debian 11 / CentOS 7+ |
| PHP | 5.4.0 | 7.4 / 8.1 |
| MySQL | 5.6 | 8.0 |
| 缓存 | 文件 | Memcached / Redis |
| Web 服务器 | Apache | Nginx 1.18+ |

### 1.2 PHP 扩展必装

- PDO + pdo_mysql（或 mysqli / mysql）
- GD（图像处理）
- mbstring（多字节字符串）
- curl（HTTP 抓取）
- json（PHP 5.2+ 内置，5.4+ 完整）
- session
- fileinfo（验证上传文件类型）
- openssl（可选，hashids / phpmailer 用到）

### 1.3 必装可选扩展

- memcache 或 memcached（启用二级缓存时）
- redis（启用 Redis 缓存时）
- apcu（启用 APC 缓存时）
- zip（启用压缩包功能）

### 1.4 目录权限

```
lecms/                 755  框架目录（只读）
admin/                 755  后台目录（建议改名）
install/               755  安装向导（安装后 644 或删除）
view/                  755  主题目录
static/                755  静态资源
upload/                775  上传目录（需 PHP 用户写权限）
runtime/               775  运行时（错误日志）
runcache/              775  编译缓存（PHP 用户写权限）
log/                   775  日志目录
lecms/config/          755  配置目录（配置文件需可读）
```

> 安装向导会对每个目录做写权限检查。

## 二、首次部署（全新安装）

### 2.1 上传代码

```bash
# 在本地解压 aimuchen100.com.7z
7z x aimuchen100.com.7z -o/workspace/aimuchen100

# 上传到服务器
rsync -avz --exclude='runcache/*' --exclude='upload/*' --exclude='log/*' \
  /workspace/aimuchen100/ user@server:/var/www/lecms/
```

### 2.2 创建数据库

```bash
mysql -u root -p
> CREATE DATABASE lecms DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
> CREATE USER 'aiuchen100'@'localhost' IDENTIFIED BY 'StrongPassword!';
> GRANT ALL ON lecms.* TO 'aiuchen100'@'localhost';
> FLUSH PRIVILEGES;
> EXIT;
```

### 2.3 配置 Web 虚拟主机

#### 2.3.1 Nginx 推荐配置

```nginx
server {
    listen 80;
    server_name lecms.example.com;
    root /var/www/lecms;
    index index.php index.html;

    client_max_body_size 50M;

    # 安全：禁止敏感路径
    location ~* /(lecms/config|runcache|runtime|log)/.* {
        deny all;
        return 404;
    }

    # 禁止访问 PHP 文件（含敏感文件）
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # 伪静态（可选，需要 lecms_parseurl=1 + route.inc.php）
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
}
```

#### 2.3.2 Apache 配置（项目自带 `.htaccess`）

```apache
<VirtualHost *:80>
    ServerName lecms.example.com
    DocumentRoot /var/www/lecms

    <Directory /var/www/lecms>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/lecms_error.log
    CustomLog ${APACHE_LOG_DIR}/lecms_access.log combined
</VirtualHost>
```

启用 mod_rewrite：

```bash
a2enmod rewrite
systemctl restart apache2
```

### 2.4 启动安装向导

浏览器访问 `http://lecms.example.com/install/`，按提示填写：

1. **语言**：简体中文 / English
2. **许可协议**：勾选"我已阅读并同意"
3. **环境检测**：所有项应为绿钩
4. **数据库配置**：
   - 数据库地址：127.0.0.1
   - 端口：3306
   - 数据库名：lecms
   - 用户名：aiuchen100
   - 密码：StrongPassword!
   - 表前缀：le_（多站点时改）
   - 驱动：pdo_mysql
5. **创始管理员**：用户名/密码/邮箱
6. **完成**：提示删除 install 目录

### 2.5 安装后必做

```bash
# 1. 删除安装目录
mv /var/www/lecms/install /var/www/lecms/install.bak.$(date +%Y%m%d)

# 2. 修改关键配置
vim /var/www/lecms/lecms/config/config.inc.php
# 修改项：
#   'auth_key' => '强随机字符串（至少32字符）',
#   'debug' => 0,
#   'debug_admin' => 0,
#   'php_error' => 1,    # 开启错误日志

# 3. 重命名后台目录
mv /var/www/lecms/admin /var/www/lecms/manage_8a2b
# 并同步修改前台模板中所有 /admin/ 引用

# 4. 设置目录权限
chown -R www-data:www-data /var/www/lecms
chmod -R 755 /var/www/lecms
chmod -R 775 /var/www/lecms/upload /var/www/lecms/runtime /var/www/lecms/runcache /var/www/lecms/log

# 5. 启用缓存（可选）
# 编辑 config.inc.php:
#   'cache' => array(
#       'enable' => 1,
#       'l2_cache' => 1,
#       'type' => 'memcache',  # 或 redis
#       ...
#   )

# 6. 配置定时清理任务（可选）
cat > /etc/cron.daily/lecms-clean <<'EOF'
#!/bin/bash
# 清理 7 天前日志
find /var/www/lecms/log -name '*.php' -mtime +7 -delete
# 清理 runcache（让框架重新生成）
# find /var/www/lecms/runcache -name '*.php' -mtime +1 -delete
EOF
chmod +x /etc/cron.daily/lecms-clean
```

## 三、生产环境推荐配置

### 3.1 `config.inc.php` 关键项

```php
$_ENV['_config'] = array(
  // 关闭调试
  'debug' => 0,
  'debug_admin' => 0,

  // 开启 GZIP
  'gzip' => 1,

  // 开启错误日志
  'php_error' => 1,
  'php_error404' => 1,

  // 强 auth_key（用 openssl rand -base64 32 生成）
  'auth_key' => 'aB3$kL9mN2pQ7rS5tU8vW1xY4zA6bC9dE0fG3hI5jK7lM9',

  // 启用二级缓存
  'cache' => array(
    'enable' => 1,
    'l2_cache' => 1,
    'type' => 'memcache',
    'pre' => 'le_',
    'memcache' => array(
      'multi' => 1,
      'host'  => '127.0.0.1',
      'port'  => '11211',
      'id'    => 0,
    ),
  ),

  // 时区
  'zone' => 'Asia/Shanghai',

  // 数据库
  'db' => array(
    'type' => 'pdo_mysql',
    'master' => array(
      'host'     => '127.0.0.1',
      'port'     => '3306',
      'user'     => 'aiuchen100',
      'password' => 'StrongPassword!',
      'name'     => 'lecms',
      'charset'  => 'utf8mb4',
      'tablepre' => 'le_',
      'engine'   => 'MyISAM',
    ),
  ),

  // 路径
  'front_static' => 'static/',
  'admin_static' => '../static/',
  'url_suffix'   => '.html',
);
```

### 3.2 PHP-FPM 优化

```ini
; /etc/php/8.1/fpm/pool.d/www.conf
pm = dynamic
pm.max_children = 50
pm.start_servers = 10
pm.min_spare_servers = 5
pm.max_spare_servers = 20
pm.max_requests = 500

; OPcache
opcache.enable = 1
opcache.memory_consumption = 192
opcache.max_accelerated_files = 20000
opcache.revalidate_freq = 60
opcache.validate_timestamps = 1
```

### 3.3 MySQL 优化

```ini
# /etc/mysql/mysql.conf.d/mysqld.cnf
[mysqld]
innodb_buffer_pool_size = 1G
query_cache_size = 64M
max_connections = 200
slow_query_log = 1
long_query_time = 1
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
```

## 四、升级部署

### 4.1 升级前准备

```bash
# 1. 全量备份
mysqldump -u aimumen100 -p aimumen100 | gzip > backup_$(date +%Y%m%d).sql.gz
tar czf code_backup_$(date +%Y%m%d).tar.gz /var/www/lecms

# 2. 停止写入（可选，CMS 通常允许热升级）
# 把站点设为维护模式
```

### 4.2 升级流程

```bash
# 1. 上传新代码（保留 config/ upload/）
rsync -avz --delete \
  --exclude='lecms/config/' \
  --exclude='upload/' \
  --exclude='log/' \
  --exclude='runcache/' \
  --exclude='view/' \
  /local/aimuchen100/ user@server:/var/www/lecms/

# 2. 清理 runcache
rm -rf /var/www/lecms/runcache/lecms_control/*
rm -rf /var/www/lecms/runcache/lecms_model/*
rm -rf /var/www/lecms/runcache/lecms_view/*
rm -rf /var/www/lecms/runcache/admin_control/*
rm -rf /var/www/lecms/runcache/admin_view/*
rm -f /var/www/lecms/runcache/_lecms.php

# 3. 检查 SQL 升级脚本（如果有 install/data/upgrade_*.sql）
mysql -u aimumen100 -p aimumen100 < upgrade_3.0.4_to_3.0.5.sql

# 4. 验证
curl -I http://lecms.example.com/
```

### 4.3 回滚

```bash
systemctl stop nginx
rm -rf /var/www/lecms
tar xzf code_backup_YYYYMMDD.tar.gz -C /
gunzip < backup_YYYYMMDD.sql.gz | mysql -u aimumen100 -p aimumen100
systemctl start nginx
```

## 五、容器化部署（Docker）

### 5.1 Dockerfile

```dockerfile
FROM php:8.1-fpm-alpine

RUN apk add --no-cache \
        nginx supervisor mysql-client \
        $PHPIZE_DEPS \
    && docker-php-ext-install pdo_mysql mysqli gd opcache zip \
    && pecl install memcached redis \
    && docker-php-ext-enable memcached redis \
    && apk del $PHPIZE_DEPS

COPY --chown=www:www aimuchen100/ /var/www/lecms/
COPY nginx.conf /etc/nginx/nginx.conf
COPY supervisord.conf /etc/supervisord.conf

WORKDIR /var/www/lecms
EXPOSE 80

CMD ["/usr/bin/supervisord", "-c", "/etc/supervisord.conf"]
```

### 5.2 docker-compose.yml

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "8080:80"
    volumes:
      - ./upload:/var/www/lecms/upload
      - ./runtime:/var/www/lecms/runtime
      - ./runcache:/var/www/lecms/runcache
      - ./log:/var/www/lecms/log
    depends_on:
      - mysql
      - memcached

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: lecms
      MYSQL_USER: aimumen100
      MYSQL_PASSWORD: StrongPassword!
    volumes:
      - mysql_data:/var/lib/mysql

  memcached:
    image: memcached:1.6-alpine

volumes:
  mysql_data:
```

## 六、CI/CD 集成

### 6.1 GitHub Actions 示例

```yaml
name: Deploy
on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Setup SSH
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.HOST }}
          username: ${{ secrets.USERNAME }}
          key: ${{ secrets.SSH_KEY }}
          script: |
            cd /var/www/lecms
            # rsync 代码
            rsync -avz --delete \
              --exclude='lecms/config/' \
              --exclude='upload/' \
              --exclude='runcache/' \
              $GITHUB_WORKSPACE/ ./ \
            # 清缓存
            rm -rf runcache/lecms_control/* runcache/lecms_model/* runcache/lecms_view/* runcache/admin_control/* runcache/admin_view/* runcache/_lecms.php
            # 重启 PHP-FPM
            sudo systemctl reload php8.1-fpm
            # 健康检查
            curl -fsS http://localhost/healthcheck.php || exit 1
```

## 七、备份与监控

### 7.1 自动备份脚本

```bash
#!/bin/bash
# /etc/cron.daily/lecms-backup
BACKUP_DIR=/backup/lecms
RETENTION_DAYS=30

mkdir -p $BACKUP_DIR

# 数据库
mysqldump -u aimumen100 -p"$DB_PASS" aimumen100 \
  --default-character-set=utf8mb4 \
  --single-transaction \
  --triggers --routines --events \
  | gzip > $BACKUP_DIR/db_$(date +%Y%m%d_%H%M%S).sql.gz

# 代码
tar czf $BACKUP_DIR/code_$(date +%Y%m%d_%H%M%S).tar.gz \
  --exclude='runtime/*' \
  --exclude='runcache/*' \
  /var/www/lecms/

# 上传文件（可选，大站单独备份）
tar czf $BACKUP_DIR/upload_$(date +%Y%m%d_%H%M%S).tar.gz /var/www/lecms/upload/

# 清理过期备份
find $BACKUP_DIR -name '*.gz' -mtime +$RETENTION_DAYS -delete

# 上传到 OSS（可选）
# aliyun oss cp $BACKUP_DIR/db_*.sql.gz oss://lecms-backup/db/
```

### 7.2 监控项

| 项 | 监控方式 | 告警阈值 |
|---|---|---|
| HTTP 状态码 | curl -I | 非 200 |
| PHP-FPM 进程数 | supervisorctl status | < 5 |
| MySQL 进程数 | `SHOW PROCESSLIST` | > 100 |
| 磁盘空间 | df -h | > 80% |
| runcache 目录大小 | du -sh | > 1GB |
| 错误日志增速 | find log -mmin -5 | > 100 行/5min |
| 慢 SQL 数量 | mysql slow log | > 10/min |
