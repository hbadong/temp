# 全功能核心算法优化记录 · 第二批（2026-10-22）

## 一、姓名打分：主分综合化（E.scoreOf 新增）

**旧**：主分 = 纯五格数理机械分。
**新**：综合评分 = 五格 42% + 音律读感 22% + 字义内涵 16% + 生肖契合 12% + 热度 8%（-重名扣减）。

- 打分页主分变为综合分，下方新增**分项进度条**（五格/音律/字义/生肖/重名热度）
- 实测：`李思辰` 68 分（五格 99 但重名热度扣分——思辰为高频名，真实）；`王梓涵` 63 分（双热字重名 -12，符合现实重名率）

## 二、姓名/生肖配对真实化（matchNames 重写）

**旧**：`100 - (笔画差 % 40) - (和 % 11)` 纯取模伪随机。
**新**：四维和合分析：
1. **人格五行生克**（相生 +20 / 相克 +2 / 比和 +10，输出如"土生金，相生有助"）
2. **音律和合**（两名尾字声调错落 + 读感分）
3. **笔画和合**（差值越小越融洽，民俗）
4. **语义亲和**（两名尾字语素亲和度）
结果附"和合分析"说明行。

## 三、诗词/周易起名：综合评分排序

两者原按五格分排序，现统一走 `qualityScore`（五格 + 音律 + 语义），reason 附音律分析（"出自「桃之夭夭」；音律谐畅"）。

## 四、公司起名细化（generateCompany 重写）

- **行业尾词映射**：餐饮→"餐饮/食品/餐饮管理/烘焙/食品科技"、科技→"科技/信息技术/智能科技"…（旧版 6 个尾词与行业无关轮换）
- **法人八字契合**：名字首字五行 vs 法人喜用神（契合 +20 权重）
- **音律评分**接入
- **去重**（seen 表）+ 综合分排序
- 实测：餐饮类输出"禾仁餐饮 90 / 味卓餐饮管理 90 / 醇耀食品科技 90"
