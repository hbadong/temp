## 一、市面调研结论

### 调研对象
美名腾（智能起名网）、起名网 qiming.cn、善若吉、56 起名网、AI 大模型起名（DeepSeek/豆包 提示词方案）。

### 核心功能共识
1. **八字排盘 + 日主强弱 + 喜用神/忌神**——"喜什么补什么，不是缺什么补什么"已成行业共识；用神（最需要）+ 喜神（辅助）+ **忌神（需避开）** 三件套
2. **四维分项评分**（美名腾）：文化印象 / 五行八字 / 生肖 / 五格数理，各维度独立打分（98 分上限）
3. **音形义三关**：声调起伏、谐音黑名单（杜子腾类）、字形繁简搭配、生僻字过滤
4. **意愿/辈分输入**（美名腾独创）：父母愿望、固定字/辈分字、排除避讳字、名字字数、单双名
5. **名字变换**（美名腾独创）：同音/同义/同笔画/同部首变换
6. **五格最优笔画组合推荐**：给定姓氏枚举使五格大吉的名字笔画组合
7. 生肖宜忌偏旁推荐、重名查询、过滤器

### 行业文章的核心观点（与本站已实现一致）
- "喜什么补什么"正确、"缺什么补什么"是最大误区 ✓（上一批已实现日主强弱）
- 五格剖象是辅助、喜用神是第一准则 ✓（本站权重 42% vs 生肖/音律等 58%）
- 生成时需过滤不雅谐音、控制声调起伏 ✓

## 二、本站差距 → 本轮六项升级

| # | 差距 | 实现 |
|---|---|---|
| 1 | **缺忌神**（只算喜用不算忌讳） | `bazi()` 新增 `tabooWx`：身强忌生扶（印/比劫）、身弱忌克泄（官杀/食伤），取八字中较多者；结果页显示"忌X（已自动避开）"，生成引擎自动过滤忌神五行字 |
| 2 | **无排除字/辈分字**（美名腾核心输入） | 八字起名页新增"排除用字""辈分/固定字"输入框；引擎 `prefs.avoid` 过滤候选、`prefs.fixed` 辈分字模式（辈分字+喜用字组合，结果只保留含辈分字的名字） |
| 3 | **生成时无谐音过滤**（仅打分页检查） | 生成循环内对全名跑谐音检查，命中不雅谐音的候选 -18 分并在推荐理由标注"⚠ 谐音「X」需斟酌" |
| 4 | **无五格最优笔画组合推荐** | 新增 `E.bestStrokePairs(surname)`：枚举名字两字笔画 1-21×21，过滤五格凶数+三才凶配置，按吉数评分取 top6；支持复姓（欧阳→天32）；结果页显示"X+Y 画"推荐 |
| 5 | **名字变换不完整**（仅同音） | 新增 `E.nameVariants(name)`：同音/同部首/同笔画/同五行四类变换；名字详情页原"同音替换"升级为"名字变换"区块（四行分类链接） |
| 6 | 语义表 "Wave" 残留 bug | 已修 |
