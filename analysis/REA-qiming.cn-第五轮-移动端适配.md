## 三、发现并已修复的 4 个问题

### 1. 公司起名页 grid 列被撑破（451px → 375px）
- **根因**：`.company-form` 为 `display:grid`，但内部 `select/input` 未设 `width:100%`，
  select 按固有内容宽度（397px）撑大 grid 列，表单整体溢出屏幕 76px，出现横向滚动。
- **修复**：`.company-form select/input { width:100%; min-width:0; box-sizing:border-box }`。

### 2. 首页"文章四栏"在 375px 仍为 2 列（656px → 375px）
- **根因**：`.art-cols` 仅在 ≤860px 从 4 列降为 2 列，缺更窄断点的单列规则；
  2×312px + gap 溢出 281px。
- **修复**：760px 断点内 `.art-cols { grid-template-columns: 1fr }`（对齐原站单列堆叠）。

### 3. 文章详情页侧栏 320px 溢出（574px → 375px）
- **根因**：`.layout`（`1fr 320px` 双栏）的 860px 断点规则写在文件前部，
  被后置的同名基础定义层叠覆盖，媒体查询失效；侧栏连带罗盘 SVG（固定 270px）溢出。
- **修复**：760px 断点内补充 `.layout { grid-template-columns: 1fr }` +
  `.promo-art svg { max-width:100% }`。

### 4. 结果页标题拆行（"结 / 果"断开）
- **根因**：860px 断点标题 26px + 6px 字距，"李姓宝宝 · 八字起名结果"超 375px 被换行拆字。
- **修复**：移动端标题降为 24px + 2px 字距，单行放下。

## 四、对齐原站的移动端优化

1. **工具矩阵改 4 列小图标格**（原站形态）：760px 下 `.icon-grid` 由 2 列大卡改 4 列紧凑格（22px 图标 + 12px 小字）。
2. **首屏紧凑化**（原站表单更靠上）：横幅 min-height 240→190px、表单卡叠加 -56→-64px、
   面板内边距收紧、Tab 字号 17→15px。首屏即可完整看到表单与"立即起名"按钮。
3. **侧栏 SVG 自适应**：罗盘推广图 `max-width:100%`，杜绝固定宽溢出。

## 六、结论

手机端 4 处布局破损（公司起名 grid 溢出、首页文章栏 2 列溢出、文章页侧栏溢出、标题拆行）**已全部修复**，
15 个页面在 375×812 视口下零横向溢出、零超宽输入控件、底部导航栏正常；
工具矩阵 4 列化与首屏紧凑化两项优化使移动端形态与原站对齐。剩余差异均为内容素材层，不影响布局正确性。
