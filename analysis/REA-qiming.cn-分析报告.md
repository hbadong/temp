## 3. 首页结构（DOM 1688 节点，A×270 / DIV×258 / LI×200 / INPUT×40 / FORM×4）

## 4. 技术栈与运行特征（REA 证据）

- **服务端**：疑似传统 CMS 生成静态 `.html`（URL 全部为伪静态/静态），利于 SEO
- **前端**：多页应用（MPA），jQuery 时代技术风格；6 个脚本文件；无框架特征
- **统计**：百度统计（localStorage `Hm_lvt_*`、sessionStorage `Hm_lpvt_*` / `HMACCOUNT`）
- **存储**：IndexedDB / Cache API 未使用；WebStorage 仅统计 Cookie 辅助
- **无 WebSocket、无 PWA**；交互主要靠表单提交 + 页面跳转
- **SEO 设施**：sitemap.txt、面包屑、海量长尾文章/名字详情页
