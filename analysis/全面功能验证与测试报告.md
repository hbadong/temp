## 二、测试中查出并修复的缺陷（3 个）

| 缺陷 | 严重度 | 修复 |
|---|---|---|
| `wuge(null)` 抛异常（"object null is not iterable"） | 中（健壮性） | 入口校验：null/非字符串/空串 → 返回 null |
| **复姓五格走单姓规则**（欧阳天格算成 5，应 15+17=32） | 高（数理正确性） | FU_SURNAMES 最长前缀匹配识别复姓，按复姓规则取格；补齐 46 复姓全部用字 + 130 个高频名用字的康熙笔画兜底表（"修"10/"登"12/"一"1 等），未收录字才回退估算 |
| 统计 API 未转义 HTML（XSS payload 原样入库） | 中（安全） | 入库前 `htmlspecialchars` 转义（前端展示层本已转义，此为纵深防御） |
