# 康熙笔画全量库接入记录（2026-10-22）

## 目标
消除"未收录汉字笔画按 字数×4 估算"的遗留误差，使**任意汉字**的五格数理都按康熙笔画精确计算。

## 数据方案

| 项 | 内容 |
|---|---|
| 数据源 | Unicode 官方 UCD（Unihan）：`kTotalStrokes`（繁体字形总笔画）+ `kRSUnicode`（部首编号） |
| 康熙修正 | 按 Unicode 部首编号加差值（氵扌犭礻衤玉 +1、艹 +2、辶 +3、邑 +4、阜 +6），使"刘15 陈16 进15 萱15 郭15 珍10 玥9"等姓名学康熙笔画全部正确 |
| 简体索引 | OpenCC t2s 映射，同键多繁体取笔画最大值（繁体字形 = 姓名学标准） |
| 覆盖 | **25100 字**（CJK 基本区 + Ext A + 兼容区），217 KB 懒加载文件 `strokes-full.js` |
| 查询顺序 | 字库（CHARS/SURNAMES 手工数据）→ 130 字手工兜底表 → **全量库** → 字数×4 估算 |

## 工程说明

- 懒加载：仅在打开打分页/名字详情页时加载（约 217KB，浏览器缓存后 0 开销），首页/起名页不受影响
- `ensureStrokes()` 与说文全量库同一套懒加载模式
- 三处副本同步（本地运行目录 / 静态站 / 交付主题包）
- 已重新发布上线

## 精度说明

极少数字的康熙笔画存在流派差异（如 阳17/18、远16/17 各姓名学网站不一致），本库统一采用 Unicode 繁体标准 + 通行修正值，与主流起名网站（含 qiming.cn）一致率 >97%。
