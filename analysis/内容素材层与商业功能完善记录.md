## 二、真实使用统计（后端 + 前端全链路）

**后端** `stats-api.php`（新增，独立于 LECMS 路由）：
- `?action=track&k=naming|score|match|search|order&n=xxx`：行为计数
- `?action=get`：返回 totals / recent（最近60条）/ charUsage（字频）/ orders
- 存储于 `data/stats.json`（flock 文件锁），自动去重限长防膨胀

**前端埋点**（main.js）：
- 起名提交、姓名打分、生肖/姓名配对、统一搜索 → 实时上报
- 付费解锁 → 记录订单号与套餐

**真实数据展示**：
- 首页新增"真实使用统计条"：累计服务查询 / 起名方案生成 / 姓名评测 / 已开通方案
- 首页"别人正在查的姓名"滚动流：**有真实记录时覆盖演示数据**（显示真实用户查询如"李函鑫 正在为宝宝起名"），无记录回退演示
- 汉字详情页：叠加"📊 本站真实查询统计：N 次（实时累计）"（来自起名/打分结果的字频统计）
- 输入内容经 HTML 转义防注入

## 三、商业付费闭环（演示支付）

**流程**（对齐原站"提交→订单→付费解锁"形态，改为结果页内嵌解锁，体验更现代）：
1. 提交起名 → 结果页顶部显示**方案编号**（QM+日期-4位，如 QM20261022-9595）+"免费预览前 3 个"徽标
2. 第 1-3 个方案完整展示；第 4-12 个**模糊锁定**（名字/分数 blur + 解锁按钮 + 提示文案）
3. 底部解锁横幅："已展示 3/12 个方案"+ 权益说明
4. 点击解锁 → **支付弹窗**：三档套餐（体验版 ¥9.9 / 标准版 ¥29.9 / 尊享版 ¥69.9）+ 支付宝/微信 Tab + 程序化占位二维码（明确标注"演示环境模拟支付"）
5. 模拟支付成功 → 订单写入 sessionStorage（一次付费本会话永久有效）→ 自动刷新解锁全部 → 订单条变为绿色"已开通 · 标准版"徽标 → 订单上报统计

**验证**：端到端实测通过（锁定 9 卡 → 支付 → 12 卡全解锁 → stats order=1）。
