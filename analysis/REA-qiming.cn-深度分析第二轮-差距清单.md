# REA 深度分析报告（第二轮）：www.qiming.cn 全站功能拆解 × 与当前实现差距清单

> 方法：REA CDP 运行时检查（inspect_web_page / capture_web_screenshot）逐页探测
> + 静态源码抓取（14 个关键页面 + 公共 JS）交叉验证。
> 证据截图见 `screenshots/`。本文只描述功能结构，不转载原站文案。

## 一、本轮新发现（第一轮报告未覆盖）

### 1. 全站统一的表单引擎（最重要的架构发现）

所有 8 个工具页共用同一套表单字段规范与提交通道：

| 字段 | 含义 | 出现页面 |
|---|---|---|
| `xing` | 姓氏（或姓名/原名/法人姓名） | 全部工具页 |
| `sex` | 性别（男/女/**未知**三态） | 全部 |
| `birth_time` → `birthday` + `hour` | 出生日期 + **出生时辰**分开存储 | 全部 |
| `birth_address` → `city_code` | 出生地 → 城市编码（弹层城市选择器） | 宝宝/改名/测试等 |
| `oid` / `type` / `key` / `ref` | 防滥用签名四件套 | 全部 |
| `first_wuxing` / `second_wuxing` | **五行偏好下拉**（八字起名特有） | bazi.html |
| `feature` / `gossip` | **卦象选择**（周易起名特有，zhouyi.js 驱动） | zhouyiqiming.html |
| `city`→`area_id`、`company_line`→`class_id` | 公司所在地 + **行业分类ID**（公司起名特有） | gongsiqiming.html |

提交流程：`common.js` 的 `submitQiming()` → AJAX POST 到 `pay.qiming.cn/gxqm/qiming.html`
→ 服务端计算 → 返回 `redirectUrl` → 跳转到服务端渲染的结果页。
**即：计算全部在服务端，结果页是可被搜索引擎收录的静态 URL。**

### 2. 表单校验规则（common.js）

- 姓氏只允许汉字、最长 2 字；单字姓必须命中**姓氏白名单**（ALLOWED_SURNAMES，含 single/double 复姓表）
- 生日的年/月/日与时辰在客户端拆分后上传

### 3. 每个工具页都是独立 SEO 落地页

结构统一为：顶部大标题（书法风）+ 一句话定位副标题 + 表单卡片 +
**"XX 综合六大维度"介绍区**（图文 SEO 内容）+ "猜你喜欢"文章推荐位 + 公共底部。
第一轮只分析了首页，这一层"页 = 渠道落地页"的模板是站点的核心 SEO 打法。

### 4. 视觉规范（REA 截图证据）

- 中国风水墨：每页顶部水墨山水/工笔插画横幅 + 书法感大标题
- 色系：暖红（CTA）+ 米白/浅粉卡片 + 墨灰正文
- 性别选择内嵌在输入框右端（圆形单选钮），含"未知"档（未出生宝宝）
- 自研日期控件（rui-datepicker，可选时辰）+ 弹层城市选择器（popcity）

### 5. 内容矩阵细节

- **名字详情页** `/mingzi/<id>.html`：每个名字一个落地页，含读音相同名字、含某字的更多名字等聚合链接（百万级页面）
- **汉字详情页** `/kxzd/<id>.html`：单字页含 **同音字 / 同部首 / 同笔画 / 同五行** 四个关联矩阵
- **首页排行栏 4 个**：男孩用字排行、女孩用字排行、男孩热门名字排行、女孩热门名字排行（带月份维度）
- **文章页**：标签聚合 + 阅读排行榜；标题普遍带长尾词与数量后缀
- **全站搜索**：每页头部统一搜索框（`/search.html?k=&formType=`），按类型查字/名字/姓名
- **配对页**：除男女姓名配对外，还有生日配对、单字查询等衍生小工具
- **404 页**：定制化（"页面迷路了"+ 引导），search.html 直接对不存在关键词回 404 标题（SEO 策略）

## 二、与当前实现的差距清单（按优先级）

### P0 —— 核心体验差距（用户可感知的最大差异）

| # | 差距 | 原站做法 | 当前实现 | 改造点 |
|---|---|---|---|---|
| 1 | 中国风视觉 | 水墨横幅+书法标题+暖红米白 | 通用扁平设计 | 重做 CSS 主题：水墨 SVG banner、书法字体标题、暖色卡片 |
| 2 | 性别三态 | 男/女/**未知**，内嵌输入框 | 仅男/女 | 加"未知"档；radio 移入输入框内 |

## 三、结论

第一轮复刻对齐了"功能清单"，但与原站的差距集中在三层：

1. **交互深度**：时辰、城市、五行偏好、卦象、行业分类等输入维度缺失；
2. **结果体系**：原站"每次计算 = 一个可收录 URL"的内容矩阵模式，我们是即时渲染；
3. **视觉气质**：原站是强中国风的垂直品牌设计，我们是通用风格。

建议实施顺序：P0（1-6）一次性改造主题模板与引擎 → P1（7-12）逐个补功能 → P2 借 LECMS 插件生态补 SEO。
