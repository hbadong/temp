# REA 第四轮深度逆向分析：图片素材 / 布局 / 显示效果

> 方法：14 个页面源码图片资产统计 + style.css 结构参数提取 + 首页与工具页截图比对。
> 证据：`screenshots/round4/`。本文只做结构描述与参数比对，不转载原站素材。

## 一、图片素材：这是当前最大的差异（9 项）

对原站 14 个页面做 `<img>` 统计后的结论：**每页 9–26 张图片**，我们**全站 0 张 `<img>`**。

| # | 图片类型 | 原站实例（文件名即用途） | 数量 | 我们的现状 |
|---|---|---|---|---|
| 1 | **每页专属横幅插画** | `bbqmBanner.jpg`（宝宝起名）、`bzqmBanner.jpg`（八字）、`scqmBanner.jpg`（诗词）、`zyqmBanner.jpg`（周易）、`gsqmBanner.jpg`（公司）、`xmcsBanner.jpg`（姓名测试）、`boyBanner.jpg`（男孩）—— 水墨山水风格，每页一张 | 7+ | 纯 CSS 渐变 + SVG 山形剪影 |
| 2 | **六大维度配图** | `wd1.jpg`~`wd6.jpg`（国学/音形义/期望/大数据/诗词/生肖），图文卡形式 | 6/页 | 纯文字宫格 |
| 3 | **汉字字形图** | `/upload/qmzd/<hash>.png` 每字一张透明底字形图 + `/upload/kxzdsvg/<id>.svg` 线稿 | 每字 2 张 | 用系统字体渲染的文字 |
| 4 | **名字页逐字配图** | 每个字一张字形图（如艳、仪各一张） | 2–4/页 | 无 |
| 5 | **文章正文配图 + 列表缩略图** | `/upload/artimg/...jpg`，列表走 `/style/pic/i.php?src=` 裁切代理 | 21/页 | 无（纯文本） |
| 6 | **侧栏工具推广图** | `bbqmright.png`、`xmcsright.png` | 2/页 | 无 |
| 7 | **装饰罗盘/指掌图** | `luopan.png`、`zhizheng.png`（每页重复出现，作维度图标） | 2–4/页 | 无 |
| 8 | **页脚品牌与资质图** | `logo_foot.png`、`qiming-110.png`（备案/认证图标） | 2/页 | 纯文字 |
| 9 | **iconfont 线性图标** | 每页 12–59 个图标元素（时钟/眼睛/评论/搜索/箭头） | 12–59/页 | emoji + 内联 SVG |

> 结论：原站的"质感"很大程度来自**定制插画 + 字形图 + 图标字体**这套视觉资产，而不是 CSS。

| # | 差异 | 原站 | 当前 |

## 四、优先级建议

**P0（视觉落差最大）**
1. **自制水墨横幅**：为 6 个工具页各生成一张原创 SVG 水墨山水（程序化山峦 + 留白 + 印章），替代纯渐变；横幅与表单卡做**叠加**关系
2. **六大维度改图文卡**：6 个原创 SVG 图标 + 标题 + 两行说明
3. **容器宽度 1200px**，区块间距与内边距放大

**P1**
4. **字形展示**：汉字/名字详情页用 SVG `<text>` 描边或大号字重渲染"字形块"，模拟字形图效果（无需图片素材）
5. **iconfont 替代 emoji**：统一用内联 SVG 图标集（时钟/眼睛/评论/搜索/箭头/罗盘）
6. **文章配图位**：文章正文支持图片样式与图注；列表页加缩略图位（LECMS 已有 pic 字段）

**P2**
7. 侧栏工具推广卡（带插画位）
8. 页脚品牌图与备案图标位
9. 列表缩略图裁切代理（等比例 4:3，object-fit）

> 说明：原站的插画与字形图属于其视觉资产，不能直接取用；实现时用**程序化生成的原创 SVG** 达到同类质感。
