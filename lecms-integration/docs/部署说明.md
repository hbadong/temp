# 好名主题 —— LECMS 整合部署说明

将"好名网"起名系统（原创设计与算法）整合进 LECMS 3.0.x（基于 xiunoPHP，MIT 协议）的完整交付包。

## 包内容

```
lecms-integration/
├── theme/haoiming/          # LECMS 主题（模板 + 工具 + 样式 + 引擎）
│   ├── index.htm            # 首页（三 Tab 起名表单 + 服务矩阵 + 用字排行 + LECMS 文章四栏）
│   ├── inc-header.htm       # 公共头部（导航 + 搜索入口）
│   ├── inc-footer.htm       # 公共底部（含 {block:list} 热门文章）
│   ├── article_list.htm     # 文章列表页（LECMS global_cate 标签）
│   ├── article_show.htm     # 文章内容页（上一篇/下一篇 + 工具导流）
│   ├── article_index.htm    # 频道页
│   ├── search.htm           # 站内搜索（LECMS 搜索）
│   ├── 404 / comment / page_show / tag_* / flags / space / close_website
│   ├── css/style.css        # 原创样式
│   ├── js/data.js           # 原创字库/诗词/百家姓数据
│   ├── js/engine.js         # 原创算法引擎（干支/五行/三才五格/起名）
│   ├── js/main.js           # 主题交互层（CMS 页 + 工具页共用）
│   └── tool/*.html          # 11 个静态工具页（起名/打分/配对/字典/百家姓/诗词/公司/介绍页）
├── scripts/seed_articles.py # 自动登录后台 → 建分类 → 发布 24 篇原创文章
└── docs/                    # 本说明 + PHP8.3 兼容补丁说明
```

## 环境要求

- PHP（建议 7.4 ~ 8.1；8.3 需打兼容补丁，见下）
- MySQL / MariaDB
- LECMS 3.0.x（官方源：https://gitee.com/phpyos/lecms3.0.3 或 www.lecms.cc）

## 部署步骤

### 1. 安装 LECMS
按官方流程安装（/install/ 向导）。LECMS 自带 PHP 版本检查，
若使用 PHP 8.2+，先把三处版本上限检查放宽：

```bash
sed -i "s/version_compare(PHP_VERSION, '8.2.0', '<')/version_compare(PHP_VERSION, '9.0.0', '<')/" \
  install/index.php lecms/xiunophp/xiunophp.php lecms/xiunophp/tpl/sys_message.php
```

### 2. PHP 8.3 兼容补丁（仅 8.2+ 需要）

```bash
# 2.1 QUERY_STRING 未定义（内建服务器/无重写环境）
sed -i 's/$u = $_SERVER\["QUERY_STRING"\];/$u = isset($_SERVER["QUERY_STRING"]) ? $_SERVER["QUERY_STRING"] : "";/' \
  lecms/xiunophp/lib/core.class.php

# 2.2 调试器把 PHP8 弃用警告当错误
# 在 lecms/xiunophp/lib/debug.class.php 的 error_handler 开头加入：
#   if (!(error_reporting() & $errno)) return;
# 并把 init_start 中的 error_reporting(E_ALL | E_STRICT) 改为
#   error_reporting(E_ALL & ~E_DEPRECATED & ~E_NOTICE & ~E_WARNING & ~E_STRICT);
```

### 3. 安装主题

```bash
cp -r theme/haoiming /path/to/lecms/view/
```

然后进 LECMS 后台 → 主题管理，启用"好名主题"；
或直接更新数据库 `lecms_kv` 中 `cfg` 的 `theme` 字段为 `haoiming`，
并清空 `lecms_runtime` 表与 `runcache` 编译缓存。

### 4. 建分类 + 发文章

```bash
# 修改 seed_articles.py 顶部的 BASE / AUTH_KEY / 管理员账号后运行：
python3 scripts/seed_articles.py
# 自动完成：登录后台 → 创建 4 个分类（八字/诗词/周易/起名知识）→ 发布 24 篇原创文章
```

### 5. 验证

| 页面 | URL |
|---|---|
| 首页 | `/index.php` |
| 分类列表 | `/index.php?cate--cid-1` |
| 文章页 | `/index.php?show--cid-1-id-1.html` |
| 搜索 | `/index.php?search-index&keyword=五行&mid=2` |
| 起名工具 | `/view/haoiming/tool/naming.html` |
| 姓名打分 | `/view/haoiming/tool/score.html` |
| 后台 | `/admin/` |

## 架构说明

- **CMS 层（LECMS 驱动）**：文章分类/列表/内容/搜索/标签/评论，模板用 LECMS 标签
  （`{block:list}`、`{block:global_cate}`、`{block:global_show}`、`{loop:$data}`、`{$cfg[tpl]}`）
- **工具层（纯前端 JS）**：起名引擎/打分/配对/康熙字典/百家姓/诗词库为公司无关的静态页，
  通过 `{$cfg[tpl]}tool/xxx.html` 与 CMS 页面互链，头部导航统一
- **数据**：字库（约150字+96姓）、43 句公共领域古典诗文、八字/五格算法均为原创实现，
  命理输出为简化演示模型，仅供娱乐参考
